Contrasts & multiple comparisons

“至少一个 mean 不同”之后，哪些差异值得相信？

整体检验没有定位差异；先写科学比较，再控制这一组决策的错误率。

比较越多，至少一次 Type I error 越常见

Comparisonwise error rate αᵢ 是单个检验错误率；Familywise / experimentwise error rate (FWER) 是同一 family 中至少错误拒绝一次的概率。t 个 treatments 有 t(t−1)/2 个 pairwise comparisons。

independent null tests：FWER = 1−(1−αᵢ)ᵐ
Bonferroni：每个 test 用 α/m，或 adjusted P=min(1,mP)

m=20、αᵢ=.05 时 independent FWER≈.6415。实际 pairwise tests 共享组，通常相关；该公式仅是独立示例，不能当它们的精确 FWER。Bonferroni 由 union bound 保证 FWER≤α，不要求独立，但可能 conservative。

Family 由研究决策定义，应在看结果前规划。只汇报显著 comparisons 会隐藏搜索成本。课程 weed-control example 用四个预设问题，并对 m=4 应用 Bonferroni。

Linear combination 先把研究问题写成 coefficients

L=Σaᵢμᵢ，L̂=Σaᵢȳᵢ
Contrast：Σaᵢ=0
SE(L̂)=√[MSE Σ(aᵢ²/nᵢ)]

任意 linear combination 可以比较均值、平均或总和；只有系数和为零才是 contrast，对共同 baseline shift 不敏感。原创 treatments control、A、B、C：比较 control 与三种处理平均，可用 [1,−1/3,−1/3,−1/3]；平均 A、B、C 是否为 0 用 [0,1/3,1/3,1/3]，这不是 contrast。

Equal n 时 SE=√[(MSE/n)Σaᵢ²]。模型内 common variance、independent groups 下成立。t=(L̂−L₀)/SE，df=error df；1-df F test 在 L₀=0 时 F=t²，SScontrast=L̂²/Σ(aᵢ²/nᵢ)。同时置信区间的 critical value 需与所选 multiplicity 方法一致。

原创 means=[10,12,14,16]、每组 n=4、MSE=4，control minus average =10−14=−4；Σa²=4/3，SE=√(4/3)≈1.1547，t≈−3.464。改变全部 coefficients 的共同倍数，会改变 estimate 和 SE，却不改变 t 的绝对值。

Orthogonality 连接设计的独立信息

Cov(L̂ₐ,L̂ᵦ)=σ²Σ(aᵢbᵢ/nᵢ)
orthogonal：Σ(aᵢbᵢ/nᵢ)=0

Equal n 时简化为 Σaᵢbᵢ=0。t 个 mean 有 t−1 个独立 contrast dimensions，完整 orthogonal set 可将 treatment SS 分解。Normal model 下 uncorrelated linear combinations 独立；不要把“coefficients 看起来不同”当成 orthogonal。

原创三个 groups，contrast a=[−2,1,1] 比较第一组与后两组，b=[0,1,−1] 比较后两组；equal n 下 inner product=0。Unequal n 时必须使用 weighted condition，而非直接沿用等样本规则。

从 cell means 转换到 SAS model coefficients

课程 wood-treatment 例用 μᵢ=μ+τᵢ 改写 linear combinations。模型 parametrization 决定 ESTIMATE 的 intercept coefficient；若 Σaᵢ≠0，intercept coefficient 就是 Σaᵢ，不能漏掉。

/* 确认 CLASS levels 的输出顺序后填写 coefficients */
proc glm data=d;
 class treatment;
 model y=treatment;
 contrast 'Control vs active average' treatment 3 -1 -1 -1;
 estimate 'Mean of active treatments' intercept 3
          treatment 0 1 1 1 / divisor=3;
run;

R 中用同一个已拟合 model 的 covariance matrix 或 emmeans comparisons，而不是分别重新拟合每一对而丢失 pooled MSE。打印 estimated contrast、SE、df、CI 与 adjusted P；labels 应说清 comparison。

Fisher’s LSD 为什么可能过度发现差异

equal n：LSD=t₁₋α/₂,ν √(2MSE/n)

每一对 |ȳᵢ−ȳⱼ| 超过 LSD 就 reject。Unprotected LSD 直接做全部 pairwise t-tests，控制的是单个 comparison error，不保证 FWER。Protected LSD 先通过整体 ANOVA 再比较，提供有限 protection，不能一般地宣称对任何配置都强控制 FWER；课程多组 null simulation 说明 false positives 的风险。

Mean separation letters：没有共有字母表示对应 method 下拒绝 equal means；共有字母只表示未拒绝，不能说两组 biologically identical。字母也不是可传递关系：A 与 B 未拒绝，B 与 C 未拒绝，不保证 A 与 C 未拒绝。

让 correction 匹配你真正做的比较

Methodfamilyequal-n threshold
Tukey’s W / HSD全部 pairwiseq₁₋α(t,ν)√(MSE/n)
Dunnett’s D每处理对一个 controldα(t−1,ν)√(2MSE/n)
Scheffé’s S全部 possible contrasts√[(t−1)F₁₋α(t−1,ν)] × SE(L̂)
Bonferroni事先定义的 m testst₁₋α/(2m),ν × SE(L̂)

Studentized range q 不是 ordinary t。Unequal n 的 Tukey–Kramer pairwise threshold 为 q√[(MSE/2)(1/nᵢ+1/nⱼ)]；Dunnett 需相应 correlation structure。Scheffé 覆盖任意 post-hoc contrast，范围大，pairwise power 可能低。

课程 hardwood-floor heat example 用同一 MSE 比较 LSD、Tukey、Dunnett、Scheffé 的 conclusions；不能仅因 method 更严格，就说其科学结论更“真实”。先根据 family 选 method，再判断 evidence。

fit <- aov(y~treatment,data=d)
TukeyHSD(fit)
p.adjust(c(.008,.02,.04,.12),method='bonferroni')
# SAS: MEANS treatment / TUKEY DUNNETT('control') SCHEFFE;

先写 comparison，再看显著性

练习：五个 treatments 只关心各 treatment 与 control，应选哪一种 family？

有 4 个 control comparisons，而非全部 10 pairs。Dunnett 专门使用这些共享 control 的相关 comparisons；Bonferroni 也能对预定 4 tests 控制 FWER，但可能更保守。

练习：[1,1,−2] 与 [2,−1,−1] 是 orthogonal 吗？

Equal n 下乘积和=2−1+2=3，非 0；二者均是 contrast，却不 orthogonal。

Wood treatment 与 weed methods

Wood 四品牌的 planned coefficients 经 cell mean→μ+τ→SAS语法转换；weed methods 的 control、Bio1、Bio2、Chem1、Chem2 能写 control vs all agents [−1,.25,.25,.25,.25]，bio vs chem [0,.5,.5,−.5,−.5]。第二个 contrast 不回答每个药物相对 control 的问题。

Heat loss / flooring 与 null simulation

同一四组 floor数据用于 LSD、Tukey、Dunnett、Scheffé，差别来自 comparison family 与 critical value。20个真实相同 normal treatments 的 unprotected-LSD 模拟仍可能产生很多显著 pairs：有190pairs，不能拿 nominal .05 当作 family error。

Mean-separation letters

Sharing a letter 表示该 procedure 与 α 下未检出 pair difference，不能声称 means 相等。A组和B组不显著、B组和C组不显著，并不推出 A 与C 不显著；letters 本身不是排定实质效应大小的证据。
