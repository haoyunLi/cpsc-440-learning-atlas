独立 random variables 的 variance 会相加

比较两组，先把目标写成一个差：D=μ₁−μ₂。组别顺序要固定，例如 fresh−stored。正差表示第一组平均更大；如果交换顺序，估计值和单侧假设方向都要一起反转。

D̂=ȳ₁−ȳ₂；E(D̂)=μ₁−μ₂
独立样本：Var(D̂)=σ₁²/n₁+σ₂²/n₂

减法为什么没有使方差相减？均值告诉我们差的中心，方差描述两组抽样误差怎样波动。两组独立时，第一组偏高或偏低都可能使差发生变化，第二组也一样，因此两份不确定性相加。

例如两组各 n=25，σ₁=σ₂=10，各自均值的方差都是 100/25=4。差的方差是 4+4=8，所以 SE=√8≈2.828，而不是 0。若它们其实相关，正确公式还包含 −2Cov(ȳ₁,ȳ₂)，这正是后面的 paired analysis 要利用的信息。

先确定 estimand（目标量）：比较均值差、某种位置差，还是同一单位的配对变化？课程药物效力例的 fresh 与 stored 是两批独立样本，因此先按两组结构估计不确定性，再根据方差条件选择 pooled 或 Welch。

Pooled t-test 假定共同的 population variance

Pooled t-test 假定两组虽然均值可能不同，却共享同一个总体方差 σ²。既然两个样本方差都在估计同一个量，就可以合并信息；合并的是 variance，不能直接把两个 SD 取平均。

sₚ²=[(n₁−1)s₁²+(n₂−1)s₂²]/(n₁+n₂−2)
SE=sₚ√(1/n₁+1/n₂)
t=[(ȳ₁−ȳ₂)−D₀]/SE；df=n₁+n₂−2

权重 nᵢ−1 是每组方差估计的自由度。样本量较大的组通常提供更多方差信息。D₀ 是 null 指定的总体均值差，常设为 0，但也可以是其他科学基准。

  1. 原创例：n₁=n₂=5，两组均值为 12 和 10，样本方差都为 4。
  2. 合并方差：(4×4+4×4)/(5+5−2)=4，所以 sₚ=2。
  3. 算差的 SE：2√(1/5+1/5)=√1.6≈1.265。
  4. 检验 D₀=0：t=(12−10)/1.265≈1.581，df=8。
  5. 估计区间：95% critical t≈2.306，CI=2±2.306×1.265≈[−.917,4.917]。数据估计为正，但区间仍允许 0 或负差。

这个结果依赖独立实验单位、共同总体方差，以及用于精确 t 推断的正态条件。样本方差恰好接近，或小样本方差检验未显著，并不证明总体方差相等。没有合理依据时，下一节的 Welch 方法更适合直接保留两组各自的方差。

Welch t-test 不必强行共享 variance

如果两组波动程度不同，强行估一个共同方差可能掩盖真实的不确定性。Welch t-test 用各组自己的样本方差估计均值差的 SE，并用 Satterthwaite approximation 调整参考 t 分布的自由度。

a=s₁²/n₁，b=s₂²/n₂；SE=√(a+b)
ν≈(a+b)²/[a²/(n₁−1)+b²/(n₂−1)]
t=[(ȳ₁−ȳ₂)−D₀]/SE
  1. 例如 n₁=5、s₁²=4，n₂=8、s₂²=16，均值仍为 12 和 10。
  2. 两组对差方差的贡献为 a=4/5=.8，b=16/8=2；相加得到 2.8，因此 SE≈1.673。
  3. 代入自由度公式：ν=2.8²/[.8²/4+2²/7]≈10.719。它不是简单的总样本数减 2，也不必是整数。
  4. 检验 D₀=0 时 t=2/1.673≈1.195；用 tν 计算 P 或 CI，而不是换回 pooled 的 df。

Welch 保留了各组对误差的不同贡献，尤其适用于 unequal n 与 unequal variances 同时出现的情形。它仍要求观测之间独立，也不能自动解决重尾、异常值或错误实验单位问题。

课程通过改变样本量和 variance ratio 的模拟，展示不满足假设时实际 Type I error 可能偏离 α。选择方法应有设计和模型依据，不应从软件两行中挑 P-value 更小的一行。

完整 R 复现。 下列原创数据专门构造为上面的 n、mean 与 variance；它们不是课程案例的原始记录。复制整段即可从数据核对到检验输出。

# Constructed data matching the summary statistics above.
x <- c(10, 10, 12, 14, 14)
y <- c(4, 6, 8, 10, 10, 12, 14, 16)
rbind(x=c(n=length(x), mean=mean(x), variance=var(x)),
      y=c(n=length(y), mean=mean(y), variance=var(y)))
t.test(x, y, alternative="two.sided", mu=0)
# Pooled inference adds the equal-population-variance assumption.
t.test(x, y, alternative="two.sided", mu=0, var.equal=TRUE)

读 one-sided 和 two-sided output 要与 Hₐ 对齐

同一个 t statistic 可以对应不同尾部的 P-value，因为不同 Hₐ 对“更极端”的定义不同。读软件之前，先在纸上写差的顺序和假设方向。

对称 t 分布下，尾部与研究方向的对应
Hₐ需要的面积常见软件标签
D>D₀当前 t 的右侧，1−Fν(t)Pr>t
D<D₀当前 t 的左侧，Fν(t)Pr<t
D≠D₀两侧至少同样远离 0 的面积Pr>|t|

双侧 P=2×min(Fν(t),1−Fν(t))。只有较小的单侧面积应乘 2，不能拿任意一侧乘 2。若观察到正 t，左侧 P 很大、右侧 P 很小；预先研究负方向时，不能因为右侧小就宣布支持目标。

课程 notes 的 tapeworm 例比较 treated 与 control sheep 的寄生虫数。若定义 D=μtreated−μcontrol，治疗改善意味着虫数减少，Hₐ 应为 D<0。软件结果的符号、尾部和研究解释都围绕这个定义一致地写。

报告时说清楚比较对象、差的单位、估计值、CI、所用方法及 P。例如“按 treated−control 计算，估计虫数下降，左侧检验提供怎样的证据”。一行 Pr>|t| 数字本身不能替代这些解释。

Wilcoxon rank-sum 使用整体排序比较两组

若数据明显偏态，研究目标适合比较整体位置或分布，可考虑 Wilcoxon rank-sum / Mann–Whitney test。它把原数值改成合并排序后的 ranks，再看一个组是否倾向于占据更大的位置。

  1. 合并排序。 原创例 A=[1,4]、B=[2,3]，合起来是 1(A)、2(B)、3(B)、4(A)。
  2. 分配 ranks。 顺序对应 1、2、3、4；相同观测用它们占据位置的平均 rank。
  3. 累加指定组。 A 的 rank sum W=1+4=5；若软件报告 U，则 U=W−n₁(n₁+1)/2=5−3=2。
  4. 与 null 比较。 null 下两组分布相同，A 的期望 rank sum 为 n₁(N+1)/2=5。这里 W 正好在中心；更大或更小的 W 才支持对应的位置差异。
E(W)=n₁(N+1)/2；无 ties 时 Var(W)=n₁n₂(N+1)/12
有 ties 时 Var(W)=n₁n₂/12×[N+1−Σ(tⱼ³−tⱼ)/(N(N−1))]

N=n₁+n₂，tⱼ 是第 j 个 tied block 中相同值的数量。大样本可把 W 标准化成 Z，再根据条件使用 tie correction 和 continuity correction；小样本应核对 exact 或 permutation 的适用条件。

基本 null 是两个 distributions 相同。只有在共同形状、主要差别是 location shift 等条件下，才可进一步按中心位移解释。它不是对任意不同形状都“只检验 median 相等”，也仍然需要 independent observations。

课程 alcohol reaction-time 例用来讨论非正态数据及方法选择。Ranks 会舍去原单位的距离：1 到 2 与 3 到 4 都只差一个 rank。因此选这个方法，也是在选择一种不同于均值差的信息总结方式。

完整 R 复现。 这里直接使用本节 A=[1,4]、B=[2,3]，先算原始 rank sum，再读软件输出。数据没有 ties，因此可以用 exact 分布；这不是要求所有实际数据都强制设置 exact=TRUE。

# Reproduce the two-group ranking example above.
x <- c(1, 4)
y <- c(2, 3)
combined_ranks <- rank(c(x, y))
raw_rank_sum <- sum(combined_ranks[seq_along(x)])
u <- raw_rank_sum - length(x)*(length(x)+1)/2
c(raw_rank_sum=raw_rank_sum, U=u)
# No ties: enumerate the exact null distribution.
wilcox.test(x, y, alternative="two.sided", exact=TRUE,
            correct=FALSE)

Paired t-test 先把每对变成一个 difference

同一辆车在两家维修店的报价，或同一块地上的两个处理结果，会共享“这辆车/这块地本身”的背景。Paired analysis（配对分析） 先在每个 pair 内作差，让共享背景尽可能抵消，再把这些差当作一个样本。

Dᵢ=Yᵢ₂−Yᵢ₁；t=(D̄−D₀)/(sᴅ/√n)，df=n−1
CI=D̄±t₁₋α/₂,ₙ₋₁sᴅ/√n
Var(D)=σ₁²+σ₂²−2Cov(Y₁,Y₂)
  1. 固定减法方向。 下方原创实验用 B−A，五个配对差为 [1,2,3,2,2]。
  2. 算差的均值。 D̄=(1+2+3+2+2)/5=2。
  3. 算差的方差。 相对 2 的偏差是 [−1,0,1,0,0]，平方和为 2，所以 sᴅ²=2/(5−1)=.5。
  4. 算差的 SE。 √(.5/5)≈.3162；检验 D₀=0 时 t=2/.3162≈6.325，df=4。
  5. 回到设计。 同一 pair 中的两个值相关，但不同 pairs 仍须独立。正态条件看 differences，而不是要求 A、B 的边际分布各自都正态。

正 covariance 会降低差的方差，所以配对可以提高精度。下方故意反转配对的选项保留了两组各自均值，却改变 difference variance；这是解释 covariance 的演示，不是允许分析者挑选有利配对。

课程维修报价例中，不同车损害程度差异很大，独立分析把这些背景差异留在误差里；paired analysis 则先在同一辆车内比较。配对关系必须来自真实设计，不能事后为了得到更小 P-value 强行匹配。

完整 R 复现。 下列 before=A、after=B 是为复现上述五个 differences 构造的原创配对值；每一行索引代表同一 pair，不能单独重排某一组。

# Construct paired values with differences B - A = 1, 2, 3, 2, 2.
before <- c(10, 20, 30, 40, 50)
after <- c(11, 22, 33, 42, 52)
difference <- after - before
c(mean_difference=mean(difference), variance=var(difference),
  SE=sd(difference)/sqrt(length(difference)))
t.test(after, before, paired=TRUE, alternative="two.sided", mu=0)
# A one-sample test of the differences gives the same result.
t.test(difference, alternative="two.sided", mu=0)

Signed-rank 同时使用 direction 和 magnitude ranks

配对数据不一定适合正态 mean-difference 模型。Wilcoxon signed-rank test 保留每个差的方向，并用差的绝对大小排序；它比 sign test 多用了“哪个变化更大”的信息。

  1. 先按固定方向求 differences；若 null 指定 D₀，先减去 D₀。删去 zero differences，剩余数量记为 m。
  2. 按 |D| 排序，而不是直接按带符号的 D 排序。Ties 使用 average ranks。
  3. 把 rank 的正负方向带回来，分别加成 W⁺ 与 W⁻。
  4. 例如 D=[−3,1,2]，|D| 对应 ranks [3,1,2]；W⁺=1+2=3，W⁻=3，总和为 6。
  5. 根据软件报告的 statistic definition、tail 和 exact / approximation 条件求 P。
E(W⁺)=m(m+1)/4
Var(W⁺)=m(m+1)(2m+1)/24−Σ(tⱼ³−tⱼ)/48

tⱼ 是绝对差中 tied block 的大小；无 ties 时减去项为 0。W⁺+W⁻=m(m+1)/2，即使平均分配 tied ranks，rank 总和也应一致，可用来检查手算。

Signed-rank 的推断需要差分布对称等条件，使 null 下正负号与绝对大小的关系符合参考分布。若 differences 极不对称，且问题确实是 median，sign test 可能更适合；“非参数”不表示没有假设。

完整 R 复现。 原创 before/after 值生成本节的 D=[−3,1,2]。先核对 differences，再核对绝对差 ranks；这组数据没有 zero differences 或 tied absolute differences，因此适用此处的 exact 计算。

after <- c(7, 13, 16)
difference <- after - before
absolute_ranks <- rank(abs(difference))
c(W_plus=sum(absolute_ranks[difference > 0]),
  W_minus=sum(absolute_ranks[difference < 0]))
# No zero differences or tied absolute differences occur here.
wilcox.test(after, before, paired=TRUE, alternative="two.sided",
            exact=TRUE, correct=FALSE)

预算要分配给真正独立的单位

两组研究中的“n”最容易被误读。独立设计的 n 通常指每一组的数量；配对设计的 n 指 pairs 的数量。一个 pair 中有两次测量，但只有一个差。

独立、共同 planning σ、每组相同 n：
n≈2σ²(z₁₋α/₂+z₁₋β)²/Δ²
配对：n pairs≈σᴅ²(z₁₋α/₂+z₁₋β)²/Δ²

独立公式中的 2 来自 σ²/n+σ²/n。配对公式改用 difference variance σᴅ²，因为真正分析的是差。合理的 pairing 若减少 σᴅ²，就可能以更少实验单位达到相同精度或 power。

如果两组数量不一样，先写出 SE² 再规划。例如 n₂=r n₁、共同 σ²，则 SE²=σ²(1+1/r)/n₁，于是 n₁≈σ²(1+1/r)(z sum)²/Δ²，再求 n₂。课程 cattle-diet 例就是比较 equal 与 unequal allocation，而不是把两组数量随意相加。

若两组 planning variances 分别是 σ₁²、σ₂²，使用 σ₁²/n₁+σ₂²/n₂；equal n 的分子相应变成 σ₁²+σ₂²。想规划 CI 半宽 E 时，用 z critical，而不是 zα+zβ：paired n≈(z₁₋α/₂σᴅ/E)²；full width W 要先换成 E=W/2。

以上是 z 近似的规划。实际 t critical 与 df 随 n 改变，需迭代核对；还要考虑独立实验单位、测量成本、dropout 和 clustering。反复测同一株植物，不能直接当作增加独立 n。

练习：同一植物处理前后测量，应套哪种样本量公式？

先以植物为 pair，估计变化量 D 的 variance，再规划需要多少独立植物。若用独立两组公式，就忽略了两次测量共享的 covariance。更复杂时间结构需对应 repeated-measures model。

接下来把规划做完：等组与不等分配：逐步取整并核验实际 t power；配对设计：从边际 SD 与ρ得到差值 SD，再规划完整 pairs。两节都提供独立可运行 R，并检查目标 power 与前一个整数。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

新鲜与储存药物：独立样本的均值差

Fresh / stored drug potency 来自两个独立组，目标是 μFresh−μStored。先确认每个观测属于独立实验单位，再计算 difference 的 SE；因为两组独立，两项 sample-mean variances 在 SE² 中相加。

软件同时列出 pooled 与 Satterthwaite 输出时，两行对应不同的 variance 假设。共同 variance 有合理依据时才使用 pooled；允许两组 variance 不同时使用 Welch / Satterthwaite。不能看哪一行 P-value 更小，再决定采用哪一行。

绵羊绦虫：把“降低”翻译成同一方向

Class notes 独有的 sheep tapeworm 例比较 drug-treated sheep 与 control sheep。若定义差为 treated−control，虫数降低就对应 Hₐ:μTreated−μControl<0，应该读取左侧 P-value。

令 Fₜ 为参考 t 分布的 CDF，则同一个统计量 tcalc 的左侧 P 为 Fₜ(tcalc)，右侧 P 为 1−Fₜ(tcalc)，常用双侧 P 为 2×min{Fₜ(tcalc),1−Fₜ(tcalc)}。先确定 subtraction 与 Hₐ，三个输出才不会被混用。

反应时间、修车估价与草地：三种结构

Alcohol reaction time 例的两组参与者独立，使用合并后的整体 ranks 比较分布。Repair estimates 例则在同一辆车上获得两家 garage 的估价，先计算 garage1−garage2，再分析这些 paired differences。

Fertilizer 例把每块 field 分半施加两个处理，以 field 为配对单位；signed-rank 使用差的方向与绝对值的排名，并依赖相应的对称性条件。先辨认独立或配对结构，再决定是否求差；不能因为都出现 ranks，就把三种问题当作同一种检验。

牛饮食与不等分配：预算对应独立动物

Cattle diets 规划先指定最小有意义的 weight-gain difference，再给出共同的 planning variance。Equal n 中的 n 是每组独立动物数，不能把同一动物的多次测量重复计入。

若 n₂=m n₁，均值差的 variance 为 σ²/n₁+σ²/(m n₁)=σ²(1+1/m)/n₁。不等分配改变两组对 SE 的贡献；更多测量记录不一定意味着更多独立信息。

手算秩和是 8，R 为什么报告 W=2？

同一个 Wilcoxon rank-sum test，教材的 raw rank sum 和 R 的 statistic 标签可能不同。判断结果是否一致，要先核对它们的定义，再比较 p-value。

原创数据：A=[3,5,5]，B=[4,8,9]。研究事先指定 Hₐ：A 的分布相对 B 向左移动。两组独立，并在位置移动解释下假定形状和尺度可比较。

  1. Raw rank sum T_A=1+3.5+3.5=8；T_B=2+5+6=13。
  2. 总和 8+13=21，等于 N(N+1)/2=6×7/2，秩分配通过检查。
  3. R 两独立样本的 W 从 raw rank sum 中减去固定偏移 n_A(n_A+1)/2=6，因此 W=8−6=2。无 ties 时，这个偏移等于最小可达秩和；本例有 ties，三个最小秩是1、2、3.5，可达最小秩和为6.5，故最小 W 为0.5，不能把固定偏移6解释成本例的最小秩和。
  4. 在本例 null 下，E(T_A)=n_A(N+1)/2=10.5；E(W)=n_A n_B/2=4.5。两者相差同一个6，不改变离各自 null 中心的距离。

Ties 会改变参考方差。 两个5形成大小为2的 tied block。近似方差为：

Var(W)=n_A n_B/12 × [N+1−Σ(tⱼ³−tⱼ)/(N(N−1))]
=9/12 × [7−(2³−2)/(6×5)]=5.1

a <- c(3,5,5)
b <- c(4,8,9)
# R reports the shifted rank sum for two independent samples.
r <- rank(c(a,b), ties.method="average")
raw_sum <- sum(r[seq_along(a)])
c(raw_rank_sum=raw_sum, W=raw_sum-length(a)*(length(a)+1)/2)
# Specify the approximation and correction to make output reproducible.
wilcox.test(a,b, alternative="less", exact=FALSE, correct=FALSE)

Signed-rank 的 exact p：五个差值为什么有32种符号排列？

从 signed ranks 得到 p-value，还需要知道 null 下哪些结果可能出现，以及每一种结果有多大概率。一个只有五个独立配对差的例子，就能把这一步完整列出来。

原创数据按 after−before 定义为 d=[−1,2,3,4,5]。研究预先指定 Hₐ：差分布的位置大于0。用于本例精确参考的 H₀ 是：差值相互独立，并来自关于0对称的连续分布。仅仅说 median=0，不足以保证下面的 signed-rank 参考分布。

  1. 固定五个绝对大小。 对称null使每个非零差为正或负的条件概率各为1/2；独立差使这些符号独立。
  2. 列出可能结果。 五个位置各有两种符号，所以有2⁵=32种等可能的符号排列。每一种概率都是1/32。这不是重新排列五个对象的5!种顺序。
  3. 找至少同样极端的结果。 W⁺≥14只有两种：所有秩为正，W⁺=15；只有秩1为负，其余为正，W⁺=14。
  4. 求右尾概率。 exact p=2/32=.0625。在预定α=.05下，证据不足以拒绝对称null。
右侧 p=P(W⁺≥14 | symmetric null)=.0625
对称参考下的双侧 p=2×.0625=.125

“五个差中四个为正”本身不是 signed-rank 的全部信息。如果唯一的负差具有最大的绝对大小，W⁺就会减小。本方法同时保留方向和绝对差的排名；sign test 只统计正号个数，因此两个检验的 p 不必相同。

d <- c(-1,2,3,4,5)
# This exact example has no zero differences and no tied magnitudes.
stopifnot(all(d != 0), !anyDuplicated(abs(d)))
r <- rank(abs(d))
observed_w <- sum(r[d > 0])
# Enumerate all 2^m sign assignments under the symmetric null.
signs <- as.matrix(expand.grid(rep(list(c(-1,1)),length(d))))
null_w <- as.vector((signs > 0) %*% r)
p_right <- mean(null_w >= observed_w)
p_two <- min(1,2*min(mean(null_w <= observed_w),p_right))
c(W_positive=observed_w, assignments=nrow(signs),
  p_right=p_right, p_two=p_two)
# R calls the positive signed-rank sum V.
wilcox.test(d,mu=0,alternative="greater",exact=TRUE,correct=FALSE)

两独立样本规划：从每组人数到不等分配的实际 power

样本量不是从最终 P-value 倒推的数字。先固定研究目标、分析模型、最小有意义效应 Δ、α 与目标 power，再决定收集多少独立单位。本例原创情境是比较两套温室灌溉方案的平均生长量；在收集数据前，把 Δ=.5 cm 作为希望检出的真实均值差，规划共同总体 SD=.8 cm，双侧 α=.05，目标 power=.90。

分析模型： 两组独立，每组内的实验单位独立；响应服从正态总体，且两个总体具有共同 variance。最终使用 pooled two-sample t-test。这里的 .8 是规划假定，不表示分析时知道真实 σ；若来自先导实验的 s，应考虑它的不确定性。若预定分析是异方差 Welch 检验，这个共同方差功效公式不能直接称为其精确 power。

等组设计：从近似人数走到实际 t power

先规定 n₁=n₂=n，因此 n 是每组独立单位数。用完整精度的 normal quantiles，z₁₋α/₂=1.959964、z₁₋β=1.281552：

n≈2σ²(z₁₋α/₂+z₁₋β)²/Δ²
=2×.8²×(1.959964+1.281552)²/.5²
≈53.798006 → 每组54

课件使用 z≈1.96、1.28，得到约53.74，也向上取整到54。这个差异只是中间数值的精度；更重要的是，该公式是 z 近似。实际 pooled t 的门槛和非中心参数为：

ν=n₁+n₂−2；λ=Δ/[σ√(1/n₁+1/n₂)]
c=t₁₋α/₂,ν
power=P(Tν,λ<−c)+P(Tν,λ>c)

Tν,λ 表示 alternative 下的 noncentral t。两个尾部都属于预先设定的双侧拒绝域。逆求得到每组连续解 n≈54.776398，向上取整后需要每组55，总计110个独立单位；再检查54是否不足。

不等组设计：先定义整数分配规则

假设第二套方案需要较多独立单位，规划 n₂≈1.4n₁。先把方差写清楚：SE²=σ²(1/n₁+1/n₂)≈σ²(1+1/1.4)/n₁，所以 z 近似为：

n₁≈σ²(1+1/1.4)(z₁₋α/₂+z₁₋β)²/Δ²≈46.112577
n₁=ceil(46.112577)=47
n₂=ceil(1.4×47)=66

ceil 表示向上取整。第二步必须使用已经取整的 n₁。这里预先接受的整数规则是 n₂=ceil(1.4n₁)，所以实际比例66/47≈1.4043；程序对这个规则下的所有较小候选 n₁逐一计算 t power，得到47/66是最先达标的组合。不能把 power.t.test(type="two.sample") 的等组结果当成不等组解。

若实验要求比例严格等于7:5，允许的组合则是 n₁=5k、n₂=7k。本例最先达标的是50/70，power≈.917405；这与允许向上取整到约1.4倍是两个不同的设计约束。在共同方差、单位成本相同的条件下，等组分配通常更有效率；较多地分配给第二组需要对应额外的研究目标或成本理由。

alpha <- .05
target_power <- .90
delta <- .5
sigma_plan <- .8
allocation_ratio <- 1.4
z_sum <- qnorm(1-alpha/2)+qnorm(target_power)
# Normal approximations provide starting values, not exact t-test power.
n_equal_z <- 2*sigma_plan^2*z_sum^2/delta^2
n1_ratio_z <- sigma_plan^2*(1+1/allocation_ratio)*z_sum^2/delta^2
# This model assumes independent normal groups with a common population SD.
power_two <- function(n1,n2) {
  df <- n1+n2-2
  ncp <- delta/(sigma_plan*sqrt(1/n1+1/n2))
  critical <- qt(1-alpha/2,df=df)
  pt(-critical,df=df,ncp=ncp)+
    pt(critical,df=df,ncp=ncp,lower.tail=FALSE)
}
# The returned n is the number in each group, not the total.
equal_plan <- power.t.test(n=NULL,delta=delta,sd=sigma_plan,
                          sig.level=alpha,power=target_power,
                          type="two.sample",alternative="two.sided",
                          strict=TRUE,tol=1e-10)
n_equal <- ceiling(equal_plan$n)
equal_check <- data.frame(n1=c(n_equal-1,n_equal),
                          n2=c(n_equal-1,n_equal))
equal_check$power <- mapply(power_two,equal_check$n1,equal_check$n2)
# Define the integer allocation rule before searching the candidate designs.
ratio_check <- data.frame(n1=2:200)
ratio_check$n2 <- ceiling(allocation_ratio*ratio_check$n1)
ratio_check$power <- mapply(power_two,ratio_check$n1,ratio_check$n2)
first <- which(ratio_check$power>=target_power)[1]
ratio_plan <- ratio_check[first,]
print(c(normal_equal=n_equal_z,normal_ratio_n1=n1_ratio_z,

print(equal_check)
print(ratio_check[c(first-1,first),])
# An exact 7:5 ratio is a different integer constraint.
k <- 1:100
exact_ratio <- data.frame(n1=5*k,n2=7*k)
exact_ratio$power <- mapply(power_two,exact_ratio$n1,exact_ratio$n2)

print(exact_ratio[exact_first,])

                            alternative="two.sided",strict=TRUE)$power
stopifnot(n_equal==55,
          equal_check$power[1]<target_power,
          equal_check$power[2]>=target_power,
          abs(helper_power-power_two(n_equal,n_equal))<1e-12,
          ratio_plan$n1==47,ratio_plan$n2==66,
          all(ratio_check$power[seq_len(first-1)]<target_power),
          exact_ratio$n1[exact_first]==50,
          exact_ratio$n2[exact_first]==70)

配对样本量规划：差值 SD、相关性与完整 pairs

配对设计把每个单位的两次测量变成一个差值。因此，规划的关键不只是“需要多少对”，还包括差值会有多大波动。原来的两列 SD 不够；同一对内的 correlation 也会改变差值的 variance。

原创情境：比较独立仪器在调整程序前后的读数，定义 D=after−before。预先检验 H₀:μD=0 对 Hₐ:μD≠0，双侧 α=.05；指定值得发现的真实均值差 Δ=.5 units，目标 power=.90。假定不同仪器的 pairs 独立、差值 D 服从正态总体。规划 before 和 after 的总体 SD 都为 .8，同一仪器前后的相关性为 ρ=.6。这些是收集数据前的效应和变异假定，不是从显著结果反推的输入。

先把边际变异换成差值变异

Var(D)=σafter²+σbefore²−2Cov(after,before)
=σafter²+σbefore²−2ρσafterσbefore
=.8²+.8²−2×.6×.8×.8=.512
σD=√.512≈.715542

target_power <- .90
delta <- .5
sd_before <- .8
sd_after <- .8
rho_plan <- .6
sd_difference <- function(rho) {
  sqrt(sd_before^2+sd_after^2-2*rho*sd_before*sd_after)
}
# n counts independent pairs; sd_d describes within-pair differences.
power_paired <- function(n,sd_d) {
  df <- n-1
  ncp <- delta*sqrt(n)/sd_d
  critical <- qt(1-alpha/2,df=df)
  pt(-critical,df=df,ncp=ncp)+
    pt(critical,df=df,ncp=ncp,lower.tail=FALSE)
}

把20种组标签分配变成精确左尾概率

Signed-rank遇到零差与ties：W、S、exact与近似

无ties的五差值exact示例已经解释2ᵐ种符号排列。本节处理课程草地例中实际会出现的两件事：零差改变有效m，重复绝对差改变秩与参考分布。仍使用一份可以全部列出的原创小数据，不需要课件的整份草地观测。

预先定义after−before，六个独立pairs给出d=[0,−1,2,2,3,4]。研究指定右侧alternative：差分布位置大于0。条件精确参考要求null下差分布关于0对称；固定非零绝对大小后，各符号独立且以1/2概率为正。记录或舍入机制也应保留该正负对称性，单凭median=0并不够。

  1. 固定五个非零秩。 对[1,2.5,2.5,4,5]枚举2⁵=32种符号分配，每种概率1/32。两个2.5仍属于两个不同的pairs，不能合并掉它们的符号机会。
  2. 找右尾边界。 W⁺≥14只有两个分配：全正得到15；只有rank 1为负得到14。Exact右尾P=2/32=.0625。
  3. 转换双侧规则。 对称参考下采用双倍较小尾部，双侧P=.125。原假设和alternative必须先定，不能因为右尾更小就在读完结果后更换检验。
