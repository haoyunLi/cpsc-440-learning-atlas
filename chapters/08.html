把每个观测写成背景、处理与误差

比较三种肥料时，逐对重复 t-test 不仅繁琐，还会扩大一整组比较中的误报概率。One-way ANOVA 先问一个整体问题：这些总体均值是否全都相同？

Completely Randomized Design（CRD，完全随机设计） 把 treatments 随机分配给适合的独立实验单位。One-way 指这里用一个处理因素描述组间差别，不表示研究只能测一个观测。

Yᵢⱼ=μ+τᵢ+εᵢⱼ；Στᵢ=0
εᵢⱼ independent Normal(0,σ²)

i 标识 treatment group，j 标识组内单位。μ 是等权 baseline，τᵢ 是该组相对 baseline 的偏移，εᵢⱼ 是同处理下仍未解释的 variation。组总体均值是 μᵢ=μ+τᵢ；Στᵢ=0 是让参数表示唯一的一种约束。

例如三组均值为 5、8、11，可写 μ=8，τ=[−3,0,3]。在第一组测到 Y=6，则它比该组均值高 1，误差部分为 1。模型因此把背景中心、处理差异和个体误差分开。

H₀:μ₁=…=μt；Hₐ 是至少一个均值不同，不是“所有组两两不同”。精确 F-test 需要独立误差、共同方差和正态条件。随机分配有助于处理比较，但不会把一盆内十片叶子变成十个独立处理重复。

一项偏差拆成 treatment signal 与 residual

ANOVA 的关键不是表格，而是把每个观测的总偏离拆成两段。先从 grand mean 走到 group mean，再从 group mean 走到观测值：

Yᵢⱼ−ȳ..=(ȳᵢ.−ȳ..)+(Yᵢⱼ−ȳᵢ.)

第一段是组均值相对整体的偏移，反映 treatment signal；第二段是同组单位之间的 residual，反映未解释的 noise。例如 grand mean=8、A组 mean=5，观测 Y=4 的总偏差 −4 可写成 −3+(−1)。

平方后，单个观测会有 cross-term，不能把每个平方随意拆开。但在一组内，residuals 相加为 0，所以加总所有观测后，cross-terms 消失，得到：

SST=ΣᵢΣⱼ(Yᵢⱼ−ȳ..)²
SStrt=Σᵢnᵢ(ȳᵢ.−ȳ..)²
SSE=ΣᵢΣⱼ(Yᵢⱼ−ȳᵢ.)²
SST=SStrt+SSE

ȳ.. 是所有 N 个观测的均值；各组样本数不相等时，按 nᵢ 加权，不能直接平均 group means。SStrt 把一个组的中心偏差按该组数量重复计算；SSE 则逐个使用组内偏差。

从平方和到平均平方，再到 F
来源自由度Mean square
Treatmentt−1MStrt=SStrt/(t−1)
ErrorN−tMSE=SSE/(N−t)
TotalN−1不用于分母

MS=SS/df，把不同数量的信息变成可比较的方差尺度。F=MStrt/MSE：null 下二者都估计同一 σ²；组总体均值不同则通常使分子增加。每组估计一个 mean，形成一个 residual-sum=0 约束，因此 error df 为 N−t。

一个完整的小型 ANOVA 计算

用完整的小例子把公式连起来。原创数据 A=[4,5,6]、B=[7,8,9]、C=[10,11,12]，三组各 3 个独立单位，N=9、t=3。

  1. 计算中心。 A均值为 5，B为 8，C为 11；全部总和为 72，所以 grand mean=72/9=8。
  2. 计算 between-group SS。 三组中心相对 8 的偏差是 −3、0、3，各重复 3 次：SStrt=3×9+3×0+3×9=54。
  3. 计算 within-group SS。 每组相对自己均值的偏差都是 [−1,0,1]，每组贡献 1+0+1=2，所以 SSE=6。
  4. 核对总量。 SST=54+6=60；也可以逐个把 Y−8 平方后加总，结果应一致。
  5. 除以 df。 Treatment df=2，error df=6，total df=8；MStrt=54/2=27，MSE=6/6=1。
  6. 计算与解释。 F=27/1=27，参考 F(2,6)，右侧 P=.001。在 α=.05 时拒绝总体均值全相同。

为什么看右尾？大的 F 表示组间中心差异相对于组内噪声更大，小 F 不支持这类偏离。整体拒绝仍不能告诉我们哪两组不同；下一单元会按具体问题安排 contrasts 和 comparisons。

下方实验分别改变 group separation 和 within-group noise。先把 noise 保持不变再增加组间差异，观察分子；再固定均值、增加 noise，观察分母。只有分清两者，才能解释相同均值差在不同实验中为何给出不同证据。

用 residuals 检查模型的条件，而非混合 raw data

得到 F 与 P 之后，仍要确认它们所依赖的模型是否合理。Residual（残差） 是 e=Y−ŷ；one-way 模型的 fitted value 是对应 group mean。诊断应主要看 residuals，因为我们已经允许不同 treatments 有不同中心。

把三组 raw values 混在一起，分布可能多峰，即使每组误差都正态。直接对这团 raw data 做 QQ plot，并不能正确回答 ANOVA 的 error normality 问题。

  1. 先查独立性。 根据随机化、实验单位和时间/空间结构判断。QQ plot 无法识别同盆测量被错当独立重复。
  2. 看 residual vs fitted。 围绕 0 的散布是否随 fitted mean 增大而变宽？Funnel 形状提示 constant variance 可能不合理。
  3. 看 normal QQ plot。 比较残差的 quantiles 与 normal theoretical quantiles，重点看系统弯曲和尾部偏离，而不是要求每点都在直线上。
  4. 结合组图与检验。 Brown–Forsythe 可以补充分散检查；Shapiro–Wilk 的 P 值需要与图和样本量一起读。

小样本的诊断检验可能漏掉明显问题，大样本又可能检出很小的偏离。因此不存在“P>.05，假设已证明”的自动通行证。课程 leaf phosphorus 与 psychology students 例把输出、残差图和检验放在一起，目的就是让推断与模型条件相互核对。

完整 R 复现。 重新定义上一节 A=[4,5,6]、B=[7,8,9]、C=[10,11,12] 的九个原创观测，因此这段代码可直接单独运行，不需要事先创建 d。group 是处理标签，y 是响应。

# Reproduce the nine observations in the preceding ANOVA example.
d <- data.frame(group=factor(rep(c("A", "B", "C"), each=3)),
                y=c(4, 5, 6, 7, 8, 9, 10, 11, 12))
fit <- aov(y ~ group, data=d)
summary(fit)
data.frame(d, fitted=fitted(fit), residual=residuals(fit))
par(mfrow=c(1, 2))
plot(fitted(fit), residuals(fit), xlab="Fitted group mean",
     ylab="Residual", main="Residuals vs fitted")
abline(h=0, lty=2)
qqnorm(residuals(fit))
qqline(residuals(fit))
par(mfrow=c(1, 1))

Kruskal–Wallis 通过 ranks 比较多个 distributions

Kruskal–Wallis test 把前面的 rank-sum 思路扩展到多个独立组：合并排序后，比较各组是否系统性占据更高或更低的 ranks。

  1. 把全部 N 个观测一起排序；ties 用 average ranks。
  2. 分别加出第 i 组 rank sum Rᵢ，并记录 nᵢ。
  3. 将 Rᵢ²/nᵢ 相加，代入 H 的公式；各组平均 rank 差距大时，H 通常更大。
  4. 大样本用 χ²(t−1) 的右尾求 P；有 ties 时先除以 correction C，小样本核对 exact/permutation 方法。
H=12/[N(N+1)]×Σ(Rᵢ²/nᵢ)−3(N+1)
C=1−Σ(tⱼ³−tⱼ)/(N³−N)；Hcorrected=H/C

tⱼ 此处是某个 tied block 的大小，不是组数。全体 ranks 的总和应为 N(N+1)/2，可用来检查排名是否遗漏。

基本 null 为各组 distributions 相同；只有共同形状和 location-shift 等条件支持时，才可解释为位置差。它不是自动修复 unequal variances 的 ANOVA，也不能在不说明的情况下把“均值问题”换成“分布问题”。

若研究目标仍是 means，但组方差不同，可以考虑 Welch ANOVA。选择时先说目标，再说数据结构与假设，最后选方法：

完整 R 复现与方法对照。 仍使用前面的九个原创观测，并重新录入数据。这里比较预先说明的两种方法如何使用同一数据；实际研究应先选定目标与方法，不能看哪行 P 更小再决定。

# Use the same nine original observations as the ANOVA example.
d <- data.frame(group=factor(rep(c("A", "B", "C"), each=3)),
                y=c(4, 5, 6, 7, 8, 9, 10, 11, 12))
d$rank <- rank(d$y)
aggregate(rank ~ group, data=d, FUN=sum)
kruskal.test(y ~ group, data=d)
# Welch ANOVA keeps the population-mean target and estimates separate variances.
oneway.test(y ~ group, data=d, var.equal=FALSE)

三组 rank sums 为 6、15、24，Kruskal–Wallis 得 H=7.2、df=2、χ² 近似 P≈.02732；每组 n=3 很小，这里的近似只用于学习输出，实际小样本应评估 exact/permutation 路线。Welch ANOVA 得 F≈23.14286、df≈(2,4)、P≈.006327，检验的是总体 means。它与 ranks 检验的目标、参考分布不同。加权均值与自由度的完整计算见Welch ANOVA 数值推导。

小样本有 ties：从平均秩到 1,680 种标签分配

前例每组只有三个观测，kruskal.test 输出的是 χ² 近似 P。现在把“核对 exact/permutation”变成可独立运行的计算：保留前例 A=[4,5,6]、B=[7,8,9]、C=[10,11,12]，再增加一组原创 ties 数据 A=[1,1,2]、B=[2,3,4]、C=[4,5,5]。两例都固定三组各三个独立单位，研究在看数据前选定整体分布比较。

先确认允许怎样排列。 条件零假设是三组具有相同分布；在独立、可交换的观测模型下，给定合并观测与组大小，组标签可重新分配。每个单位仍是独立记录，相同数值不会合并成一个单位。仅有三个 median 相等不足以保证可交换性；有 pairs、blocks 或其他分配限制时，不能照用这里的任意分组。

  1. 核对 ranks 与组和。 R_A=6.5、R_B=15、R_C=23.5，总和45=N(N+1)/2。不能在各组内单独排名，否则每组三个秩都会变成1、2、3，组间信息被删除。
  2. 先求未校正的 H。 H=12/(9×10)×(6.5²/3+15²/3+23.5²/3)−3×10≈6.422222。
  3. 再按 pooled ties 修正。 值1、2、4、5各出现两次，值3出现一次，所以 Σ(tⱼ³−tⱼ)=4×(2³−2)=24，C=1−24/(9³−9)=29/30。得到 H′=H/C≈6.643678；不是 H×C。值2与4的 ties 跨组，仍必须计入。
  4. 明确 χ² 输出的含义。 df=组数−1=2，近似 P=P(χ²₂≥6.643678)≈.0360864。平均秩与 C 已处理 ties，但它们不会把每组三个观测的 χ² 近似自动变成精确分布。

为什么是 1,680 种，而不是把不同 H 去重？

先从九个记录选三个归 A，再从剩下六个选三个归 B，余下三个归 C，共 C(9,3)×C(6,3)=84×20=1,680 种固定组规模的分配。每一种在给定零假设下等概率；两个相同数值的记录换标签，可以产生同一个 H，却仍占两份分配机会。不能将统计量取值去重后等权计数。

每次保留同一组 pooled ranks，只重新相加三组 rank sums。由于组大小和 pooled ties 固定，C 对所有分配也相同。枚举全部分配后，数出 H′≥观测 H′ 的个数，包括恰好等于观测统计量的边界；尾部个数除以1,680，就是这套条件排列检验的 exact P。

无 ties 例的最极端结果是三组分别占据连续的低、中、高三个秩块；三个组名有3!=6种安排。ties 例在边界数值2与4处各有两条可交换记录，所以同样的最大 H′ 可由6×2×2=24种分配产生。代码不依赖这个捷径，而是逐一检查所有分配。

两例在预定 α=.05 下，近似与 exact 都拒绝相同分布零假设，但 P 的数值差距明显。这不说明 exact 总比近似小，也不支持事后挑选较小 P。Exact 表示按本例的有限条件参考完整计算；模型、独立单位与可交换性仍必须成立。

“H 的右尾”不是某个组更大的单侧结论

H 将各组平均秩偏离总体平均秩的程度平方后汇总，所以只在 H 较大时拒绝。将 A、C 组名交换后，H′和 P 完全不变：统计量的右尾并未保存“A<B<C”的科学方向。整体拒绝只提供并非三组分布全部相同的证据，不证明每一对都不同，也不能在任意形状差异下直接改称 mean 或 median 都不同。若需要具体成对或有序方向结论，应另行预先定义对应比较和误差控制。

代码用双倍秩避免平均秩的半整数边界问题。对本节固定的3+3+3结构，令 S=Σ(2Rⱼ)²，则 H=S/90−30；S是小整数，比较 S≥S_observed 与比较 H′≥H′_observed 完全等价。这个90只适用于本例组大小，不能复制到不同设计。若全部九个值都相同，则 C=0，标准 H/C 未定义；程序会停止并解释，不能把0/0当成有效检验结果。

# This teaching function is intentionally limited to three groups of size three.
kw_three_exact <- function(groups) {
  stopifnot(is.list(groups),length(groups)==3,
            all(lengths(groups)==3),all(is.finite(unlist(groups))))
  y <- unlist(groups,use.names=FALSE)
  group <- factor(rep(c("A","B","C"),each=3))
  N <- length(y)
  ranks <- rank(y,ties.method="average")
  doubled_ranks <- 2*ranks
  rank_sums <- as.numeric(tapply(ranks,group,sum))
  # Count equal numeric values directly, without converting them to labels.
  tie_sizes <- rle(sort(y))$lengths
  correction <- 1-sum(tie_sizes^3-tie_sizes)/(N^3-N)
  if (correction<=0) stop("All observations are tied: H/C is undefined.")
  raw_H <- 12/(N*(N+1))*sum(rank_sums^2/3)-3*(N+1)
  corrected_H <- raw_H/correction
  # With fixed sizes 3,3,3, S=sum((2*R_j)^2) and H=S/90-30.
  # Integer scores avoid floating-point ambiguity when including an equal boundary.
  observed_score <- sum((2*rank_sums)^2)
  expected_allocations <- choose(9,3)*choose(6,3)
  null_scores <- numeric(expected_allocations)
  allocation <- 0L
  for (A in combn(seq_len(N),3,simplify=FALSE)) {
    remaining <- setdiff(seq_len(N),A)
    for (B in combn(remaining,3,simplify=FALSE)) {
      C <- setdiff(remaining,B)
      allocation <- allocation+1L
      doubled_sums <- c(sum(doubled_ranks[A]),sum(doubled_ranks[B]),
                        sum(doubled_ranks[C]))
      null_scores[allocation] <- sum(doubled_sums^2)
    }
  }
  extreme <- sum(null_scores>=observed_score)
  exact_P <- extreme/allocation
  approx_P <- pchisq(corrected_H,df=2,lower.tail=FALSE)
  # Re-ranking pooled ranks is equivalent and avoids old R decimal-label merging.
  reference <- kruskal.test(split(ranks,group))
  stopifnot(allocation==1680,sum(rank_sums)==45,
            all(doubled_ranks==round(doubled_ranks)),
            abs(raw_H-(observed_score/90-30))<1e-12,
            abs(corrected_H-unname(reference$statistic))<1e-12,
            abs(approx_P-reference$p.value)<1e-12)
  list(rows=data.frame(record=seq_len(N),group=group,y=y,rank=ranks),
       summary=data.frame(R_A=rank_sums[1],R_B=rank_sums[2],R_C=rank_sums[3],
         C=correction,H=raw_H,H_corrected=corrected_H,df=2,
         chi_square_P=approx_P,extreme=extreme,allocations=allocation,
         exact_P=exact_P),
       score_frequency=as.data.frame(table(null_scores)),
       null_scores=null_scores)
}

Transformation 改变分析尺度，也改变问题

有些响应越大，波动也越大。Transformation（变量变换）尝试换一个尺度，使误差结构更适合模型；它同时也改变了结果的解释。因此不能只找让 P-value 最小的变换。

例如原单位上 10→20 与 100→110 都增加 10，比例却不同。Log scale 把倍数变化转成差：log(20)−log(10)=log(2)。在 log scale 上比较 means，回答的是变换后响应的中心差，不自动等价于原尺度 arithmetic means 的检验。

由 mean–variance pattern 选择候选尺度
原尺度关系候选变换需要检查
Var(Y)≈kμ√Y；小值例也可考虑 √(Y+3/8)非负，低值与零附近的近似
Var(Y)≈kμ²log Y正数，比例解释与零值处理
Var(Y)≈kμ⁴1/Y不能为 0，数值顺序会反转
Delta method：Var[g(Y)]≈[g′(μ)]²Var(Y)

以 log 为例，g′(μ)=1/μ；若原方差约 kμ²，变换后近似方差为 (1/μ²)×kμ²=k。这说明尺度选择如何抵消与均值有关的波动，而不是“取 log 通常更好”的经验口号。

Notes 的 proportion transform 是 g(p)=arcsin√p。固定 denominator m 时 Var(p)=p(1−p)/m，导数为 1/[2√(p(1−p))]，所以近似 variance 为 1/(4m)。靠近 0/1 或 denominator 不同，这个简单稳定性结果就不能随意推广。

Box–Cox 用 gλ(y)=(yλ−1)/λ，λ→0 对应 log y，要求 y>0。选择 λ 后要重新拟合、重新看 residuals，并明确尺度。课程 Gulf oxygen consumption、laughing-gas 和 notes 的 IBS scores 例就是对照 raw、sqrt、log 后的诊断。Count 或 proportion 也可用对应 generalized models，让 denominator 等结构直接进入模型。

把变换后的中心带回原单位：先辨认估计对象

课程 Gulf oxygen 例实际使用 T=√(Y+3/8)，即 √(Y+.375)。这个平移量也是变换定义的一部分，复现与回变换都应保留。变换后模型比较 E(T)，把这个中心平方再减 3/8，得到的是 [E(T)]²−3/8；它通常不是 E(Y)。

原创五个正响应为 .625, 3.625, 8.625, 15.625, 24.625。取 √(Y+.375) 后恰好是 1,2,3,4,5，因此 T̄=3，sample variance sT²=10/(5−1)=2.5。

  1. 先看直接回变换。 T̄²−.375=9−.375=8.625。
  2. 再直接计算原始 arithmetic mean。 五个原值总和为 53.125，所以 Ȳ=53.125/5=10.625。两者相差 2，不能称为同一个 mean。
  3. 找回被丢掉的二阶矩。 因为 Yi=Ti²−c，所以 Ȳ=mean(T²)−c=T̄²+[(n−1)/n]sT²−c。本例为 9+(4/5)×2.5−.375=10.625。
  4. 区分样本恒等式与总体参数。 总体上 E(Y)=Var(T)+[E(T)]²−c。样本公式中的 (n−1)/n 来自 sample variance 使用 n−1；不能在总体公式中加入这个样本修正，也不能在样本回算时遗漏它。
# Original observations; retain the shift used by the transformation.
y <- c(.625, 3.625, 8.625, 15.625, 24.625)
shift <- 3/8
transformed <- sqrt(y+shift)
n <- length(y)
naive_back_transform <- mean(transformed)^2-shift
recovered_sample_mean <- mean(transformed)^2 +
  (n-1)/n*var(transformed)-shift
data.frame(y=y, transformed=transformed)
c(mean_transformed=mean(transformed), variance_transformed=var(transformed),
  back_transformed_center=naive_back_transform,
  recovered_sample_mean=recovered_sample_mean, observed_sample_mean=mean(y))

这个恒等式用于解释尺度，并不证明该变换已改善 normality 或 constant variance。若目标是总体 arithmetic mean，还需对包含 variance 的目标量进行适当估计和推断；不能把“回算当前样本均值”当作已经获得总体 mean 的 CI。

Log-normal：同一组数据中的三个 mean 与一种明确的 CI

另一组原创正数据由 Y=exp(Z) 定义，六个 log values 为 1.6,1.8,2.0,2.2,2.4,2.6。假定独立 Z=log(Y) 来自 Normal(μlog,σlog²)，则 geometric mean 与 median 都是 exp(μlog)，而 arithmetic mean 是 exp(μlog+σlog²/2)。例如 μlog=log(10)、σlog²=.36 时，前者为 10，后者约 11.9722。

  1. 在 log scale 估计。 本组 Z̄=2.1，sZ²=.14，SE(Z̄)=√(.14/6)≈.1527525。df=5，95% t critical≈2.570582。
  2. 先构造 μlog 的 CI。 2.1±2.570582×.1527525≈[1.707337,2.492663]。
  3. 通过单调指数变换得到 geometric-mean CI。 估计为 exp(2.1)≈8.166170，区间为 [exp(1.707337),exp(2.492663)]≈[5.514258,12.093436]。在此 log-normal 模型下，它也是 median 的 CI。
  4. 单独识别 arithmetic mean。 当前六个 Y 的 arithmetic sample mean≈8.650611；log-normal 的代入估计 exp(Z̄+sZ²/2)=exp(2.17)≈8.758284。这是使用两个估计参数得到的模型均值估计，并非有限样本下的精确无偏估计。
# Original positive data, fully specified on the log scale.
y <- exp(c(1.6, 1.8, 2.0, 2.2, 2.4, 2.6))
z <- log(y)
mu_ci <- t.test(z, conf.level=.95)$conf.int
geometric_estimate <- exp(mean(z))
geometric_ci <- exp(mu_ci)
# This is a plug-in arithmetic-mean estimate, not an arithmetic-mean CI.
arithmetic_plugin <- exp(mean(z)+var(z)/2)
data.frame(y=y, log_y=z)
c(mean_log=mean(z), variance_log=var(z),
  geometric_mean=geometric_estimate,
  observed_arithmetic_mean=mean(y), arithmetic_plugin=arithmetic_plugin)

区间标签不能换。 上面的 [5.5143,12.0934] 不应标为原尺度 arithmetic-mean CI。Arithmetic mean 同时依赖 μlog 与 σlog²；把 log-mean CI 的两个端点直接 exp，或者都加上同一个估计的 sZ²/2 再 exp，都没有自动计入未知 variance 的估计不确定性。这里仅提供 geometric mean/median 的对应区间。

比较两组时，exp(μlog,B−μlog,A) 总是 geometric means 的比。在额外的 log-normal 且两组 log variance 相同的模型下，variance 项会在 arithmetic-mean ratio 中抵消，这个比才也等于 arithmetic means 的比；两组 log variances 不同时则需保留它们的差。对含零值的 log(Y+c)，得到的首先是 Y+c 的变换后目标，不能随意给 c 后继续解释为 Y 的同一个倍数效应。

整体问题与 follow-up 问题需要分开

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

F很大，是否意味着实际生产中的差异很大？

先拆开F的分子和分母：稳定的小差异也可能相对噪声很大。再报告原单位 mean differences、CI 与科学阈值。最后区分证据强度和实质效应大小；单个F不能替代这两种说明。

SSE的df为什么是N−t？

每组估一个自己的均值，使该组残差之和必须为0。t组共有t个约束。把N个原始信息减去t个估计中心的约束，留下N−t个error df；总df则是N−1。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

温室与 CRD：读懂平方和的每一行

Greenhouse 的四组数据采用 one-way ANOVA。先求每组均值与 grand mean，再将每个观测的总偏差拆成“本组均值与 grand mean 的差”加“观测与本组均值的差”。前一部分形成 treatment SS，后一部分形成 error SS。

Class notes 的实算表进一步把 SS 与对应 df 配对。先用本站的小例子手算这一分解，再读软件表中的 MS 和 F，便能解释每一行的来源，而不是只记住最后一个 F-value。

苹果叶磷与心理学学生：整体检验的范围

Apple leaf phosphorus 比较多个 treatments 的 means。Omnibus F 拒绝 null 只说明并非所有 mean 都相等；若要回答哪两个处理不同，还需预先定义具体 comparisons 并考虑 multiplicity。

Psychology students 例的残差不符合 normal 模型，引出 Kruskal–Wallis 与 tie correction。Ranks 方法针对分布或适当条件下的位置差异，不能未经额外条件就解释为同一个 mean test。组标签仍是类别，而不是连续 predictor。

海湾污染与耗氧：变换以后重新检查

不同离岸距离的 sampling groups 出现 mean 与 variance 随水平一起变化的现象。课件实际采用 √(Y+3/8)=√(Y+.375)，目的是缓解这种异方差，但不能只因为做了变换，就断定问题已解决。需要重新拟合，并检查变换后 residuals 的散布和形状。

变换也改变参数目标：在 √(Y+3/8) 上做 ANOVA 比较的是 E[√(Y+3/8)]，它通常不等于 √(E[Y]+3/8)。结论应说明所用尺度，不能直接把变换后的检验当作原始 mean 的同一个检验。

笑气与 IBS：scale 应服务测量问题

Laughing-gas 剂量与 class notes 的三个气体组 IBS 症状评分案例，分别考察原尺度、sqrt 和 log scales。先说明 score 测量什么，再检查零值与尺度是否允许所选变换；例如普通 log 不适用于零值。

Normality 与 constant variance 是两个不同检查。每换一种 scale，都要重新看 residuals，并按新参数解释结论。不能仅因某种变换得到最小 P-value，就倒推它是最合理的分析尺度。

每组人数不同，ANOVA 的 grand mean 怎样计算？

等样本量的例子容易让人误记为“grand mean 就是几个组均值的简单平均”。一元 ANOVA 的 total sum of squares 以所有观测的均值为中心，因此组大小不同时必须按人数加权。

原创数据：A=[2,4]，B=[5,5,8]，C=[8,9,10,11]。组大小分别2、3、4，组均值分别3、6、9.5。N=9，全部观测总和62，所以 grand mean=62/9≈6.888889。直接平均三个组均值得到6.166667，描述的是三个组各占三分之一的另一个目标，不能拿来代入本例的 SST 分解。

ȳ..=Σnᵢȳᵢ/N
SS_between=Σnᵢ(ȳᵢ−ȳ..)²
SS_error=ΣΣ(Yᵢⱼ−ȳᵢ)²
  1. 组内平方和。 A贡献2，B贡献6，C贡献5，所以 SSE=13。
  2. 组间平方和。 2(3−62/9)²+3(6−62/9)²+4(9.5−62/9)²=539/9≈59.888889。
  3. 核对总平方和。 SST=59.888889+13=72.888889。
  4. 自由度。 三个组估计三个组均值，error df=N−3=6；treatment df=3−1=2；total df=8。
  5. 检验。 MStrt=29.944444，MSE=13/6≈2.166667，F≈13.820513，参考 F(2,6)，右尾 p≈.00567。

summary(fit)

sst <- sum((y-mean(y))^2)
c(grand_mean=mean(y),SS_between=sst-sse,SS_error=sse,SS_total=sst)
# Check model diagnostics; a small example cannot certify assumptions.
qqnorm(residuals(fit)); qqline(residuals(fit))

Welch ANOVA：异方差下怎样比较三个总体均值

当研究问题仍是比较多个总体均值，但各组误差方差不同，Welch ANOVA保留每组自己的方差信息。它扩展了两样本Welch思路，使用按精度加权的组均值差异，并校正参考统计量与自由度。课件提到该方法，这里把计算与输出完整展开。

原创数据：三个独立组，样本量和方差都不相同
组原始观测nᵢȳᵢsᵢ²wᵢ=nᵢ/sᵢ²
A9,10,11,10410.6666676
B5,9,13,17,21,2561556.107143
C10,11,12,13,145122.52

预先指定H₀:μA=μB=μC，Hₐ为并非所有均值相同。假定组间和组内实验单位独立、各组总体近似正态，允许不同的总体方差。这里的小数据主要用于手算和复现，不能仅凭这些观测证明分布条件。

第一步：让精度决定计算权重。 组均值的估计方差为sᵢ²/nᵢ，其倒数是wᵢ。B组虽然有六个观测，方差却很大，均值估计不精确，因此权重很小。总权重W=Σwᵢ≈8.107143，参考中心为：

ȳw=Σwᵢȳᵢ/W≈10.559471

ȳw用于形成检验统计量，并没有把科学问题改成“比较加权总体均值”。检验目标始终是三个μ是否相同。

第二步：计算组均值的加权偏离，并校正估计方差的额外不确定性。 用U表示下面的校正和，k=3：

U=Σ[(1−wᵢ/W)²/(nᵢ−1)]≈.359133
A=Σwᵢ(ȳᵢ−ȳw)²/(k−1)≈4.070485
C=1+[2(k−2)/(k²−1)]U≈1.089783
FWelch=A/C≈3.735132

A是加权组间差异；C反映权重使用样本方差估计所带来的校正。它没有经典ANOVA中那一个所有组共用的MSE分母。

第三步：使用匹配的近似F参考。

ν₁=k−1=2
ν₂=(k²−1)/(3U)≈7.425282
p=P[F(2,7.425282)≥3.735132]≈.075424

所以α=.05时不拒绝均值全相同的null。分母df为7.425282而非N−k=12，也不需要把它取整。这是近似参考分布；未知且不同的方差通常不产生一个简单的精确有限样本F检验。

y <- c(9,10,11,10, 5,9,13,17,21,25, 10,11,12,13,14)
g <- factor(rep(c("A","B","C"),c(4,6,5)))
ni <- as.numeric(table(g))
mi <- as.numeric(tapply(y,g,mean))
si2 <- as.numeric(tapply(y,g,var))
stopifnot(all(ni > 1),all(si2 > 0))
k <- length(ni)
# Estimate the precision of each group mean separately.
w <- ni/si2
W <- sum(w)
weighted_mean <- sum(w*mi)/W
U <- sum((1-w/W)^2/(ni-1))
A <- sum(w*(mi-weighted_mean)^2)/(k-1)
C <- 1+2*(k-2)*U/(k^2-1)
f_welch <- A/C
df1 <- k-1
df2 <- (k^2-1)/(3*U)
p_welch <- pf(f_welch,df1,df2,lower.tail=FALSE)
print(data.frame(group=levels(g),n=ni,mean=mi,variance=si2,weight=w))
print(c(weighted_mean=weighted_mean,F=f_welch,
        numerator_df=df1,denominator_df=df2,p=p_welch))
# Verify the manual calculation against base R.
fit <- oneway.test(y ~ g,var.equal=FALSE)
print(fit)
stopifnot(abs(unname(fit$statistic)-f_welch) < 1e-10,
          abs(fit$p.value-p_welch) < 1e-10)

怎样读输出： F是经过校正的Welch统计量；num df是组数减一；denom df是估计出来的近似自由度；p-value对应“所有总体均值相同”的整体问题。拒绝时也不能直接推出每一对都不同。

为什么要事先确定模型： 同一数据用共同方差的经典ANOVA，F≈1.30137、p≈.308，两种方法对噪声的处理不同。这个对照用于解释假设，不能成为选择较小p的方法。研究设计、目标量和对方差结构的合理判断应先于查看比较结果；也不应把一次方差检验的p当作自动切换按钮。

后续比较与边界： 异方差整体检验之后，不要直接接一个依赖共同MSE的经典Tukey阈值，声称它已经配套保护了异方差推断。可事先定义需要的pairwise均值比较，并对相应Welch检验作适当的family校正，例如Holm，或采用适用的异方差同时推断方法。Welch不会修复配对被忽略、伪重复、严重重尾或选择性删点；若真正目标是median或分布，应另行明确估计对象。

把预先指定的三对均值比较算到底：Welch + Bonferroni

沿用上面的 A、B、C 数据，在看结果前把比较族（family）定为全部三对双侧比较：μA−μB、μA−μC、μB−μC，m=3，family α=.05。每一项检验 H₀:μᵢ−μⱼ=0。整体 Welch P≈.075424 回答“所有均值是否相同”，不是预先计划的逐对比较必须通过的门槛；若研究方案没有设置整体检验的 gatekeeping 要求，可以直接完成这三项及其校正。不能先看哪一对的 P 小，再把 family 缩成那一对。

每一对保留各自的方差估计，不能用共同 MSE 代替。令 vᵢ=sᵢ²/nᵢ，则：

dᵢⱼ=ȳᵢ−ȳⱼ，SEᵢⱼ=√(vᵢ+vⱼ)
νᵢⱼ=(vᵢ+vⱼ)²/[vᵢ²/(nᵢ−1)+vⱼ²/(nⱼ−1)]
tᵢⱼ=dᵢⱼ/SEᵢⱼ，pᵢⱼ=2P(Tνᵢⱼ≥|tᵢⱼ|)
Bonferroni adjusted p=min(1,3pᵢⱼ)
Bonferroni CI：dᵢⱼ±t₁₋.05/(2×3),νᵢⱼ SEᵢⱼ

例如 A−C：d=10−12=−2，vA=(2/3)/4=1/6，vC=2.5/5=1/2，所以 SE=√(2/3)=.816497，ν≈6.193548，t≈−2.449490。原始双侧 P≈.048571，但三项 Bonferroni adjusted P≈.145713；对应区间为 [−4.654733,.654733]。

每项分配 α/3=.0166667，因此每个区间使用名义置信水平 1−α/3=.9833333。若各单项错误率确实不超过分配值，Bonferroni 概率界保证 family 错误率不超过 .05、三个区间的同时覆盖率至少 .95；它不要求这三项比较彼此独立。这里的 Welch t/df 是近似参考，所以应把这些报告为以 95% 同时覆盖为目标的 Bonferroni–Welch 近似区间，不能宣称任意有限样本下严格精确的 95% 保证。

本例三个校正 P 都大于 .05，三个区间都包含 0：在这个预先定义的 family 下，没有一对达到显著差异门槛；这并未证明三对总体均值差都为 0。原始 A−C 的 P<.05 不能绕过已经设定的三项校正。此程序仍依赖组间、组内独立及各组分布适合 Welch 近似等条件，无法修复配对、伪重复或严重重尾。

下面一个代码块从原始数据独立运行：手算每对统计量，再分别与 t.test(var.equal=FALSE) 的统计量、df、P 和 98.3333% 区间核对；调整 P 与 p.adjust(method="bonferroni") 核对。

# Define all three two-sided pairwise comparisons before examining results.
groups <- list(A = c(9,10,11,10),
               B = c(5,9,13,17,21,25),
               C = c(10,11,12,13,14))
alpha <- .05
pairs <- combn(names(groups), 2, simplify = FALSE)
m <- length(pairs)
result <- do.call(rbind, lapply(pairs, function(pair) {
  x <- groups[[pair[1]]]; y <- groups[[pair[2]]]
  nx <- length(x); ny <- length(y)
  vx <- var(x) / nx; vy <- var(y) / ny
  difference <- mean(x) - mean(y)
  se <- sqrt(vx + vy)
  df <- (vx + vy)^2 / (vx^2 / (nx - 1) + vy^2 / (ny - 1))
  t_stat <- difference / se
  p_raw <- 2 * pt(-abs(t_stat), df = df)
  critical <- qt(1 - alpha / (2 * m), df = df)
  interval <- difference + c(-1, 1) * critical * se
  # Each interval has nominal confidence 1 - alpha/m, not 1 - alpha.
  check <- t.test(x, y, alternative = "two.sided", var.equal = FALSE,
                  conf.level = 1 - alpha / m)
  stopifnot(abs(unname(check$statistic) - t_stat) < 1e-10,
            abs(unname(check$parameter) - df) < 1e-10,
            abs(check$p.value - p_raw) < 1e-10,
            max(abs(as.numeric(check$conf.int) - interval)) < 1e-10)
  data.frame(pair = paste(pair, collapse = " - "), difference = difference,
             SE = se, df = df, t = t_stat, p_raw = p_raw,
             p_bonferroni = min(1, m * p_raw),
             lower = interval[1], upper = interval[2])
}))
# Bonferroni does not require independence between the three comparisons.
stopifnot(max(abs(result$p_bonferroni -
                  p.adjust(result$p_raw, method = "bonferroni"))) < 1e-10)
print(result, digits = 10, row.names = FALSE)
print(c(family_alpha = alpha, number_of_pairs = m,
        per_pair_confidence = 1 - alpha/m))
# The omnibus question is distinct from the prespecified pairwise questions.
dat <- stack(groups)
print(oneway.test(values ~ ind, data = dat, var.equal = FALSE))
