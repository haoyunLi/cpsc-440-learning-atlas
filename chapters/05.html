Confidence interval 是一个有覆盖率的程序

样本均值是一个估计，但它离真实均值可能有多远？Confidence interval（CI，置信区间） 把“估计值”和“抽样误差的尺度”放在一起，提供与模型对应的区间估计。

已知总体 σ：ȳ±z₁₋α/₂σ/√n
未知 σ、独立正态观测：ȳ±t₁₋α/₂,ₙ₋₁s/√n
未知 σ 的 large-sample z approximation：ȳ±z₁₋α/₂s/√n

先问标准差的来源：σ 是总体参数，s 是由本次样本算出的估计。已知 σ 且独立正态抽样时，第一式有精确的正态参考分布；未知 σ 且独立正态抽样时，第二式有精确的 t 参考分布。第三式把 s 代入标准误、仍使用 z critical value，是大样本近似。在独立同分布、有限且非零 variance 等条件下，CLT 与 s 的一致性支持这种近似；有限样本的准确程度仍取决于偏态、重尾等情况，没有普适的“n≥30 就精确”保证。非正态总体下，使用 t 也不能自动获得精确覆盖率。

n 变大不会让未知 σ 变成已知。 它只会使 s 通常估得更稳定、t critical value 更接近 z。若独立正态模型成立、σ 由样本估计，无论 n 是 15 还是 168，都可以使用 df=n−1 的 t 区间。

公式可读成“estimate ± critical value × standard error”。Estimate 决定中心；SE 决定估计值会有多大波动；critical value 为指定的 confidence level 留出足够范围。

  1. 确定估计对象。 原创例要估计总体均值 μ，从正态总体独立抽样，已知 σ=10，抽到 n=25，样本均值为 54。
  2. 算标准误。 SE=10/√25=2。不要把个体 SD=10 直接当作均值的 SE。
  3. 选临界值。 95% 双侧区间让左右各留 .025，z₀.₉₇₅≈1.96。
  4. 计算边际误差。 E=1.96×2=3.92，因此 CI=[54−3.92,54+3.92]=[50.08,57.92]。
  5. 说明覆盖含义。 固定总体、按同样程序反复抽样并构造区间，长期约 95% 的区间覆盖固定参数 μ。

已经算出的区间是固定的，μ 也固定，所以 frequentist CI 不应说成“μ 有 95% 概率落在这一个区间”。它也不是“95% 的个体落在这里”。下方的重复覆盖动画会把固定的 μ 和不断改变的区间分开显示。

同一个 SD 数字，先辨认是 σ 还是 s

课程两份资料的符号不同：PPT/Chapter_5.pptx 第 6 页把 n=168、ȳ=36.92 的 SD=6.73 标为 σ；classnote/440 - Chapter 5 - 2022 Fall.pdf 第 5 页明确写 sample standard deviation，并记为 s=6.73。数值都是 6.73。按 PPT 的已知 σ 设定计算 z 区间；按 notes 的样本 s 设定，那里展示的是 large-sample z approximation，独立正态模型下则可使用 t₁₆₇ 区间。不能因为课件用了 z，就反过来把样本 s 改称已知 σ。

两种计算的标准误数值都是 6.73/√168=.519230773。95% z critical=1.959963985，得到 [35.902326,37.937674]；t₁₆₇ critical=1.974270957，得到 [35.894898,37.945102]。t 区间略宽，反映估计 σ 的不确定性。第一组端点接近不意味着两种统计量拥有相同的有限样本参考分布；下方案例对照继续核对树林例。

相同数据与方法下，99% 比 95% 区间更宽；增加独立样本、降低测量变异则通常提高精度。区间窄只说明模型下估计更精确，不能弥补不具代表性的抽样。

若规划时希望 half-width 不超过 E，已知或假设的 σ 给出 n≥(z₁₋α/₂σ/E)²。课程 cereal 例要求 full width W=.50，所以 E=.25；σ=.75、99% confidence 时，用完整的 qnorm(.995) 得到 n≥59.714069，向上取整为 60。若用舍入的 z=2.576，得到约 59.72；PPT 第 13 页与 notes 第 9 页用 z=2.58，得到约 59.91，最终同为 60。要求的是完整区间宽度还是半宽，必须先确认。若 σ 仅来自先导研究，这个 n 是基于规划 SD 的近似，不会让正式分析中的 σ 变为已知，也不保证未来用随机 s 计算的区间必定达到该宽度。

独立复算：基本区间与宽度规划

# Exact z interval for an independent normal sample with known sigma.
ybar <- 54; sigma <- 10; n <- 25
print(ybar + c(-1, 1) * qnorm(.975) * sigma / sqrt(n))

# Planning uses the assumed population SD, not a future observed sample SD.
planning_sd <- .75; target_width <- .50; level <- .99
critical_z <- qnorm((1 + level) / 2)
n_continuous <- (critical_z * planning_sd / (target_width / 2))^2
n_required <- ceiling(n_continuous)
width_at <- function(n) 2 * critical_z * planning_sd / sqrt(n)
print(c(n_continuous = n_continuous, n_required = n_required,
        width_at_n = width_at(n_required),
        width_at_previous_n = width_at(n_required - 1)))
stopifnot(width_at(n_required) <= target_width,
          width_at(n_required - 1) > target_width)

七步 test 把问题、模型与结论连起来

现在把问题从“μ 可能在哪个范围”改为“数据是否提供足够证据，反对一个指定的 μ”。Hypothesis test（假设检验） 先规定一个参考世界，再判断当前数据在这个世界里是否太不寻常。

Null hypothesis（H₀） 指被检验的基准；alternative hypothesis（Hₐ） 是研究希望区分的方向。例如双侧 H₀:μ=50、Hₐ:μ≠50，问任何方向的偏离；右侧 H₀:μ≤50、Hₐ:μ>50，只问增大。方向应由研究问题决定，不能看到结果后再改。

  1. 写清假设。 原创例检验 H₀:μ=50 与 Hₐ:μ≠50。
  2. 预先定规则。 使用 α=.05、n=25，明确抽样与独立性条件。
  3. 选参考分布。 假设 σ=10 已知，正态模型下使用 Z；σ 未知时通常改用 t。
  4. 定拒绝区域。 双侧标准正态在左右各留 .025，临界值为 ±1.96。
  5. 用数据算距离。 观察到 ȳ=54；SE=10/5=2；Z=(54−50)/2=2，表示样本均值比 null 中心高两个 SE。
  6. 按规则决策。 |2|>1.96，或双侧 P≈.0455≤.05，因此拒绝 H₀。
  7. 用研究语言解释。 在这些抽样和模型条件下，数据支持总体均值不同于 50。还应报告估计值与 CI，而不只写“显著”。
Z=(ȳ−μ₀)/(σ/√n)；t=(ȳ−μ₀)/(s/√n)，df=n−1

P-value 是在 H₀ 和模型成立时，得到当前或更极端统计量的概率。“更极端”由 Hₐ 的方向规定。这里双侧包含 Z≥2 和 Z≤−2；预先规定右侧时只取 Z≥2，P≈.0228。

P-value 不是 H₀ 为真的概率，也不是“差异由偶然造成”的概率。没有达到拒绝规则，叫 fail to reject：资料不足以拒绝该 null，不能直接说“证实相同”或“没有作用”。α、effect size 和 estimate uncertainty 分别承担不同角色。

先把研究句子写成假设，再看数据

原创自检，先写再展开。 一套过滤器改进方案希望使“过滤 1 L 水所需的总体平均时间”低于现行基准 40 秒。团队在收集数据前就确定：只把平均时间缩短视为支持改进的证据，α=.05。计划独立随机抽取 18 个新方案过滤器，每个只测一次；假定时间来自正态总体，总体 σ 未知。现在尚未看到任何读数。请写出参数、完整 H₀/Hₐ、tail、检验统计量与 reference distribution，并指出参考分布在哪个 null 边界成立。

先完成假设与参考分布，再展开答案
  1. 参数属于总体。 μ 是目标使用条件下，新方案过滤器过滤 1 L 水的总体平均时间，单位秒；它不是这 18 个观测的样本均值 ȳ。
  2. 方向来自预先提出的目标。 缩短意味着 μ<40，所以 Hₐ:μ<40；完整 null 为 H₀:μ≥40。等号归入 null，μ=40 是其边界；μ>40 也属于 null，不能把它漏掉。
  3. 未知 σ 使用样本 S。 统计量 T=(Ȳ−40)/(S/√18)。在独立正态模型与边界 μ=40 下，T~t₁₇。这里 df=n−1=17；样本量与“σ 是否已知”是不同信息。
  4. 小的 T 支持预设 alternative。 采用左尾，拒绝域 T≤t_.05,17，这里的 t_.05,17 是 t₁₇ 的下侧 5% 分位数；观察到 t_obs 后，边界 P-value 为 P(t₁₇≤t_obs)。在此模型中，边界 μ=40 给出复合 null 内最大的左尾拒绝概率；μ>40 时 T 向右偏移，不能说整个复合 null 下都服从同一个中心 t₁₇。

常见错误： 不应写 H₀:ȳ≥40，因为假设针对固定但未知的总体参数；也不能先看样本均值低于 40 才决定用左尾。若研究方案原本把变快与变慢都列为关心的变化，才应预先使用 H₀:μ=40 对 Hₐ:μ≠40 的双侧检验；这是另一项研究计划，不是看过结果后的备选按钮。

Type I 与 Type II errors 对应不同世界

一个检验规则可以在不同的真实世界里产生不同结果。理解 α、β 与 power（检验效能），需要先固定规则，再分别看 H₀ 真实和某个具体 Hₐ 真实时会怎样。

同一决策规则，在不同真实情形中的表现
我们的决策H₀ 真实指定 alternative 真实
Reject H₀Type I error；模型下的有效检验将其概率控制为 ≤α正确检出，概率 1−β
Fail to reject正确不拒绝Type II error，概率 β

α 是预先设定的错误率上限。 对点零假设，精确校准的连续检验可达到 α；对复合零假设，不同真实参数对应的误报率可以不同。下例假定25个观测独立同分布于 N(μ,10²)，总体 σ=10 已知。右尾检验 H₀:μ≤50 对 Hₐ:μ>50，在最不利边界 μ=50 处误报率为 .05；若真实 μ=46，仍属于 H₀，同一个门槛的误报率约 .000134。不要把整个 H₀ 中每一种情形的误报率都写成恰好 α。课程 Chapter 5 PPT 第30页介绍两类错误，第47页在 μ=μ₀ 的边界计算 α；复合零假设中的错误率上界是这里补充的澄清。

Type I error 是 H₀ 真实却拒绝了 null；Type II error 是指定效应真实存在却没检出。β 必须针对一个具体真实均值 μₐ 计算：真实均值只高 .1 和高 10，不可能有同样的检出难度。

  1. 在 null 下定门槛。 右侧检验 μ₀=50、σ=10、n=25、α=.05。SE=2，临界样本均值 c=50+1.645×2≈53.29。只有 ȳ>c 才拒绝。
  2. 换真实世界，保留门槛。 假设真实 μₐ=54，样本均值的分布中心变为 54，但仍用 c=53.29 决策。
  3. 算漏检面积。 β=P(ȳ≤53.29|μ=54)=Φ((53.29−54)/2)=Φ(−.355)≈.3612。
  4. 取补集。 Power=1−β≈.6388。它表示在这个具体效应与模型下，反复进行同样研究的长期检出比例。
右侧：c=μ₀+z₁₋αSE；β(μₐ)=Φ((c−μₐ)/SE)
双侧：β=Φ((cᵤ−μₐ)/SE)−Φ((cₗ−μₐ)/SE)

下方实验把 null 与 alternative 两条曲线叠在同一坐标上。调整 α 会移动拒绝门槛；调整真实差异会移动 alternative 中心；调整 n 会缩窄两条均值分布。固定 n 时，减小 α 通常更不容易误拒绝，却也更容易漏检。

课程 encyclopedia 例 μ₀=33、μₐ=38、planning σ≈8.4、n=35、α=.05，z 近似下 c≈35.34，power≈.970。μₐ 是规划假设，不是把观察到的样本均值当作已知总体真值。未知方差的精确 t power 需要 noncentral t，不能简单把 t 临界值塞进标准正态 CDF。

Sample size 先服务研究中有意义的差异

决定 sample size 之前，先问研究要发现多大的差异。很小的差异可能在大样本中显著，却未必值得改变农学实践；样本太小又可能漏掉有实际意义的效果。

设 Δ=|μₐ−μ₀| 为最小值得发现的差异。再指定 α、目标 power=1−β，以及合理的 planning σ。这些输入共同决定需要多少独立单位。

右侧 z 规划：n≈σ²(z₁₋α+z₁₋β)²/Δ²
双侧常用近似：n≈σ²(z₁₋α/₂+z₁₋β)²/Δ²
  1. 写科学目标。 假设 Δ=5、σ=10，使用右侧检验 α=.05，目标 power=.8，因此 β=.2。
  2. 找两个分位数。 z₀.₉₅≈1.645，z₀.₈≈.842。前者规定拒绝门槛，后者使 alternative 下约 80% 落入检出区域。
  3. 代入。 n≈100×(1.645+.842)²/25≈24.74。
  4. 向上取整并回到设计。 至少取 25 个独立单位；若有 dropout 或 clustering，还要按实际结构另行调整。

Δ 减半时，分母变成原来的四分之一，所需 n 约变为四倍。降低噪声也有价值，因此改进测量或实验设计，有时比单纯增加测量次数更有效。

CI precision planning 的 E 是允许的估计误差半宽；power planning 的 Δ 是希望检出的真实差异。两者目的不同，不能交换使用。

实际用t检验时：从目标power反求n

总体σ通常未知，实际检验会用样本S构成T=(Ȳ−μ₀)/(S/√n)。规划时仍需给出一个合理的planning σ：这是对未来总体波动的假定，并没有使实际分析中的σ变成已知。独立正态模型下，备择分布为noncentral t；它的df和非中心参数都随n改变，所以要数值求解。

原创规划：检验H₀:μ≤50对Hₐ:μ>50，预先指定有意义的真实均值μₐ=54，planning σ=6，α=.05，目标power=.80。这里Δ=4，在每一个候选n下：

df=n−1；λ=Δ√n/σ
拒绝域：T>t₁₋α,n−1
power(n)=P[Tₙ₋₁,λ>t₁₋α,n−1]
  1. 先固定设计。 这是一个总体的单侧mean检验，因此调用时明确写type="one.sample"与alternative="one.sided"。省略时函数默认使用two-sample、two-sided设计，不能把其每组n当成本题总样本量。
  2. 求出连续解。 将n=NULL作为唯一待求参数，给定其余规划量，power.t.test()求出n≈15.357623。它是数值求根结果，还不是可以实际招募的观测个数。
  3. 向上取整。 取n=16个独立观测，并重新计算此整数n的power。
  4. 检查前一个整数。 n=16时power≈.815566，n=15时约.790835。因此本例16满足至少.80，15尚未满足。

}

Student’s t 承认我们也在估计 variance

上一节的 z 方法假设知道总体 σ。实际研究往往只有样本 SD=s；换一批样本，ȳ 和 s 都会变化。分母也有不确定性，因此标准化后的统计量比标准正态更容易出现较大绝对值，这就是 t 分布的厚尾来源。

T=(Ȳ−μ₀)/(S/√n)
独立正态观测，且真实 μ=μ₀ 时：T~Student’s t(n−1)

Degrees of freedom（df，自由度） 此处为 n−1。df 很小时，临界值较大、区间较宽；df 增大时，t 分布逐渐接近标准正态。不能看到小样本标准误很小，就忽略估计 s 带来的额外不确定性。

  1. 定义方向。 课程冰淇淋微生物例检验 μ>.3。
  2. 算 SE。 n=9、ȳ=.4564、s=.2128；SE=.2128/√9≈.07093。
  3. 标准化。 t=(.4564−.3)/.07093≈2.205，df=8。
  4. 查正确尾部。 右侧 P=P(t₈≥2.205)≈.029。若预先 α=.01，.029>.01，所以不能拒绝；估计值高于 .3 本身并不够。

使用之前还要检查独立性和分布。QQ plot 可以看尾部与形状，却不能验证实验单位是否独立。Shapiro–Wilk 未拒绝也不是“证明正态”，小样本的诊断可能没有足够能力。温和偏离下 t procedure 可能稳健，但强偏态、heavy tails 和 outliers 要特别留意。

本例给出的是汇总统计量；下面直接用它们复现检验与单侧下限，不假造九个原始观测。仅凭 mean 和 SD 不能恢复原始样本，也不能画出真实的 Q–Q plot。

规划 t-test power 时，用 noncentral t 描述 alternative 世界。若规划 σ，noncentrality 为 δ=(μₐ−μ₀)√n/σ；右侧 power=1−Fₙct(t₁₋α;df,δ)，双侧把两个拒绝尾部相加。可用 pt(...,ncp=delta) 或 power.t.test()，不要把样本 s 当作已知 σ 后仍声称是精确 z power。

同一份小样本：为什么把 s 填进 z 公式还不够？

原创例：五个独立实验单位的测量值为 8, 9, 10, 11, 12 mg。为说明精确 t 推断，假设观测独立同分布于一个正态总体，μ 和 σ 都未知；这是假定的抽样模型，不能由这五个数本身证明。研究前规定双侧检验 H₀: μ=8.5 mg，Hₐ: μ≠8.5 mg，α=.05。

  1. 先从原始数据估计标准误。 n=5、ȳ=10 mg，平方偏差和为 10 mg²，所以 s²=10/(5−1)=2.5 mg²，s=1.581139 mg，估计的 SE=s/√5=0.707107 mg。
  2. 再算统计量。 t=(10−8.5)/0.707107=2.121320，df=4。此时 σ 未知；把分母写成 s/√n，并不会让统计量服从标准正态。
  3. 最后选择与模型相符的参考分布。 下表两行使用完全相同的估计值和 SE，因此差异来自临界值与尾概率。第一行将大样本 z 近似用于 n=5 的小样本，不能把它当作本模型下精确的 95% 方法，也不能把它称为已知 σ 的 z 方法。
同一数据的算法95% CI 的临界值μ 的区间（mg）双侧 Pα=.05 的结论
用样本 s，却查 N(0,1)1.959964[8.614096, 11.385904]0.033895会拒绝 H₀
用样本 s，查 t₄2.776445[8.036757, 11.963243]0.101192不能拒绝 H₀

对各自方法，检验与同一方法的双侧区间相对应：8.5 不在第一行区间内，却在正确 t 区间内。t 的较大 P 不代表 H₀ 为真的概率更大；结论是，这份数据在指定模型下不足以拒绝 μ=8.5。不能看到两行结果后再选择较显著的一行。

真正“已知 σ”的 z 方法是另一种信息条件。 若总体 σ 确实已知，正态模型下 (Ȳ−μ)/(σ/√n) 才服从 N(0,1)。这里没有给定 σ，所以不能把 s=1.581139 称作已知 σ。模拟实验可以预先设定真实 σ 作比较基准，实际分析不能把未知真值拿来用。

单次结果之外：标称 95% 实际覆盖多少？

大写 S 表示“每次重新抽样都会改变的样本 SD”，小写 s 是本次观测值。正态独立抽样下，以真实均值 μ为中心的 pivot（枢轴量）T*=(Ȳ−μ)/(S/√n) 精确服从 tn−1。因此，不需要知道 μ 或 σ，也不需要运行模拟，就能算出这两种区间方法的长期覆盖率：

P(μ∈[Ȳ−z₀.₉₇₅S/√n, Ȳ+z₀.₉₇₅S/√n])
= P(|T*|≤z₀.₉₇₅)=2Ft₄(1.959964)−1=0.878440
P(|T*|≤t₄,₀.₉₇₅)=0.95

其中 Ft₄ 是 t₄ 的累积分布函数。n=5 时，把随机 S 代入标准误、仍查 z 临界值的区间只有约 87.84% 覆盖率；对应双侧检验在 μ=μ₀ 时的误报率约为 12.16%，并非 5%。这不是说某一次区间有 87.84% 的概率覆盖固定 μ，也不是说每一次 s 都小于 σ：问题是随机分母改变了整个抽样分布。t 校正在独立正态模型下恢复标称覆盖率；它不能修复相关观测，也不能保证小样本严重非正态时仍精确。

# Analyze one original sample under an independent normal sampling model.
y <- c(8, 9, 10, 11, 12)
mu0 <- 8.5
alpha <- 0.05
n <- length(y)
ybar <- mean(y)
s <- sd(y)
se <- s / sqrt(n)
df <- n - 1
t_obs <- (ybar - mu0) / se
z_crit <- qnorm(1 - alpha / 2)
t_crit <- qt(1 - alpha / 2, df = df)

# Both rows use the same estimated SE; only the reference distribution changes.
naive_z_p <- 2 * pnorm(-abs(t_obs))
t_p <- 2 * pt(-abs(t_obs), df = df)
naive_z_ci <- ybar + c(-1, 1) * z_crit * se
t_ci <- ybar + c(-1, 1) * t_crit * se
results <- data.frame(
  method = c("Normal reference with sample S", "Student t reference"),
  statistic = rep(t_obs, 2),
  p_value = c(naive_z_p, t_p),
  lower = c(naive_z_ci[1], t_ci[1]),
  upper = c(naive_z_ci[2], t_ci[2])
)
print(c(n = n, mean = ybar, s = s, se = se, df = df), digits = 12)
print(results, digits = 12, row.names = FALSE)

# Check the manual t calculation against the base R implementation.
check <- t.test(y, mu = mu0, alternative = "two.sided",
                conf.level = 1 - alpha)
stopifnot(isTRUE(all.equal(t_p, check$p.value, tolerance = 1e-12)))
stopifnot(isTRUE(all.equal(t_ci, as.numeric(check$conf.int),
                          tolerance = 1e-12)))
stopifnot(naive_z_p < alpha, t_p > alpha)

# Exact repeated-sampling coverage under iid normal observations, not a simulation.
# Here the pivot is centered at the true population mean, not an arbitrary mu0.
naive_coverage <- 2 * pt(z_crit, df = df) - 1
t_coverage <- 2 * pt(t_crit, df = df) - 1

        naive_coverage = naive_coverage,
        t_coverage = t_coverage,
        naive_null_rejection = 1 - naive_coverage), digits = 12)
stopifnot(abs(naive_coverage - 0.8784403402128) < 1e-12)

当中心问题是 median：Sign test 与 order statistics

如果研究问题关心的是中位数，而不是均值，就需要直接针对 median 推断。偏态垃圾量或回收量中，一个很大的值可能明显改变均值，却不改变中间位置；目标必须由科学问题决定，不能只因为均值检验不显著就换一个方法。

Sign test（符号检验） 只看每个值位于假设中位数 M₀ 的上方还是下方。连续分布且 H₀ median=M₀ 时，一次独立观测位于上方的概率为 .5，于是正号个数可用 binomial。

  1. 计算每个 Yᵢ−M₀，记录正号和负号。
  2. 若按预先说明的规则删去恰好为0的中心处 ties，须核实 H₀ 下 P(Y>M₀｜Y≠M₀)=.5，才可在非零差数量 m 上使用 Binomial(m,.5)。离散或取整产生的零值不能机械删除：median=M₀ 本身不保证这个条件。
  3. 若 Hₐ:median>M₀，较多正号支持 Hₐ。9 个非零差中 8 个为正时，P=P(B≥8)，B~Binomial(9,.5)。
  4. 逐项相加得到 [C(9,8)+C(9,9)]/2⁹=(9+1)/512≈.01953。这是右侧 P；双侧的“更极端”包含两个方向。

相同但不等于 M₀ 的观测仍各计一个符号；影响这里有效 m 的是恰好等于被检验中心的零差。条件符号检验题给出一个三点分布反例：M₀ 确为 median，删零后正号概率却不是.5。若 m=0，没有非零符号信息，也不能据此声称两者等效。

Median 的区间可以用 order statistics（顺序统计量）。将Y排序得到Y₍₁₎…Y₍ₙ₎。下述覆盖计算假设观测独立同分布，来自连续总体；对固定的真实中位数M，有P(Y<M)=P(Y>M)=.5。令B为样本中低于M的个数，则B~Binomial(n,.5)。

区间[Y₍ₖ₎,Y₍ₙ₋ₖ₊₁₎]覆盖M，等价于至少k个观测在M以下、至少k个在M以上，也就是k≤B≤n−k。连续性使恰好等于M的情形概率为0。

coverage(k)=P(k≤B≤n−k)=1−2P(B≤k−1)
选满足2P(B≤k−1)≤α的最大整数k
CI=[Y₍ₖ₎,Y₍ₙ₋ₖ₊₁₎]

为什么选最大的合法k？ 在这组对称、嵌套的顺序统计量区间中，k越大，两边各移入一个位置，区间越窄。先要求覆盖率达到目标，再选其中最窄的一项；不能先看哪段数据最集中，再任意挑端点。

从95%置信度开始，自己找到区间

原创等待时间为18,7,12,9,35,11,6,14,10分钟。共有n=9个独立观测，目标confidence level=.95，因此α=.05。先只根据n与α选择索引，再把索引应用于排序数据。

n=9时逐个核对候选索引
kP(B≤k−1)实际coverage达到至少.95？
1.001953125.996093750是，但区间更宽
2.019531250.960937500是，最大合法k
3.089843750.820312500否；更大k的覆盖率还会下降
  1. 选索引。 最大合法k=2，上端索引为n−k+1=8。
  2. 排序。 数据变成[6,7,9,10,11,12,14,18,35]。排序不改变观测或样本量。
  3. 读取实际端点。 第二小为7，第八小为18，所以median CI为[7,18]分钟。不要把索引[2,8]当成时间区间。
  4. 报告覆盖含义。 在上述模型下反复抽样并采用同一程序，覆盖固定M的比例为.9609375。计数是离散的，无法通过微调整数索引恰好达到.95；这个“至少95%”区间稍保守。

n太小时怎么办？ n=5时，在有限观测端点中最宽的区间已经是[Y₍₁₎,Y₍₅₎]。其覆盖率为1−2(.5)⁵=.9375，仍低于.95，因此这类有限端点、分布无关的区间无法达到95%。不能硬选最小值和最大值后仍标成95%。可增加独立样本；若保持此类分布无关程序，保证所需覆盖可能需要无穷端点。不要添加未经说明的分布假设来缩窄区间。

y <- c(18,7,12,9,35,11,6,14,10)
confidence <- .95
n <- length(y)
ordered <- sort(y)
# Search all symmetric, nested order-statistic intervals.
candidate_k <- seq_len(floor(n/2))
lower_tail <- pbinom(candidate_k-1,n,.5)
coverage <- 1-2*lower_tail
index_table <- data.frame(k=candidate_k,lower_tail=lower_tail,
                          coverage=coverage)
print(index_table)
eligible <- candidate_k[coverage >= confidence]
stopifnot(length(eligible) > 0)
k <- max(eligible)
indices <- c(k,n-k+1)
ci <- ordered[indices]
actual_coverage <- coverage[match(k,candidate_k)]
print(ordered)
print(c(k=k,lower_index=indices[1],upper_index=indices[2],
        lower=ci[1],upper=ci[2],coverage=actual_coverage))
stopifnot(k==2,all(ci==c(7,18)),
          abs(actual_coverage-.9609375) < 1e-12)
# With five observations, even the widest finite interval falls short.
n_small <- 5
best_finite_coverage <- 1-2*pbinom(0,n_small,.5)
print(c(n=n_small,best_finite_coverage=best_finite_coverage,
        meets_target=best_finite_coverage >= confidence))
stopifnot(best_finite_coverage < confidence)

把显著性转换成准确的话

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

P=.08、α=.05，可以写“处理没有作用”吗？

第一步，按预定规则 .08>.05，fail to reject。第二步，查看估计值与 CI，了解数据仍允许哪些效应。第三步，结论写成没有足够证据反对该 null，而不是证明作用为零。若目标是证明差异小于实质阈值，需要预定 equivalence margins 与对应方法。

95% CI 不含μ₀，是否等价于双侧α=.05拒绝？

先核对是否使用同一个模型、SE、tail 与临界值。对应的双侧检验和CI互相反演时，答案是是。例如 [50.08,57.92] 不含50，与Z=2的双侧P≈.0455一致。若一个用z近似、另一个用t，或改为单侧，不能未经核对直接套这个关系。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

课程 CI 案例：区分 PPT 的 σ 与 notes 的 s

下面并列两种来源设定，不把符号差异当作相同条件。PPT/Chapter_5.pptx 第 6/9 页把两例的 SD 分别记为总体 σ=6.73、12.1；classnote/440 - Chapter 5 - 2022 Fall.pdf 第 5/7 页则记为样本 s=6.73、12.1。Notes 第 7 页还明确说用 s² 估计 σ²，并假定总体正态。

因此，按 PPT 的已知 σ 设定使用 z；按 notes 的样本 s 设定，那里的 z 计算应理解为大样本近似。若按独立正态模型分析 notes 的样本 s 摘要，使用 df=n−1 的 t 区间可获得模型下的精确覆盖率。已知 σ 的 z 区间也需要正态样本均值才能具有精确覆盖率；若依靠 CLT，则同样是近似。是否知道 σ 来自研究信息，不由 n 的大小决定。

课程摘要与定位SE 的数值z 区间：已知 σ，或以 s 代入的近似t 区间：未知 σ、独立正态模型
n=168，ȳ=36.92，SD=6.73，95%；PPT 6 / notes 5.519230773[35.902326,37.937674]df=167；[35.894898,37.945102]
n=50，ȳ=27.3，SD=12.1，99%；PPT 9 / notes 71.711198410[22.892245,31.707755]df=49；[22.714070,31.885930]

表中使用完整的 qnorm/qt 分位数。课件手算把 z 舍入为 1.96 或 2.58，保留到小数点后两位时仍得到约 [35.90,37.94] 与 [22.89,31.71]。两组 z 与 t 的中心相同，t 区间较宽；尤其不能把树林例的 s=12.1 说成已经知道总体 σ=12.1。若总体不正态，这里的 t 区间也需要评估其近似适用性。

Cereal 精度规划给出 σ=.75、99% CI 的 full width W=.50。先把全宽除以 2，得到允许的 half-width .25，再算 n≥(qnorm(.995)×.75/.25)²≈59.714069，向上取整为 60 个独立箱体。用 z=2.576 得约 59.72，用课件舍入的 2.58 得约 59.91，整数规划相同。若把 .50 直接当 half-width，会规划出过少的样本。前面的独立 R 代码也检查了 n=60 达标、n=59 不足；若 SD 只是先导估计，则精度规划依赖这个假定。

工程过程与 rat growth：超过基准不等于显著

工程例做右侧检验，ȳ=553、μ₀=520、σ=124、n=36。SE=124/6≈20.667，z=(553−520)/20.667≈1.597，仍小于 α=.05 的临界值 1.645。因此样本均值虽高于 520，证据还未越过预定的拒绝门槛。

若另一问题给出 ȳ=500 并做双侧检验，则 z≈−.968，必须按双侧规则解释。Class notes 的 rat growth 例采用相同思路：先写 Hₐ 的方向，再计算标准化距离，最后用事先确定的规则下结论。

城市垃圾与百科全书：门槛固定，真实 mean 改变

城市垃圾量例以 μ₀=380 设置 rejection threshold，然后考察多个假定的真实 μₐ。计算 β 时，这个门槛保持不动；改变的是 alternative 下 sample mean 的分布。否则每换一个 μₐ 就换检验规则，会把 Type II error 的含义弄错。

Encyclopedia 例做右侧 z-test，μ₀=33、σ=8.4、n=35。门槛约为 33+1.645×8.4/√35≈35.336。若真实 μₐ=38，power=P(ȳ>35.336|μ=38)≈.970。这个 .970 针对指定的 planning effect，不能把一次观察到的均值 35 当作已知真实 mean 来套用。

仓库、飞行员与家庭垃圾：先确定中心目标

Warehouse 例给出 n=15、ȳ=28.2、s≈11.44，计算得 t≈1.083、df=14，右侧 P≈.148。Pilots 例给出 n=14、ȳ=2.26、s=.28，95% mean CI≈[2.098,2.422] m。这里用 s 估计总体波动，所以参考分布是 t，而不是已知 σ 的 z。

垃圾与回收数据较偏。如果科学问题关心典型家庭的 median，可用 sign test 与 order-statistic CI；这与比较总体 mean 是不同目标。先明确参数，再把 CI、test statistic 和 P-value 放在同一模型与方向下解释。

独立复算：相同摘要的 z 与 t 区间

# Reproduce both source examples from summaries; no raw data are invented.
examples <- data.frame(
  case = c("Example 1", "Count trees"),
  n = c(168, 50), ybar = c(36.92, 27.3),
  sd_value = c(6.73, 12.1), confidence = c(.95, .99))
result <- do.call(rbind, lapply(seq_len(nrow(examples)), function(i) {
  e <- examples[i, ]
  se <- e$sd_value / sqrt(e$n)
  z_critical <- qnorm((1 + e$confidence) / 2)
  t_critical <- qt((1 + e$confidence) / 2, df = e$n - 1)
  # The z formula is exact for known sigma under normal sampling.
  # With sample s, the same numeric z formula is a large-sample approximation.
  # The t formula is exact for unknown sigma under normal sampling.
  data.frame(case = e$case, df = e$n - 1, SE = se,
    z_critical = z_critical, t_critical = t_critical,
    z_lower = e$ybar - z_critical * se,
    z_upper = e$ybar + z_critical * se,
    t_lower = e$ybar - t_critical * se,
    t_upper = e$ybar + t_critical * se)
}))
print(result, digits = 10, row.names = FALSE)
stopifnot(all(result$t_lower < result$z_lower),
          all(result$t_upper > result$z_upper))

功效的计算从拒绝区域出发，左右尾都不会弄反

功效公式中的正负号很容易记错。更可靠的做法是先在样本均值的原始单位上确定拒绝区域，再到指定的真实总体下计算落入该区域的概率。

原创实验：独立测量 n=25 株植物，已知总体 SD σ=10 cm；假设个体正态。检验 H₀:μ≤50 对 Hₐ:μ>50，α=.05。样本均值的 SE=10/√25=2 cm。

  1. 在 null 边界找门槛。 μ₀=50 时，拒绝条件为 Z>1.644854，即 ȳ>50+1.644854×2=53.289707 cm。
  2. 指定一个真实 alternative。 若真正的 μₐ=54，重复实验时 ȳ 的中心在 54，SE 仍为 2。
  3. 把同一个门槛放到 alternative 下。 power=P(ȳ>53.289707 | μ=54)=P[Z>(53.289707−54)/2]。
  4. 计算。 标准化门槛约 −.355146；power≈.638760，β≈.361240。约64%的这类实验会检出这个真实差异。

这里有两个不同世界：α 是 μ=50 时落入拒绝区的概率；power 是 μ=54 时落入同一拒绝区的概率。α 不是这次显著结论出错的后验概率，power 也不是 μ=54 为真的概率。

如果研究问题改成“双向变化”： Hₐ:μ≠50，α 仍为 .05，就把 .025 分配到每一端。拒绝区域为 ȳ<46.080072 或 ȳ>53.919928。真实 μ=54 时，两个尾部都要相加：

Power(54)=Φ[(46.080072−54)/2]
+1−Φ[(53.919928−54)/2]≈.516005

常见的双侧近似只保留朝效应方向的一端。本例另一端很小，但完整写法能解释为什么这是近似。双侧功效较低，是因为相同 α 被分给了两个方向；这不能成为看过数据之后再把双侧改成单侧的理由。

mu0 <- 50
mua <- 54
se <- 10/sqrt(25)
alpha <- .05
# Derive the rejection boundary under the null.
cut <- mu0 + qnorm(1-alpha)*se
power_right <- pnorm(cut, mean=mua, sd=se, lower.tail=FALSE)
# Include both rejection tails for an exact normal-model calculation.
limits <- mu0 + qnorm(c(alpha/2, 1-alpha/2))*se
power_two <- pnorm(limits[1],mua,se) +
  pnorm(limits[2],mua,se,lower.tail=FALSE)
c(power_right=power_right, power_two=power_two)
