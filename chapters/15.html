设计实验来分离 nuisance variation

学习单元 09 / 10 · Chapter 15

RCBD, random effects & Latin squares

温室光照梯度，怎样避免被误认为品种差异？

分析无法修复完全 confounded 的设计；blocking 在收集数据前创造可比较的条件。

每个 block 内都有所有 treatments

温室中靠窗与远离窗的位置可能光照不同。如果一种品种全放靠窗，另一种全放里面，测到的差就混合了品种与光照。Blocking（区组化） 先把相近环境的实验单位组成 block，再在每个 block 内比较 treatments。

Randomized Complete Block Design（RCBD，随机完全区组设计） 中，“complete”表示每个 block 都含所有 treatments，“randomized”表示在 block 内随机分配。课程温室例有 3 varieties 和 5 light-gradient blocks，每个 block 各放一个品种，共 15 个实验单位。

  1. 先识别已知 nuisance，例如光照、实验日期或地块背景。
  2. 把内部较相似的单位组成 blocks，让光照差异主要出现在 blocks 之间。
  3. 在每个 block 内随机分配所有 treatments，使每种处理都经历同一组环境。
  4. 分析时把 block term 留在模型中，避免将可解释的环境差异全部算成 error。
Yᵢⱼ=μ+τᵢ+βⱼ+εᵢⱼ

τᵢ 是 treatment 部分，βⱼ 是 block 部分。每 treatment×block 只有一个观测时，无法再独立估计 treatment×block interaction；additivity 是需要科学依据的假设。

Blocking 的价值来自减少与研究目标无关的 variation。如果 blocks 实际几乎没差，估计它们仍消耗 df，可能未提高精度。下方实验会保留 treatment balance，同时改变环境梯度，显示这个权衡。

分解 treatment、block 与 error

RCBD 的总变化分成三份：treatment 中心差、block 中心差，以及两者都解释不了的 residual。完整平衡设计让每种 treatment 包含同样的 blocks，因此这些部分可以分开。

SStrt=bΣᵢ(ȳᵢ.−ȳ..)²
SSblock=tΣⱼ(ȳ.ⱼ−ȳ..)²
SSE=ΣᵢΣⱼ(Yᵢⱼ−ȳᵢ.−ȳ.ⱼ+ȳ..)²

i 指 treatment，j 指 block，t 为处理数，b 为区组数。一个 treatment mean 汇总 b 个观测，所以其偏差平方乘 b；一个 block mean 汇总 t 个观测，所以乘 t。Residual 从观测中扣去两种中心偏移，再加回被扣两次的 grand mean。

课程 t=3、b=5：df 为 2、4、8，总 14。Fixed-treatment 检验使用 F=MStrt/MSE。若忽略 blocks，当作 CRD，error df 会变为 15−3=12，但 error SS 也会变为 SSblock+SSE。更多 df 伴随着更多未解释 variation，不能只看 df 数量选模型。

Insecticide 案例同样先解释 treatment question，再看 block variation；block 显著不等于处理显著，也不是所有情形下 blocking 成功的唯一标准。

Relative efficiency 要同时考虑 residual reduction 与 df

Blocking 是否提高精度，需要同时看 residual reduction 和自由度成本。课程用 relative efficiency（RE，相对效率） 比较同一完整 block 数据在两个模型中的 MSE。

RE(RCBD,CRD)=MSE_CRD/MSE_RCBD
  1. RCBD 将 SSblock 分开，只用 SSE 估计 residual variance，df=(t−1)(b−1)。
  2. 忽略 blocks 的 CRD 将 SSblock+SSE 留在 error，df=b(t−1)。
  3. 分别除以各自 df，再取 MSE ratio。只看 SSE 下降不够，因为分母 df 也下降。
RE=[(b−1)MSblock+(b−1)(t−1)MSE_RCBD]
/[b(t−1)MSE_RCBD]

在本单元原创演示中，t=3、b=5，固定 residual SSE=10。RCBD MSE=10/8=1.25。若没有 block 梯度，CRD MSE=10/12≈.833，RE≈.667；此时估计无作用的 block 消耗了 df。梯度增强时，CRD error 多出 block variation，RE 会升高。

RE>1 表示按这一 residual-variance 评价，RCBD 更有效率；它不是 actual power 的精确倍数，一些教材还加小样本 df adjustments。实际 randomization structure 仍必须尊重，不能仅按观察到的 RE 事后抹掉设计。

完整设计中，每种 treatment 的均值包含同样的 block weights，treatment difference 中共享背景抵消。某个 cell 缺失后，权重不同，raw means 的差可能重新混入 block composition。Notes 的 missing-EU 推导强调应使用模型调整并核对 estimability，而不是随意补一个值。

Fixed 与 random 的区别是推断目标

Fixed effect 与 random effect 的区别在推断目标。若只关心这几个指定 levels 的均值差，可视为 fixed；若把这些 levels 看作从更大环境总体中抽出的样本，关注它们的 variance component，则使用 random-effect 结构。

“随机分配 treatments”与“random effects”不是同一概念。Fixed treatments 也应随机分配；random block 描述的是 block levels 如何代表目标总体以及它们的 covariance。

βⱼ~Normal(0,σᵦ²)，εᵢⱼ~Normal(0,σₑ²)
同 block 不同单位：Cov(Yᵢⱼ,Yᵢ′ⱼ)=σᵦ²

共享 βⱼ 的观测会一起偏高或偏低，所以同 block 相关。Balanced fixed-treatments/random-block additive RCBD 中：

E(MSE)=σₑ²；E(MSblock)=σₑ²+tσᵦ²
moment estimate：σ̂ᵦ²=(MSblock−MSE)/t

推导顺序是先写 expected mean squares，再相减以分离 block variance。抽样中 MSblock 可能比 MSE 小，moment estimate 于是为负；这不是负的真实 variance，而是该估计方法与样本波动的结果，约束估计需明确处理。

完整平衡设计的 treatment comparison 会抵消共享 block 部分，所以这里 fixed treatment test 仍用 MSE。不要把这个 denominator 规则扩展到所有 mixed/factorial designs；不同随机项可能改变 expected MS、covariance 与 df。

proc mixed data=d;
 class treatment block;
 model y=treatment;
 random block;
 lsmeans treatment / diff adjust=tukey;
run;

Factorial treatments 可以放进 RCBD

Factorial treatment structure 与 blocking 可以同时存在。前者列出研究要比较的组合，后者安排这些组合如何跨背景环境重复。

课程 bread 例研究 flour 与 oven temperature。一天只能做完一轮实验，day 是 nuisance block；每天包含 3×3=9 个 flour×temperature combinations。这样每个组合都在三个 days 出现，不把某一种面粉只安排在某一天。

Yᵢⱼₖ=μ+Aᵢ+Bⱼ+ABᵢⱼ+Blockₖ+εᵢⱼₖ
  1. 识别 treatment components：A、B 与 AB；block 不是这里感兴趣的第三个 treatment factor。
  2. 若 a×b combinations、b₀ blocks，每个 combination×block 一个 EU，则 N=ab b₀。
  3. df 为 A:a−1，B:b−1，AB:(a−1)(b−1)，block:b₀−1，error:(ab−1)(b₀−1)。
  4. 课程 a=b=3、b₀=3：N=27，treatment df=2+2+4=8，block df=2，error df=16，总 26。

先按 factorial 的逻辑解释 interaction 与条件效应，再按 block model 处理背景。Residual diagnostics、共同方差检查和 comparison family 仍要做；blocking 不会自动保证分布条件。

Latin square 控制两个 nuisance factors

若有两种重要 nuisance，普通 block 可能只控制其中一种。Latin square（拉丁方） 用 rows 与 columns 两个区组方向安排 treatments：每种处理在每行、每列各出现一次。

例如四种 spreadsheet treatments，在四位 secretaries 与四种 task types 的组合上测量。Rows 可以代表人员，columns 代表任务。每人经历所有软件，每类任务也经历所有软件，从而避免软件只对应某一种人员或任务。

  1. 检查方阵结构：t×t cells，t treatments，两个 blocking factors 都有 t levels。
  2. 使用合法 Latin square，并在允许的 row、column、treatment permutations 中随机化。
  3. 不能让每格独立随意抽一个字母，否则可能某 treatment 在一行重复，失去 balance。
  4. 拟合 additive treatment+row+column 模型，再核对其条件。
Y=μ+Treatment+Row+Column+ε
df treatment=row=column=t−1
error df=(t−1)(t−2)；total df=t²−1

课程 t=4，N=16，三个来源各 df=3，error df=6。SST=SStrt+SSrow+SScol+SSE。下方表格可逐行逐列核对 A–D 各一次。

每 cell 一个观测，无法独立估计重要的 treatment×row、treatment×column 或 row×column interaction，additivity 因而十分关键。t 小时剩余 error df 很少；missing observations 也会破坏正交结构，需要对应模型分析。控制两种背景后的结果，仍不自动适用于任意人员与任务总体。

在测量前检查设计是否能回答问题

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

V1全放强光区、V2全放弱光区，多测1000株有用吗？

它能更精确地估计混合差异，却无法分开品种与光照，因为两者完全confounded。要识别variety effect，需要同样光照条件中包含不同varieties或其他可识别设计。增加观测数不能补救没有比较基础。

3×3 Latin square剩多少error df？

先算9个观测的total df=8；treatment、row、column各用2个df，共6。Error df=8−6=2，也等于(3−1)(3−2)。这说明一个看起来完整的方阵仍可能只有很少误差信息。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

温室与杀虫剂：从 block 内形成比较

Greenhouse 的 15 个 experimental units 分成 5 个 blocks，每 block 包含 3 个 varieties。RCBD 的 error df=(3−1)(5−1)=8；忽略 block 后按 CRD 分析，error df=15−3=12。Blocking 同时减少部分 SSE 并消耗 df，因此效率要通过 MSE 比较。

如果一个单位缺失，各 treatment 所经历的 block 构成可能不再一样，共同背景不能像完整平衡时那样直接抵消。Insecticide×bean variety 案例同样把 treatment 问题与 block variation 分开解释；研究因素可以是 factorial，block 仍承担控制背景差异的作用。

Fixed 与 random blocks：推断到哪里

Fixed block 模型的推断针对选定的这些 levels；random block 模型把它们看作环境总体的抽样。若 Bj 与 εij 独立，Var(Bj)=σb²，则 E(MSblock)=σe²+tσb²，而 E(MSE)=σe²。

两式相减得到 moment estimate σ̂b²=(MSblock−MSE)/t。这个估计可能为负，尽管真正的 variance 不能为负；采用现代 mixed model 时要说明估计方法与约束。Treatment test 的 denominator 也应由对应模型的 expected mean squares 推导。

面包实验：factorial treatments 放进 days

Flour 3 个 levels 与 temperature 3 个 levels 形成 9 个 treatment combinations，在 3 个 days 中各完成一次，N=27。Flour、temperature、interaction、day 的 df 为 2、2、4、2；error df=(9−1)(3−1)=16。

先检查每个 day 都包含全部 9 个组合，再按模型分解。Flour 与 temperature 是研究 factors，day 是 nuisance block；factorial structure 与 blocking 可以同时存在，分别回答处理关系与背景控制问题。

秘书、任务与电子表格：Latin square 的代价

四种 spreadsheet treatments 在 4 个 secretaries×4 个 task 类型构成的方阵中安排，每个 treatment 在每行和每列各出现一次。N=16，treatment、row、column 各用 3 个 df，剩下 error df=15−9=6。

先逐行逐列检查出现次数，再写 additive model。每格只有一个观测，不能独立估计重要的 treatment×row 或 treatment×column interactions；若这些交互有科学上的可能性，应把它们作为该设计的限制说明。
