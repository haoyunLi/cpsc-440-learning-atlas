Treatment structure 与 experimental design 是两层

只改变一个因素，可能看不到处理在不同条件下如何工作。Factorial treatment structure（析因处理结构） 同时安排多个因素的所有 level combinations，既能看各自效果，也能看它们是否相互影响。

Factor（因素） 是改变的变量，例如 variety 与 fertilizer；level（水平） 是一个取值，例如 V1/V2 与 low/high。两因素有 a、b 个 levels，形成 ab 个 cells，每个 cell 有 r 个独立 repeats，则 N=abr。

Yᵢⱼₖ=μ+αᵢ+βⱼ+(αβ)ᵢⱼ+εᵢⱼₖ

i、j 指两因素的 level，k 指同一个 cell 的重复。α 和 β 表示各因素的部分，(αβ) 表示 interaction：两个因素一起作用时，不能仅用各自平均效应相加来解释的部分。

Factorial 回答“有哪些 treatment combinations”，CRD 或 RCBD 回答“把它们怎样分配给实验单位”。两因素的四个 combinations 可以完全随机分配，也可以每个 block 都包含四个 combinations。Factorial 本身不能替代 randomization。

需要区分 cell repeats 与重复测量同一单位；后者不会自动提供独立 error df。独立误差、共同方差和精确推断所需的正态条件仍要检查。

Interaction 是 simple effects 之间的差

“V2 比 V1 更好吗？”可能要先问肥料条件。Interaction（交互作用） 表示一个因素的效应随另一个因素的水平改变，因此一个跨条件的平均数可能掩盖重要差别。

  1. 固定低肥条件。 V1 mean=10、V2=12，variety 的 simple effect 是 12−10=2。
  2. 固定高肥条件。 V1=14、V2=20，simple effect 是 20−14=6。
  3. 比较这两个效应。 Difference-of-differences I=6−2=4。同一个 variety change 在高肥下的效果更大。
  4. 再看 main effect。 等权平均两个 simple effects 得到 (2+6)/2=4；它有意义，但没有说明低肥下为 2、高肥下为 6。
I=(μ₂₂−μ₁₂)−(μ₂₁−μ₁₁)
cell interaction deviation=μᵢⱼ−μᵢ.−μ.ⱼ+μ..

Interaction plot 把一个 factor 放横轴，用另一 factor 的不同线表示。平行线对应 additive means；不平行表示 estimated interaction，不必交叉。下方四个滑块直接对应四个 cell means：先让两条线斜率相同，再改变一个 cell，观察 I 如何变化。

图显示的是 estimates，未显示 uncertainty；是否有充分证据支持 interaction 仍需 error estimate 与 replication。课程 car×transmission 和 notes 的 asphalt aggregate×compaction 是两个不同场景，都应先解释固定条件下的 simple effects。

不同课程或软件可能把 two-level “interaction effect” 定义成上述 I 的一半，或使用 cell deviations。报告数值时先注明定义，避免把不同尺度相互替代。

Balanced design 让 A、B 与 interaction SS 分开

Complete balanced design 中，每个 cell 数量一样，让 A、B、AB 与 cell 内 error 可以按清楚的正交结构分开。先计算 cell means、两方向 marginal means 和 grand mean，再依次计算平方和。

SSA=brΣ(ȳᵢ..−ȳ...)²
SSB=arΣ(ȳ.ⱼ.−ȳ...)²
SSAB=rΣᵢΣⱼ(ȳᵢⱼ.−ȳᵢ..−ȳ.ⱼ.+ȳ...)²
SSE=ΣᵢΣⱼΣₖ(Yᵢⱼₖ−ȳᵢⱼ.)²

A 的一个 marginal mean 代表 br 个观测，所以中心偏差平方乘 br；B 同理。AB 先从 cell mean 中扣除两种 marginal effects，再加回被扣两次的 grand mean；error 则只看每个观测离自己 cell mean 多远。

从 factorial ANOVA 接到 main-effect Tukey 比较

原创完整例题。 三种培养处理 A1/A2/A3 与两个固定光照条件 B1/B2 组成 3×2 factorial。六种组合随机分配给 18 个独立花盆，每格 r=3；Y 是每盆干物质，单位 g。这里采用 balanced complete fixed-effects model：所有 cells 都有等量独立重复，A、B 水平均为固定水平，errors 独立正态且有共同 variance σ²。预先指定的比较 family 是三个 A marginal means 的全部三对。

  1. 先写 estimand。 μᵢ.=(μᵢ,B1+μᵢ,B2)/2，把两种光照条件各赋一半权重。要比较的是 μ₂.−μ₁.、μ₃.−μ₁.、μ₃.−μ₂.，估计分别为 2、4、2 g。它不是某一个光照条件内的 simple effect，也不是任意自然光照构成下的平均差。
  2. 从完整模型保留误差。 拟合 Y~A*B。每格相对均值的偏差为 −1、0、1，各贡献 SSE=2；六格 SSE=12，error df=ab(r−1)=3×2×2=12，所以 MSE=1。完整表给出 SSA=48、SSB=450、SSAB=0，A 的 F=(48/2)/1=24、P=.000064。样本 SSAB=0 不证明总体 interaction 精确为零；也不据此悄悄改用另一模型的 error df。
  3. 把 cell 数量换成 marginal mean 的精度。 对 A，ȳᵢ.. 是 b 个独立 cell means 的等权平均；每个 cell mean 的 variance 为 σ²/r，所以 Var(ȳᵢ..)=(1/b²)×bσ²/r=σ²/(br)。因此 A 每个 marginal mean 对应 br=2×3=6 个观测；对 B 则为 ar=3×3=9。不能把每格 r=3、总 N=18 或 error df=12 直接填入此处的 n。
  4. 形成 Tukey 同时区间。 三个 A means 的 q critical 为 q_.95(3,12)=3.772929；共同半宽 H=q×√[MSE/(br)]=3.772929×√(1/6)=1.540292 g。每一对的 SE 是 √[2MSE/(br)]，而 studentized-range 尺度是 SE/√2；不要把 q 直接乘 pairwise SE。Adjusted P 用 q_obs=|差|/√[MSE/(br)] 的 studentized-range 右尾。

# Original balanced complete 3-by-2 fixed-effects design, three pots per cell.
d <- expand.grid(replicate=1:3, B=factor(c("B1","B2")),
                 A=factor(c("A1","A2","A3")))
d$y <- rep(c(10,20,12,22,14,24),each=3)+rep(c(-1,0,1),6)
fit <- aov(y ~ A*B,data=d)
print(with(d,table(A,B)))
cell_mean <- with(d,tapply(y,list(A,B),mean))
print(cell_mean)
print(summary(fit))
a <- nlevels(d$A)
b <- nlevels(d$B)
r <- 3
error_df <- df.residual(fit)
mse <- deviance(fit)/error_df
marginal_A <- rowMeans(cell_mean)
marginal_B <- colMeans(cell_mean)
print(c(A_observations_per_mean=b*r,B_observations_per_mean=a*r,
        MSE=mse,error_df=error_df))
print(marginal_A)
print(marginal_B)
# The prespecified family contains all three pairs of A marginal means only.
pairs <- combn(seq_len(a),2)
labels <- apply(pairs,2,function(z) paste0(rownames(cell_mean)[z[2]],"-",
                                         rownames(cell_mean)[z[1]]))
estimate <- apply(pairs,2,function(z) marginal_A[z[2]]-marginal_A[z[1]])
q_scale <- sqrt(mse/(b*r))
critical <- qtukey(.95,nmeans=a,df=error_df)
half <- critical*q_scale
p_adj <- ptukey(abs(estimate)/q_scale,nmeans=a,df=error_df,lower.tail=FALSE)
manual <- data.frame(pair=labels,diff=estimate,lwr=estimate-half,
                     upr=estimate+half,p_adj=p_adj)
print(c(q_critical=critical,half_width=half))
print(manual,row.names=FALSE)
tk <- TukeyHSD(fit,which="A",conf.level=.95)$A
print(tk)
stopifnot(error_df==12,abs(mse-1)<1e-10,
          max(abs(tk[labels,"diff"]-estimate))<1e-10,
          max(abs(tk[labels,"lwr"]-(estimate-half)))<1e-10,
          max(abs(tk[labels,"upr"]-(estimate+half)))<1e-10,
          max(abs(tk[labels,"p adj"]-p_adj))<1e-10)
# Omitting B changes the model and pools its systematic variation into residuals.
A_only <- aov(y ~ A,data=d)
wrong_mse <- deviance(A_only)/df.residual(A_only)
wrong_half <- qtukey(.95,nmeans=a,df=df.residual(A_only))*
              sqrt(wrong_mse/(b*r))
print(c(omitted_B_SSE=deviance(A_only),omitted_B_df=df.residual(A_only),
        omitted_B_MSE=wrong_mse,omitted_B_half_width=wrong_half))
print(TukeyHSD(A_only,which="A"))
stopifnot(abs(wrong_mse-30.8)<1e-10)

Three-way interaction 问的是“二阶关系是否再次改变”

三个因素时，除了 A、B、C 各自的效应，还有三个 two-way interactions。Three-way interaction 问的是更具体的一件事：例如 A×B 的关系，会不会随着 C 改变？

Y=μ+A+B+C+AB+AC+BC+ABC+ε

可以把每个 C level 单独画一个 A×B profile。若这些图中的 difference-of-differences 改变，就存在 estimated ABC interaction。这样逐层看，比直接盯着软件里一行 ABC 更容易说明研究含义。

a×b×c、每 cell r repeats 时，main df 为 a−1、b−1、c−1；AB df=(a−1)(b−1)，AC、BC 同理；ABC df=(a−1)(b−1)(c−1)；error df=abc(r−1)。

课程 noise×group×experience 是 3×2×3、r=3，N=54。Main df=2,1,2；two-way df=2,4,2；ABC df=4；error df=36，总和为 53。先判断高阶 interaction 是否改变所关心的效应，再看相应条件下的 profiles，不要在明显交互下只列一个平均排名。

某个 group 若是自然属性而不是随机分配的 treatment，差异也不能自动解释成因果。Residual diagnostics 使用全部 factors 形成的 fitted cell means；漏掉 interaction 后，相关的系统差异可能被误当成 noise。

  1. 先算 A 的 simple effects。 C1 中，B1 下 A2−A1=14−10=4，B2 下为20−12=8。C2 中，对应为14−10=4与14−14=0。这四个数字是条件差的点估计，还不是四项已经通过多重校正的结论。
  2. 在每个 C 内算 AB。 Δ̂AB|C1=8−4=4；Δ̂AB|C2=0−4=−4。即从 B1 变到 B2，估计的品种差在 C1 增加4 g，在 C2 却减少4 g。
  3. 比较两个 AB。 L̂=(−4)−4=−8 g。它是八个 cell means 的线性组合，每项系数为+1或−1；“difference of differences of differences”仍保留响应单位g，不是g³。
  4. 用完整模型估计 uncertainty。 每格偏差为−1、0、1，贡献SSE=2；总SSE=16，error df=abc(r−1)=8×2=16，MSE=1。八个独立cell means各有variance σ²/r，因此 Var̂(L̂)=8MSE/r=8/3，SE=1.632993。这里r=3是每格的独立重复数，不是总N=24。
  5. 完成预定的两侧推断。 t=−8/1.632993=−4.898979，df=16，双侧P=.000160534。95% CI为−8±t_.975,16×1.632993≈[−11.461791,−4.538209] g。在模型条件下，支持两种供水条件的AB关系不同，且C2的AB contrast低于C1。

为什么这里能用 t² 核对整体 ABC？ 2×2×2 的 ABC 只有(2−1)³=1个df；零三阶交互等价于L=0。其SSABC=L̂²/(8/r)=rL̂²/8=24，因此 FABC=(24/1)/MSE=24=t²，参考F(1,16)，右尾P与上述双侧t完全相同。

读表时不要把“平均”偷换成“每个条件”。 跨C等权平均后，四个A×B cell means为[A1B1=10，A1B2=13，A2B1=14，A2B2=17]；A2−A1在两种B下都为4，所以边际AB contrast=(4+−4)/2=0。这解释AB行的F=0，而不是证明C1和C2内都没有AB interaction。ABC行比较的是4与−4是否有差，两行问的不是同一个问题。

Missing data 会让 averaging 与 adjustment 分叉

每个 cell 的样本数量不一样时，“平均”先要说明按什么权重。Raw marginal mean 按实际观测数加权；least-squares mean / estimated marginal mean 根据 fitted model，在指定 reference grid 上平均，常用 equal-cell weighting。

  1. V1 的低肥 cell 有 9 个观测，mean=10；高肥有 1 个，mean=20。
  2. Raw mean=(9×10+1×20)/10=11，主要代表低肥下的构成。
  3. 若目标是两种肥料条件各占一半，equal-cell mean=(10+20)/2=15。
  4. V2 两个 cell 等量且 means=12、18，其 raw 与 equal-cell means 都为 15。

所以 raw 的 11 vs 15 包含不一样的肥料构成，不能直接当作调整后 variety effect。选择权重要对应目标总体或明确的比较条件，而不是为了得到想要的结果。

Unequal replication 也破坏了前面的简单 SS 分解。Type I SS 按变量加入顺序计算增量；Type II SS 先调整其他不包含目标项的效应；Type III SS 针对特定 adjusted hypotheses，依赖 model、coding 和 estimability。不能一概说其中一种“总是更正确”。

Missing cell 与少几个观测不同：某些 interactions 或 marginal contrasts 可能根本 non-estimable。软件可以在有模型依据的范围内调整，却不能凭空恢复缺失信息。不要补 0；报告 missing mechanism、模型、权重和仍可估计的问题。

共同目标构成可以不是各占一半

如果研究目标预先规定 Low 占75%、High占25%，就把同一组权重用于两个品种。V1的目标均值为.75×10+.25×20=12.5；V2为.75×12+.25×18=13.5，因此目标差V2−V1为1。它既不同于各组按自身样本构成算出的raw difference=4，也不同于两种条件各半时的差0。

设 w 为目标 High 比例：
D(w)=(1−w)(μ₂,Low−μ₁,Low)+w(μ₂,High−μ₁,High)
本例 D̂(.25)=.75×2+.25×(−2)=1

差异来自回答了不同的问题：目标构成由目标总体、研究用途或预定比较确定，不能看到结果后再选择最有利的权重。有interaction时，先报告各条件的simple effects，再解释为什么需要这个跨条件平均。改变样本数会影响估计精度；这里的点估计比较不能代替区间或检验，也不会解决missing cell的不可估计问题。

四个系数，为什么只有三个可识别的方向？

以A1、B1为reference，令I(A2)在A2行等于1、其余为0，I(B2)同理。完整模型可写成下面四个系数；这里用γ表示该编码下的interaction系数。

E(Y|A,B)=β₀+βA I(A2)+βB I(B2)+γ I(A2)I(B2)
μ₁₁=β₀；μ₁₂=β₀+βB；μ₂₁=β₀+βA；μ₂₂=β₀+βA+βB+γ

Design matrix X每一行对应一条观测，每一列对应一个系数。三种已观测cell的行分别为[1,0,0,0]、[1,0,1,0]、[1,1,0,0]，各重复两次。没有任何行使I(A2)I(B2)=1，所以第四列全为0：X有4列，但rank只有3。Rank在这里表示数据能独立识别的系数方向数；三个cell的均值只提供三个方向的信息。

两条线没交叉，可以有interaction吗？

先在两个B levels分别求A的simple effect，再相减。只要两个simple effects不同，就有estimated interaction，无需交叉。还需error与replication才能判断这个差是否有充分统计证据。

每cell只有一次测量，能分别估interaction与error吗？

普通完整fixed-effects two-way模型r=1，所以error df=ab(r−1)=0。Cell差异可以被interaction吸收，没有cell内重复提供独立noise估计。需要适用的额外假设或独立replication，不能悄悄把interaction当error。

Interaction 之后怎样检验 simple effects：先固定比较 family

总体 interaction 检验回答“一个因素的效应是否随另一个因素改变”，但没有直接回答“在哪个条件下，哪两个 treatments 相差多少”。Simple effect / slice（条件效应检验） 把另一个因素固定下来，形成具体的均值比较。它仍应使用完整模型对应的误差估计。

三个levels一起比较：slice的联合F怎样计算？

沿用上面相同的完整2×3原创数据，换一个明确的问题：固定A1时，B1/B2/B3的总体均值是否相等？固定A2时呢？ A与B均为fixed factors，各cell仍有r=4个独立实验单位。本段使用完整模型Y~A*B，假定所有六个cells的errors独立、正态且有共同variance。

用covariance核对；为什么不能把两个t²直接相加？

在A2处，取两个contrast：d=[μA2,B2−μA2,B1，μA2,B3−μA2,B1]ᵀ，估计d̂=[4,8]ᵀ。每个cell mean的估计variance为MSE/r=5/12。两个差都减去B1，所以有正covariance：

V̂=(MSE/r)[2，1；1，2]
=[5/6，5/12；5/12，5/6]
F=(d̂ᵀV̂⁻¹d̂)/2=38.4

这与均值SS方法完全一致。两个contrast共享B1，不能把两个单独t²直接相加来构造联合检验。公式里的除以2对应两个独立约束；一个contrast的t²只等于相应1-df的F。

三个检验问题要分开。 上述两个slice检验各问一个A条件下的B效应；完整A×B interaction检验问B的效应模式是否随A改变。不能仅凭“一个slice显著、另一个不显著”宣称interaction显著，也不能用interaction不显著来证明所有slice为零。前段已经单独计算了本例的interaction。若分开拟合A1、A2的子集模型，每个只剩9个error df；即使这份构造数据恰好给出相同MSE，也不是这里用完整模型18 df的检验。

  2. 在每个 cell 内转换响应。 Zij=|Yij−median(Y in cell i)|。前四格的 Z 都是 [1.5,.5,.5,1.5]；第五格为 [3,1,1,3]，第六格为 [6,2,2,6]。
  3. 计算 Z 的 between-cell SS。 六个 Z means 为 1,1,1,1,2,4，grand mean=5/3；SSbetween=4Σ(Z̄i−5/3)²=88/3≈29.3333，df=6−1=5。
  4. 计算 Z 的 within-cell SS。 前四格各贡献 1，第五格贡献 4，第六格贡献 16，所以 SSEz=24，error df=24−6=18，MSEz=4/3。
  5. 对转换后的响应作一次整体检验。 F=(29.3333/5)/(24/18)=4.4，以 F(5,18) 近似参考得到 P≈.0085815。这是 cell 间 spread 不一致的诊断证据，不是原始六个 means 的检验。

为什么不是 A:B 那一行？ 完整 factorial ANOVA 的 interaction 行 df=(2−1)(3−1)=2，回答的是 interaction 参数问题。这里需要把六个 cells 的 Z means 同时比较，numerator df 是 5。对 3×2×3 的课程案例，对应 k=18、between-cell df=17、error df=54−18=36；不能拿 ABC 单项的 4 df 来代替。

最后的 TRUE 解释了课程讲义为什么有时从完整 factorial 模型的 residuals 开始：在本例完整 cell 模型中，同一 cell 的 residual 只是 y 减去一个常数，而 median-centered absolute deviations 对这种平移不变。但直接拟合 residual ~ cell、不取 absolute deviations，会遇到各 cell residual mean 本来就是 0 的情况，不能用那个 P 值判断等方差。

条件与行动。 Brown–Forsythe 的 F 参考是近似，四个观测一格的本例用于学会计算，不能保证小样本校准完美；它对 spread 的解释还需要结合各组分布形状。未拒绝不证明方差完全一样，拒绝也不直接告诉我们该删除哪一格。若需要比较 means，应重新评估误差模型与推断方法。这个复现是独立误差的 factorial CRD；含 random blocks 或 repeated measurements 时，还需处理对应的相关结构，不能把本段直接当成通用 mixed-model 方差检验。

不平衡factorial的三种SS：同一数据，不同假设

不平衡设计不是把每格n换一下就结束了。相同完整模型可以提出不同的假设，得到不同的平方和；顺序、调整对象和平均权重都必须说明。本节用一份原创3×2数据，把Type I、II、III从观测一直算到F与P，不依赖额外R包。

A为三个品种，B为两种培养条件，每个观测来自独立实验单位。六个cells都存在，只是重复数不同；这与整个cell为空不同。拟合fixed-effects完整模型Y=μ+A+B+AB+ε，假定独立正态、共同variance误差。

Type II：先调整其他不包含目标项的因素

检验A时先调整B，但不先加入包含A的AB项：SSA(II)=SSE(B)−SSE(A+B)=142.763677。类似地SSB(II)=SSE(A)−SSE(A+B)=42.408122；interaction仍比较加性与完整模型，SSAB=.791878。这套构造不随A、B的输入顺序改变。

这里“没有先加入AB”不表示把研究中的interaction证明为0。Type II A在本不平衡设计中对应按cell counts加权的加性投影里A的增量，并不是下面Type III的等权边际假设；当完整模型允许interaction时，这些假设可以包含interaction成分。若科学上需要条件效应，应该明确做simple effects，不能把所有“main effect”标签看成同一问题。
