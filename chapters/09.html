比较越多，至少一次 Type I error 越常见

一次检验的 α=.05，不表示做完一批检验后，整个研究误报概率仍是 .05。比较得越多，至少碰到一个假阳性的机会通常越大。这里要区分单个比较和整组决策。

Comparisonwise error rate 描述单个检验；familywise error rate（FWER，也称 experimentwise） 描述一个事先定义的 family 中，至少错误拒绝一个真实 null 的概率。t 个 treatments 的全部两两比较有 t(t−1)/2 对，例如 5 组有 10 对。

独立且 null 全真实：FWER=1−(1−αᵢ)ᵐ
Bonferroni：单个阈值 α/m；adjusted P=min(1,mP)
  1. 先看“全部不误报”。独立的 20 个 null tests，每个不误报概率为 .95，全部不误报概率为 .95²⁰。
  2. 取补集，至少误报一次的概率为 1−.95²⁰≈.6415。
  3. 若目标 family α=.05，Bonferroni 将每个阈值设为 .05/20=.0025。
  4. 这个控制来自 union bound，不要求 tests 独立；上面的 .6415 公式则要求独立，不能直接当实际 pairwise tests 的精确 FWER。

共享同一组观测的 pairwise tests 通常相关。因此下方独立实验是解释累积风险的模型示例，不能把图上曲线套到所有 comparisons。Family 应围绕研究决策预先确定，不能只把结果显著的几项留下来，再按留下数量校正。

课程 weed-control 例先写四个具体问题，再按 m=4 考虑 Bonferroni。先问需要回答哪些问题，通常比先运行所有 comparisons 更容易得到清楚且有效率的分析。

Linear combination 先把研究问题写成 coefficients

Linear combination（线性组合） 用系数把一个研究问题翻译成均值的加减。Contrast（对比） 是其中系数和为 0 的一种：它比较相对差异，不受所有均值共同加上一个常数的影响。

L=Σaᵢμᵢ；L̂=Σaᵢȳᵢ；contrast 要求 Σaᵢ=0
SE(L̂)=√[MSE×Σ(aᵢ²/nᵢ)]
  1. 先写问题。 有 control、A、B、C 四组，想比较 control 与三种处理的平均。
  2. 写 coefficients。 用 [1,−1/3,−1/3,−1/3]，和为 0。若均值是 [10,12,14,16]，L̂=10−(12+14+16)/3=−4。
  3. 算不确定性。 每组 n=4、MSE=4。Σaᵢ²=1+3×(1/9)=4/3，所以 SE=√[(4/4)×4/3]≈1.1547。
  4. 标准化。 检验 L₀=0 时 t=−4/1.1547≈−3.464，使用原 ANOVA 的 error df。
  5. 按 family 给 CI 或 P。 单个预定问题与一组 simultaneous comparisons 的 critical value 不一定相同。

若只想估计三种 active treatments 的平均，用 [0,1/3,1/3,1/3]，系数和为 1，所以它是 linear combination，但不是 contrast。把所有组加 10，这个平均增加 10；control−active average 则不变。

SScontrast=L̂²/Σ(aᵢ²/nᵢ)；1-df F=t²（检验 L₀=0）

这些公式使用共同 MSE 与独立组的模型条件。把所有系数同时乘 3，会把 estimate 与 SE 都乘 3，t 的绝对值不变；乘负数还会反转方向。下面的 SAS 语句转换正是利用这个性质避免分数。

把这个contrast算到P-value与CI

继续用组均值[10,12,14,16]、每组n=4、共同MSE=4。先指定这是一个事先选定的双侧问题：H₀:L=0，对Hₐ:L≠0，其中L=μcontrol−(μA+μB+μC)/3。总样本量16，估计4个组均值，所以ν=N−t=12。

L̂=−4；SE=√(4/3)≈1.154701
tobs=−3.464102；F=tobs²=12
P双侧=2P(t₁₂≥|tobs|)≈.004681605
95% CI：−4±t.975,12×1.154701
=[−6.515876,−1.484124]

这是单个预定contrast的ordinary interval。在α=.05下拒绝L=0；负的estimate与整个负区间表明，对照总体mean低于三种active总体means的等权平均。它没有证明每一种active都分别优于control。如果这一问题属于更大的family，应采用配套的simultaneous interval与adjusted P。

为什么F只对应双侧t检验？ 平方把t=−3.464与t=+3.464都变成F=12，因此F右尾同时收集两个方向，得到与双侧t相同的P。若事先指定Hₐ:L<0，P≈.002340802；若事先指定Hₐ:L>0，P≈.997659198。不能先看到负号再改变方向，也不能把F的右尾P当作这两个单侧P。

group_means <- c(control=10,A=12,B=14,C=16)
ni <- rep(4,4)
mse <- 4
weights <- c(1,-1/3,-1/3,-1/3)
error_df <- sum(ni)-length(ni)
estimate <- sum(weights*group_means)
se <- sqrt(mse*sum(weights^2/ni))
t_obs <- estimate/se
f_obs <- t_obs^2
# The F tail equals the two-sided t probability, not either one-sided tail.
p_two <- 2*pt(-abs(t_obs),df=error_df)
p_f <- pf(f_obs,1,error_df,lower.tail=FALSE)
p_left <- pt(t_obs,error_df)
p_right <- pt(t_obs,error_df,lower.tail=FALSE)
ci <- estimate+c(-1,1)*qt(.975,error_df)*se
print(c(estimate=estimate,SE=se,df=error_df,t=t_obs,F=f_obs,
        p_two=p_two,p_F=p_f,p_left=p_left,p_right=p_right))
print(c(lower=ci[1],upper=ci[2]))
stopifnot(error_df==12,abs(p_two-p_f)<1e-12,
          abs(p_two-.00468160475316)<1e-12)

先自己写系数：把等权比较翻译成 contrast

原创自检，先写再展开。 四组独立盆栽分别接受对照 C、缓释配方 L1、缓释配方 L2、常规配方 H，响应为生长结束时的根长（cm）。参数顺序固定为 [μC, μL1, μL2, μH]。研究者事先要比较“两种缓释配方的总体均值等权平均”与“C、H 两个常规处理的总体均值等权平均”，方向为缓释平均减常规平均。请先只根据这句话写 L 与四个系数，检查系数和；再用按同一顺序给出的样本均值 [12,15,17,14] cm 计算 L̂。各组 n=[4,8,6,10]，是否应该因此改变这个等权问题的系数？最后写出反向比较的系数与解释。

写好系数与目标量后，展开逐步核对
  1. 先把两侧各自的平均写全。 L=(μL1+μL2)/2−(μC+μH)/2。按题目指定顺序，c=[−1/2,1/2,1/2,−1/2]，Σc=0，因此它是 contrast。
  2. 单位与方向保持一致。 L̂=−12/2+15/2+17/2−14/2=3 cm。正号表示两种缓释配方的总体均值等权平均，被估计为比两个常规处理的等权平均高 3 cm；它不表示每一种缓释配方都比每一个常规处理高 3 cm，也没有仅凭估计值完成显著性检验。
  3. 样本量改变精度，不自动改变这个目标。 研究问题明确对配方等权，所以各侧仍各占 1/2。不应按 n 把样本更多的配方赋更大目标权重；n 应进入前面的 SE 公式。若改成按观察数量加权的平均，就回答了另一个问题。
  4. 反向比较要把全部符号一起反转。 “常规平均减缓释平均”对应 [1/2,−1/2,−1/2,1/2]，L′=−L，估计为 −3 cm。其负号与原来正的 3 cm 表达同一事实。若原先的单侧问题是 L>0，换成 L′ 后相同科学方向应写 L′<0，而不是保留大于号。

常见错误： [−1,1,1,−1] 的系数和也为零，但表示两个“总和”的差，即 2L，估计为 6 cm；检验是否为 0 的双侧结论虽不因整体正比例缩放改变，不能仍把这个 6 cm 叫作题目要求的两个等权平均之差。系数和为零只是必要的结构检查，还要核对顺序、权重及科学解释。

Orthogonality 连接设计的独立信息

两个 contrasts 都合法，不表示它们使用了独立方向的信息。Orthogonality（正交性） 通过 coefficients 与样本数，判断两个线性估计是否在共同方差模型下不相关。

Cov(L̂ₐ,L̂ᵦ)=σ²Σ(aᵢbᵢ/nᵢ)
正交条件：Σ(aᵢbᵢ/nᵢ)=0

Equal n 时，公共的 1/n 可以提出，条件简化为 Σaᵢbᵢ=0。用三组作例子：a=[−2,1,1] 问第一组与后两组的平均差，b=[0,1,−1] 问后两组之间的差。内积为 (−2)×0+1×1+1×(−1)=0，因此这两个方向正交。

直观上，a 将后两组同等看待，b 则在后两组之间比较高低。二者没有把同一个平均差方向重复使用。t 个组均值共有 t−1 个 contrast dimensions；完整正交组可以分解 treatment SS。

样本数不同，必须回到加权条件。例如后两组 n 不同，1/n 的权重不再抵消，刚才的 coefficients 未必仍正交。在 normal model 下，零 covariance 的线性估计独立；但由它们形成的 t/F statistics 还可能共享估计 MSE，不能据此一概取消 multiplicity 处理。

正交方向怎样加回ANOVA的treatment SS

回到Chapter 8的原创数据A=[4,5,6]、B=[7,8,9]、C=[10,11,12]。组均值为5、8、11，各n=3；SStrt=54、MSE=1、error df=6。用本节已有a=[−2,1,1]与b=[0,1,−1]作为完整的两个contrast方向。

每个方向贡献1个df的平方和
方向估计值L̂Σaᵢ²/nᵢSScontrast
a=[−2,1,1]−2×5+8+11=9(4+1+1)/3=29²/2=40.5
b=[0,1,−1]8−11=−3(0+1+1)/3=2/3(−3)²/(2/3)=13.5

a估计的是2×[(μB+μC)/2−μA]，所以9是平均差4.5的两倍；将整行系数除以2会使estimate与SE同时减半，但不改变SS、|t|或F。b则直接估计μB−μC。

Σaᵢbᵢ/nᵢ=0；两个方向正交
SSa+SSb=40.5+13.5=54=SStrt
1+1=2=treatment df

这让整体组间差异分解成两个明确的科学问题。组内SSE与MSE仍是同一模型提供的误差参照，没有为每个contrast重新拟合一套噪声。

任意两个合法contrast不能这样相加。 如果改成A−B与B−C，两者都使用B，按正确的1/n加权内积不为0。它们各自SS为13.5，直接相加只有27，并不等于54。非正交方向可以做推断，但其SS不构成上述互不重叠的分解；和也不保证总比SStrt大或小。

d <- data.frame(group=factor(rep(c("A","B","C"),each=3)),
                y=c(4,5,6,7,8,9,10,11,12))
fit <- aov(y ~ group,data=d)
group_means <- as.numeric(tapply(d$y,d$group,mean))
ni <- as.numeric(table(d$group))
error_df <- df.residual(fit)
mse <- sum(residuals(fit)^2)/error_df
C <- rbind(A_vs_BC=c(-2,1,1),B_vs_C=c(0,1,-1))
# This matrix equals the covariance matrix divided by the common variance.
covariance_factor <- C %*% diag(1/ni) %*% t(C)
estimate <- as.vector(C %*% group_means)
ss_contrast <- estimate^2/diag(covariance_factor)
sstrt <- sum(ni*(group_means-weighted.mean(group_means,ni))^2)
print(covariance_factor)
print(data.frame(estimate=estimate,SS=ss_contrast,df=1,
                 F=ss_contrast/mse,
                 p=pf(ss_contrast/mse,1,error_df,lower.tail=FALSE)))
print(c(sum_contrast_SS=sum(ss_contrast),treatment_SS=sstrt))
stopifnot(abs(covariance_factor[1,2])<1e-12,
          abs(sum(ss_contrast)-sstrt)<1e-12)
# A nonorthogonal basis does not give an additive SS decomposition.
C_other <- rbind(A_minus_B=c(1,-1,0),B_minus_C=c(0,1,-1))
L_other <- as.vector(C_other %*% group_means)
ss_other <- L_other^2/rowSums(sweep(C_other^2,2,ni,"/"))
print(c(sum_nonorthogonal_SS=sum(ss_other),treatment_SS=sstrt))

从 cell means 转换到 SAS model coefficients

把研究问题写成 cell means 还不够，软件需要的是它使用的 model coefficients。课程 wood-treatment 例把 μᵢ=μ+τᵢ 代入，解释为什么某些 ESTIMATE 语句必须包含 intercept。

  1. 从目标表达式出发。 三个 active means 的平均为 (μA+μB+μC)/3。
  2. 换成模型参数。 每个 μᵢ=μ+τᵢ，因此这个平均为 μ+(τA+τB+τC)/3。
  3. 避免分数。 将整式乘 3，intercept coefficient 变成 3，三个 active coefficients 为 1，control 为 0。
  4. 还原尺度。 用 divisor=3。若是系数和为 0 的 contrast，intercept 项会抵消，不需要这里的 3。

SAS 语法示意。 此段需在 SAS 中使用，先准备包含响应 y 与四水平 treatment 的数据集 d，并确保 CLASS 输出顺序为 control、A、B、C；这里没有提供该数据集，不能直接作为独立的 R 脚本运行。它用于对照参数表达式与语句系数。

/* 先核对 CLASS levels 的实际输出顺序 */
proc glm data=d;
 class treatment;
 model y=treatment;
 contrast 'Control vs active average' treatment 3 -1 -1 -1;
 estimate 'Mean of active treatments' intercept 3
          treatment 0 1 1 1 / divisor=3;
run;

第一条是 control 与 active average 的等比例 contrast；第二条估计 active mean，本身不是 contrast。Levels 排序若与想象不同，即使代码运行成功，也可能计算了另一个问题。先写 cell-mean expression，再核对软件 parameterization 和 estimability。

R 中应从同一个 fitted model 的 covariance matrix 或适用的 emmeans comparisons 取得结果。不要为了每一对比较重新拟合小模型而丢掉共同 MSE。报告 estimated contrast、SE、df、CI 与 adjusted P，labels 用完整研究问题表达。

Fisher’s LSD 为什么可能过度发现差异

Fisher’s least significant difference（LSD） 把两组均值差的 t-test 写成一个原单位阈值。Equal n 时，只要两均值的绝对差超过 LSD，就按该单个比较规则拒绝相等。

LSD=t₁₋α/₂,ν√(2MSE/n)

根号项是两均值差的 SE，t critical 把它换成“多大均值差才跨过门槛”。例如同一 MSE 下，n 增加会降低门槛；但这并没有解决做很多次比较的累积误报。

Unprotected LSD 直接做所有 pairwise t-tests，主要控制单个 comparison 的错误率。Protected LSD 要先通过 omnibus ANOVA 再做比较，提供某些条件下的保护，却不能一般地声称对任何 true/false null 配置都强控制 FWER。课程 20 组相同总体的模拟就是提醒：全部 190 对一起搜索，可能出现不少看似显著的差异。

软件的 mean-separation letters 也容易被过度解读。没有共同字母，表示按指定 method 与 α 拒绝该 pair 的相等；共享字母只是未拒绝，不能说生物学上相同。A与B未拒绝、B与C未拒绝，并不推出 A与C也未拒绝，因为未拒绝不是相等关系。

下一节按研究 family 选择方法。重点不是一味寻找更大或更小的阈值，而是让阈值保护的对象与实际决策一致。

当各组n不等时，每对需要自己的SE与LSD。接着用16个原创观测，逐对计算LSD与Tukey–Kramer区间。

让 correction 匹配你真正做的比较

选 multiplicity method，先列需要保护的 comparisons。全部 pairs、每处理对 control、以及任意事后 contrast，范围不同，因此 critical values 也不同。

研究问题决定要保护的 family
方法保护范围等样本量时的阈值
Tukey HSD / W全部 pairwise comparisonsq₁₋α(t,ν)√(MSE/n)
Dunnett D各 treatment 对一个 controld(α,t−1,ν,tail)√(2MSE/n)
Scheffé S全部 possible contrasts√[(t−1)F₁₋α(t−1,ν)]×SE(L̂)
Bonferroni预定 m testst₁₋α/(2m),ν×SE(L̂)

Tukey 使用 studentized range q，比较最大与最小均值形成的范围，不是普通 t。Unequal n 的 Tukey–Kramer 阈值为 q√[(MSE/2)(1/nᵢ+1/nⱼ)]。

Dunnett 利用多个比较共享 control 的相关结构。例如五组只关心四个 active-vs-control，不需要额外保护六个 active-vs-active。单侧或双侧版本仍需预先选择。

Scheffé 保护所有 contrast 方向，范围比“全部 pairs”更广，所以针对某一个 pair 的 power 可能更低。Bonferroni 则按预定 m 分配错误预算，通用但可能保守。

课程 floor heat-loss 用同一数据与 MSE 对照这些方法。结果不同，不表示可以按哪个显著来挑哪个；应先按研究问题选 family 和 method，再解释 evidence。假设也要匹配，上表基于共同方差 ANOVA 结构。

完整 R 软件示例。 使用第 8 章的九个原创观测，预先把 A–B、A–C、B–C 三个 pairs 定为同一 family。两种方法使用相同 ANOVA 数据与共同 MSE；它们不是课程 floor heat-loss 原始数据的复算。

# Reuse the original three-group ANOVA data, with all three pairs as the family.
d <- data.frame(group=factor(rep(c("A", "B", "C"), each=3)),
                y=c(4, 5, 6, 7, 8, 9, 10, 11, 12))
fit <- aov(y ~ group, data=d)
summary(fit)
TukeyHSD(fit, which="group", conf.level=.95)
# pool.sd=TRUE uses one residual SD pooled across all groups.
pairwise.t.test(d$y, d$group, alternative="two.sided",
                p.adjust.method="bonferroni", pool.sd=TRUE)

模型得到 MSE=1、error df=6。Tukey 输出 B−A 与 C−B 的差均为 3，family-wise 95% CI≈[.4948,5.5052]、adjusted P≈.02423；C−A 的差为 6，CI≈[3.4948,8.5052]、adjusted P≈.0007942。Bonferroni 对同一三个比较的 adjusted P 分别约为 .03121、.0009749、.03121。两种校正在本例均拒绝三个零差假设；数值不同来自对整个 family 的不同保护方式，而非重新为每一对拟合不同误差模型。

Scheffé：把一般contrast算到同时区间

继续用四组means[10,12,14,16]、各n=4、MSE=4、ν=12，目标仍为L=μcontrol−(μA+μB+μC)/3。Scheffé保护这四个总体均值的全部contrast方向，因此乘子取决于contrast空间维数t−1=3，不是这次恰好列出了多少个问题。

  1. 保留同一个estimate与SE。 L̂=−4，SE=1.154700538。
  2. 构造同时乘子。 cS=√[3F.95(3,12)]≈3.235874605。
  3. 得到原单位区间。 half-width=cS×SE≈3.736466148，所以95% simultaneous CI为[−7.736466148,−.263533852]。
  4. 把临界值反演成adjusted P。 因tobs²/(t−1)=12/3=4，所以PScheffé=P[F(3,12)≥4]≈.034590357。与.05比较时拒绝L=0。

这里的F(3,12)是为所有contrast方向提供同时保护的参考；单个contrast未经校正的1-df检验仍用F(1,12)。两者不能交换分子df。所有公式仍依赖同一个独立、正态、共同variance的ANOVA模型。

与预定Bonferroni family对照。 若在看数据前只计划三个问题：control−active average、A−(B+C)/2、B−C，则m=3。Bonferroni保护这三个预定问题；Scheffé则连未列出的contrast方向也保护。下面只在第一行问题上展示不同保护范围的区间，并由代码输出全部三个问题的结果。

同一个L̂=−4与SE=1.154701，不同保护范围
规则乘子区间P
单个预定问题，ordinary 95%2.178813[−6.515876,−1.484124].004681605
Bonferroni，预定m=32.779473[−7.209459,−.790541].014044814
Scheffé，全部contrasts3.235875[−7.736466,−.263534].034590357

普通区间不宣称同时保护三个问题。Bonferroni随预定m改变；Scheffé的乘子在组数、df和α固定时不随列出的m改变。因此不能笼统说某一种永远更保守，也不能看到结果后选择最小P。

group_means <- c(control=10,A=12,B=14,C=16)
ni <- rep(4,4)
mse <- 4
alpha <- .05
g <- length(group_means)
error_df <- sum(ni)-g
# Define the three planned questions before inspecting their results.
C <- rbind(control_vs_active=c(1,-1/3,-1/3,-1/3),
           A_vs_BC=c(0,1,-.5,-.5),B_vs_C=c(0,0,1,-1))
stopifnot(all(abs(rowSums(C))<1e-12))
estimate <- as.vector(C %*% group_means)
se <- sqrt(mse*rowSums(sweep(C^2,2,ni,"/")))
t_obs <- estimate/se
m <- nrow(C)
p_raw <- 2*pt(-abs(t_obs),error_df)
multiplier_b <- qt(1-alpha/(2*m),error_df)
multiplier_s <- sqrt((g-1)*qf(1-alpha,g-1,error_df))
p_s <- pf(t_obs^2/(g-1),g-1,error_df,lower.tail=FALSE)
results <- data.frame(contrast=rownames(C),estimate=estimate,SE=se,
                      ordinary_p=p_raw,bonferroni_p=pmin(1,m*p_raw),
                      scheffe_p=p_s,
                      scheffe_lower=estimate-multiplier_s*se,
                      scheffe_upper=estimate+multiplier_s*se)
print(results)
print(c(ordinary=qt(1-alpha/2,error_df),
        bonferroni=multiplier_b,scheffe=multiplier_s))
print(c(bonferroni_lower=estimate[1]-multiplier_b*se[1],
        bonferroni_upper=estimate[1]+multiplier_b*se[1]))
stopifnot(abs(p_s[1]-.0345903571556)<1e-12,
          abs(results$scheffe_lower[1]+7.7364661483801)<1e-10)

Dunnett：先固定control和方向，再计算共同门槛

现用四组summary信息完成一个独立例题：control=10、A=12、B=14、C=16，每组n=4，完整ANOVA给出共同MSE=4、ν=12。假定实验单位独立、组内误差正态且共同variance。研究事先只关心三个active是否高于control，family为A−control、B−control、C−control，共m=3个右侧检验：H₀:Δᵢ≤0，对Hₐ:Δᵢ>0。

Δ̂ᵢ=ȳᵢ−ȳcontrol=[2,4,6]
SEᵢ=√[MSE(1/nᵢ+1/ncontrol)]=√2≈1.414214
Tobs=[1.414214,2.828427,4.242641]

为什么不能查三个独立t检验的门槛？ 三个差值都减去同一个control mean。不同差值的covariance为σ²/ncontrol；等n时，每个差值variance为2σ²/n，因此它们的相关系数为1/2。此外，三个统计量还共用同一个估计MSE。

在零假设边界下，用相互独立的Z₀,Z₁,…,Zₘ~N(0,1)与U~χ²ν表示这些统计量：

U=νMSE/σ²
Tᵢ=(Zᵢ−Z₀)/√(2U/ν)

Z₀代表共享的control误差，U代表共享的方差估计。它们产生一个相关的multivariate t参考分布；分别调用三次rt()会丢掉这两种共享结构。

  1. 校准整个family。 右侧临界值c满足H(c)=P(maxᵢTᵢ≤c)=.95。数值积分得c≈2.287342；它大于普通单侧t.95,12≈1.782288。
  2. 回到原始单位。 最小显著差为c×SE≈3.234790。只有预定方向上的Δ̂ᵢ>3.234790才拒绝。
  3. 构造同时下界。 每项区间为[Δ̂ᵢ−cSE,∞)。这是三个差值的单侧95% simultaneous coverage，而非每项分别95%后再假装family也95%。
  4. 取得adjusted P。 每一项Pᵢ=1−H(Tobs,ᵢ)，即在joint null下至少一个统计量达到该观测门槛的概率。

比较估计差95% simultaneous下界Adjusted Pα=.05决策

C−control62.765210.00153352拒绝

单双侧不能混用。 若研究事先问任何方向的差异，应校准P(maxᵢ|Tᵢ|≤c)=.95，得到更大的c≈2.682870与双侧半宽3.794151。若事先问active低于control，则利用对称性拒绝Tᵢ<−2.287342，并报告同时上界Δ̂ᵢ+cSE。不能只改变P-value的尾部，却沿用错误版本的临界值。

展开base R积分：共同control怎样进入联合概率

给定Z₀=z与U=u后，各Zᵢ独立。令h=c√(2u/ν)，则每一项Tᵢ≤c等价于Zᵢ≤z+h。先把m个条件概率相乘，再对z与u加权积分：

H(c)=∫₀∞ fχ²ν(u)∫₋∞∞ φ(z)[Φ(z+h)]ᵐ dz du
G(c)=P(max|Tᵢ|≤c)
=∫₀∞ fχ²ν(u)∫₋∞∞ φ(z)[Φ(z+h)−Φ(z−h)]ᵐ dz du，c≥0

下面的代码使用base R的integrate()与uniroot()。它限定为这里的平衡、共同variance设计；不等n时相关矩阵改变，不能仅更改各行SE后仍沿用相关系数1/2的这个CDF。数值积分也有误差，末几位不应当作无限精度。

# Balanced normal groups with a common residual variance.
# Shared control and shared pooled MSE define the joint t distribution.
dunnett_cdf <- function(cut,m,df,two_sided=FALSE) {
  stopifnot(length(cut)==1L,m>=1,df>0)
  if(two_sided && cut<=0) return(0)
  integrand <- function(u) vapply(u,function(uu) {
    h <- cut*sqrt(2*uu/df)
    conditional <- function(z) {
      prob <- if(two_sided) pnorm(z+h)-pnorm(z-h) else pnorm(z+h)
      dnorm(z)*pmax(prob,0)^m
    }
    integrate(conditional,-Inf,Inf,rel.tol=1e-8,
              subdivisions=200L)$value*dchisq(uu,df)
  },numeric(1))
  value <- integrate(integrand,0,Inf,rel.tol=1e-7,
                     subdivisions=200L)$value
  min(1,max(0,value))
}
group_means <- c(control=10,A=12,B=14,C=16)
# Choose the control by its name, independently of factor ordering.
control <- "control"
active_names <- setdiff(names(group_means),control)
n <- 4
mse <- 4
m <- length(active_names)
error_df <- length(group_means)*(n-1)
alpha <- .05
# This bracket is adequate for m=3 and df=12.
critical_one <- uniroot(function(cut) {
  dunnett_cdf(cut,m,error_df)-(1-alpha)
},interval=c(1,4),tol=1e-7)$root
critical_two <- uniroot(function(cut) {
  dunnett_cdf(cut,m,error_df,TRUE)-(1-alpha)
},interval=c(1,4),tol=1e-7)$root
estimate <- group_means[active_names]-group_means[control]
se <- sqrt(2*mse/n)
t_obs <- estimate/se
# The prespecified analysis tests each active mean above the control.
p_adjusted <- vapply(t_obs,function(stat) {
  1-dunnett_cdf(stat,m,error_df)
},numeric(1))
lower <- estimate-critical_one*se
print(c(one_sided_critical=critical_one,two_sided_critical=critical_two,
        ordinary_one_sided_t=qt(1-alpha,error_df),SE=se))
print(data.frame(comparison=paste(names(estimate),"minus control"),
                 estimate=estimate,t=t_obs,lower=lower,upper=Inf,
                 adjusted_p=p_adjusted,reject=lower>0))
# A single comparison must reproduce the ordinary t CDF.
stopifnot(abs(dunnett_cdf(1.5,1,error_df)-pt(1.5,error_df))<1e-6,
          abs(critical_one-2.28732)<1e-4,
          abs(critical_two-2.68291)<1e-4)

先写 comparison，再看显著性

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

五组中只关心各active treatment对control，应保护几项？

先列四个active-vs-control问题，所以family为4项，而不是全部10对。Dunnett使用这些共享control的相关比较；Bonferroni也可按m=4分配α。选择之后再看结果，不能临时按显著项数重新定义family。

[1,1,−2]与[2,−1,−1]是否正交？

先核对两个系数和，都为0，所以都是contrast。Equal n时计算内积：1×2+1×(−1)+(−2)×(−1)=3，不是0，因而不正交。Unequal n还要分别除以对应nᵢ。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

木材处理与除草方法：系数对应具体问题

Wood treatment 的四品牌 planned comparison 先以 cell means 写成系数，再转换到 μ+τ 的 model 参数与 SAS 语法。每次转换都应保留同一个科学问题，并检查系数与编码约束。

Weed methods 按 control、Bio1、Bio2、Chem1、Chem2 排列时，[−1,.25,.25,.25,.25] 比较 control 与四个方法的平均值；[0,.5,.5,−.5,−.5] 比较两种 biological 与两种 chemical 方法的平均值。第二个 contrast 不回答各药物是否分别优于 control。

地板热损失与 null 模拟：保护范围为何重要

同一份四组 floor / heat-loss 数据使用 LSD、Tukey、Dunnett 与 Scheffé 后，可能得到不同结论。先列出每个 procedure 保护的 comparison family，再看相应的 critical value；输出不同并不是任选最有利结果的理由。

课程模拟 20 个真实 mean 完全相同的 normal treatments。全部 pairs 有 20×19/2=190 项；unprotected LSD 即使每项 nominal α=.05，也可能报告很多显著差异。这里需要关注至少一次误报的 familywise error，而非把单项 .05 当作整个 family 的风险。

均值分组字母：未拒绝没有传递性

Mean-separation letters 中，两组共享字母表示在该 procedure 与 α 下没有检出 pair difference。它不证明两个总体 means 相等，也不能代替原单位效应大小与 CI。

例如 A 与 B 未检出差异、B 与 C 未检出差异，仍可能检出 A 与 C 的差异。因此应回到每一对比较的规则读 letters，不能把它们当作数学相等关系进行传递。

读懂 Tukey 区间和字母分组：不显著没有传递性

多重比较常用 a、ab、b 表示分组。这些字母压缩了若干假设检验结果，并没有把总体分成已经证明相等的类别。用一个可复现的小例子看清它的含义。

原创数据三组各五个观测：A=[8,8,10,12,12]，B=[10,10,12,14,14]，C=[12,12,14,16,16]。三组均值10、12、14，每组 sample variance=4。共同 MSE=4，error df=15−3=12。

Tukey 的目标 family 为三个 pairwise comparisons。95% simultaneous interval 的半宽为 q_.95(3,12)√(MSE/n)≈3.772929√(4/5)=3.374610。

三组全部两两比较，统一使用 Tukey 校正
比较方向估计差95% simultaneous CI是否包含0
B−A2[−1.3746,5.3746]是：未检出差异
C−B2[−1.3746,5.3746]是：未检出差异
C−A4[.6254,7.3746]否：检出差异

一种有效的字母表示是 A=a、B=ab、C=b。A 和 B 共享 a，B 和 C 共享 b，A 和 C 没有共同字母。这里没有逻辑矛盾，因为“未拒绝A=B”与“未拒绝B=C”并不能推出A=C。

三个层次分开读： estimate 告诉你差的方向和量级；CI 告诉你在该模型与比较 family 下的不确定性；adjusted p-value 告诉你在所选 α 下是否拒绝。只看显著星号会漏掉效果大小和精度。

y <- c(8,8,10,12,12, 10,10,12,14,14, 12,12,14,16,16)
group <- factor(rep(c("A","B","C"),each=5))
fit <- aov(y ~ group)
# Simultaneous intervals for the complete pairwise family.
tk <- TukeyHSD(fit, "group", conf.level=.95)
tk
plot(tk)
# Equal-size HSD threshold, verified against the interval output.
qtukey(.95,nmeans=3,df=12)*sqrt(4/5)

不等n时逐对计算：LSD与Tukey–Kramer的SE、区间和P

先取得完整ANOVA的误差参照

  1. 计算共同MSE。 SSE=8+16+12=36；N=16、组数g=3，因此ν=N−g=13，MSE=36/13≈2.769231。不是三组SD的简单平均，也不是为每对重新拟合新的误差。
  2. 核对全局问题。 Grand mean=(3×10+5×12+8×14.2)/16=12.725；SStrt=Σnᵢ(ȳᵢ−12.725)²=42.31。F=(42.31/2)/(36/13)≈7.639306，P≈.006400，拒绝三个总体means全相等。
  3. 回到事先定义的pairs。 全局F只说明至少一个不同，不指出哪些不同。若事先采用protected LSD，其全局门槛本例已经通过；普通pairwise区间仍不能因此改名为95% simultaneous intervals。

每对的SE不同，LSD也随pair改变

SEᵢⱼ=√[MSE(1/nᵢ+1/nⱼ)]
LSDᵢⱼ=t.975,13×SEᵢⱼ；t.975,13≈2.160369
ordinary CI=(ȳⱼ−ȳᵢ)±LSDᵢⱼ
ordinary P=2P(t₁₃≥|ȳⱼ−ȳᵢ|/SEᵢⱼ)

A只有3个观测，涉及A的比较通常更不精确。B−A和C−B的均值差接近，但SE和P不同，说明“差值大于某个统一数”在不等n时不成立。此处使用共同variance假设；若误差方差不相同，不能只把n改掉就认为问题已解决。

全部三对的Tukey–Kramer同时推断

qcrit=q.95(g=3,ν=13)≈3.734142
scaleᵢⱼ=√[(MSE/2)(1/nᵢ+1/nⱼ)]=SEᵢⱼ/√2
halfᵢⱼ=qcrit×scaleᵢⱼ
qobsᵢⱼ=|ȳⱼ−ȳᵢ|/scaleᵢⱼ
adjusted P=P(Qg,ν≥qobsᵢⱼ)

q的第一个参数是被比较的总体均值个数g=3，不是总N、不是每对n，也不是直接填“比较次数”。本例恰巧三组有三对；若有四组，就应填g=4，而不是六对的6。q是studentized range变量，不是普通t critical；因此也不能漏掉SE/√2中的√2。

精确性边界：在独立正态、共同variance的一元ANOVA中，平衡设计的Tukey studentized-range校准给出精确的family coverage；不等n采用Tukey–Kramer样本量调整，不能把名义95%说成对每种不平衡程度都恰好95%。R官方将其说明为适用于温和不平衡的调整。本例用于学习该计算链，不证明异方差、依赖观测或任意模型下仍可照用。

# Original one-way experiment with unequal independent group sizes.
y <- c(8,10,12, 10,10,12,14,14,
       12.2,13.2,13.2,14.2,14.2,15.2,15.2,16.2)
group <- factor(rep(c("A","B","C"),c(3,5,8)))
d <- data.frame(group=group,y=y)
fit <- aov(y ~ group,data=d)
print(summary(fit))
ni <- as.numeric(table(group))
means <- as.numeric(tapply(y,group,mean))
names(ni) <- names(means) <- levels(group)
g <- length(ni)
error_df <- df.residual(fit)
mse <- deviance(fit)/error_df
# Define all three unordered pairs as the Tukey-Kramer family before analysis.
pairs <- combn(seq_len(g),2)
labels <- apply(pairs,2,function(p) paste0(names(means)[p[2]],"-",names(means)[p[1]]))
estimate <- apply(pairs,2,function(p) means[p[2]]-means[p[1]])
se <- apply(pairs,2,function(p) sqrt(mse*sum(1/ni[p])))
t_obs <- estimate/se
ordinary_p <- 2*pt(-abs(t_obs),df=error_df)
t_critical <- qt(.975,df=error_df)
ordinary_half <- t_critical*se
q_critical <- qtukey(.95,nmeans=g,df=error_df)
q_scale <- se/sqrt(2)
tk_half <- q_critical*q_scale
q_obs <- abs(estimate)/q_scale
tk_p <- ptukey(q_obs,nmeans=g,df=error_df,lower.tail=FALSE)
result <- data.frame(comparison=labels,estimate=estimate,SE=se,
  ordinary_lower=estimate-ordinary_half,ordinary_upper=estimate+ordinary_half,
  ordinary_p=ordinary_p,
  TK_lower=estimate-tk_half,TK_upper=estimate+tk_half,TK_adjusted_p=tk_p)
print(c(N=length(y),groups=g,error_df=error_df,SSE=deviance(fit),MSE=mse,
        t_critical=t_critical,q_critical=q_critical))
print(result,row.names=FALSE)
# Verify every manual interval and adjusted probability against base R.
tk <- TukeyHSD(fit,which="group",conf.level=.95)$group
print(tk)
stopifnot(error_df==13,abs(mse-36/13)<1e-12,
          max(abs(tk[labels,"diff"]-estimate))<1e-10,
          max(abs(tk[labels,"lwr"]-(estimate-tk_half)))<1e-10,
          max(abs(tk[labels,"upr"]-(estimate+tk_half)))<1e-10,
          max(abs(tk[labels,"p adj"]-tk_p))<1e-10)
