来源与使用说明

这是一份独立编写的学习辅助材料，学习目标是理解统计推理的结构。它不是 UIUC 官方课程站，也不替代教师说明。中文解释保留英文 technical terms，以便回到课程材料和软件文档中核对。

课程来源

Alexander E. Lipka, CPSC 440: Applied Statistical Methods I。Lecture slides：Chapters 1–3, 4, 5, 6, 7, 8, 9, 11, 14, 15；相同章节的 class notes。

PPT 共 743 slides；class notes 共 495 pages。页数用于界定材料范围，不能单独证明解释完整。站点将两套材料的教学概念归并为十个单元；重复幻灯片、同一公式的逐行展开和同类例题不各自建立一页。本页下方提供分章节文件与主题定位；新增深入例题也标出具体课件/笔记页码。

课件的原始图、扫描表格和 textbook 页面未转载；本站的 SVG、图表和教学交互重新绘制。作业、测验、考试、个人提交答案以及姓名、成绩、账号等私人信息不在公开材料中。课程资料中的教学例子与原创例子在正文中区分。

实验如何计算

Normal CDF 用数值近似；Student’s t、F 与 χ² 的 CDF 使用 incomplete beta / gamma，quantile 由 bisection 求解。SVG 显示固定坐标轴范围内的数值；图中阴影对应 probability 或 interval，输出保留明确的假设。随机实验使用可复现的 pseudorandom generator，重复模拟得到的频率不必等于理论值。

置信区间实验和分步图解均需手动开始自动演示，可随时暂停；离开页面后停止。分步图解也可用上一步、下一步逐条阅读，减少动态模式下只保留手动推进。窄屏默认显示完整图解，也可展开“放大查看图解”移动查看细节；较宽的数据表可横向滚动，文字解释仍完整保留。所有核心解释与 worked examples 可在 JavaScript 关闭时阅读。图的颜色之外也使用形状、线型与数值来表达差异。

如何学习

  1. 先写 population、parameter、experimental unit 和研究问题。
  2. 逐项检查 independence、normality、variance 与设计条件。
  3. 手算一个小例子，再改变实验中的一个参数，解释输出为何改变。
  4. 看练习答案之前先给出自己的结论，尤其区分 evidence、effect size 和 uncertainty。

遇到软件或课程输出的差异，先检查 tail、df、quantile convention、missing values 和 model coding，不能只比最后一个 P-value。
