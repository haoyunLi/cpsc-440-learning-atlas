χ² 从 normal deviations 的平方和出现

前面主要比较中心；质量控制还可能关心“波动是否过大”。例如咖啡装填量平均达标，但每袋相差很大，仍然是稳定性问题。这里的目标参数是总体方差 σ²，而不是均值 μ。

独立正态观测：Q=(n−1)s²/σ²~χ²(ν=n−1)

Chi-square distribution（χ² 分布） 可以理解为独立标准正态量的平方和。平方使数值非负；平方和通常右偏，df 越大形状越不同。它的均值 E(Q)=ν，方差 Var(Q)=2ν。

在样本方差中，我们先估计了 μ，所以剩余自由度是 n−1。把样本平方和 (n−1)s² 除以真实 σ²，就得到上述 pivot：它含未知参数，但在正态假设下有已知参考分布。下一节将利用这个关系，反过来限制 σ² 的范围。

必须特别注意：sample mean 的 CLT 不会自动让这个 variance pivot 服从 χ²。方差使用平方，尾部和极端观测影响很大，因此对 nonnormality 通常比均值推断更敏感。课程改变总体形状的模拟就是展示 nominal α 与实际错误率可能不一致。

所有总体variance都是100，检验仍会维持5%错误率吗？

这次模拟固定真实σ²=100，研究的是检验在null边界是否校准，而不是检出一个真实效应的power。右侧问题预先定为 H₀:σ²≤100 对 Hₐ:σ²>100，α=.05。若正态模型成立，Q=(n−1)s²/100在边界服从χ²(n−1)，用其95th percentile作门槛，理论Type I error恰为.05。

只改变总体形状，保持理论variance=100。本节使用以下五个明确的生成模型，每次研究都重新抽取n个独立观测；总体mean可以不同，因为这里的目标是variance，而且每次s²均围绕该次样本均值计算。

  1. 固定每次研究的n。 分别考察n=10、20、50；每个模型与n组合都重复B=5000次，原创seed=440701。
  2. 每次应用同一个预先规定的检验。 计算Q=(n−1)s²/100；若Q>qchisq(.95,n−1)，记I=1，否则记I=0。
  3. 汇总拒绝频率。 r̂=ΣI/B。这里null为真，拒绝即Type I error，所以r̂估计该生成模型下的实际错误率。

代码另行考察预先规定的左侧检验 H₀:σ²≥100 对 Hₐ:σ²<100，门槛改为χ².05,n−1。在同样的Gamma(shape=.1)、n=50重复样本中，左尾拒绝频率为.5190、MCSE≈.007066。左尾与右尾结果来自同批重复样本，是两套事先定义的检验表现；不应逐次挑选能拒绝的方向。

# Independent repetitions from five populations with theoretical variance 100.
RNGkind(kind="Mersenne-Twister",normal.kind="Inversion",sample.kind="Rejection")
set.seed(440701)
B <- 5000
alpha <- .05
null_variance <- 100
sample_sizes <- c(10,20,50)
generators <- list(
  Normal=function(m) rnorm(m,mean=0,sd=10),
  Uniform=function(m) runif(m,min=0,max=sqrt(1200)),
  Scaled_t5=function(m) 10*sqrt(3/5)*rt(m,df=5),
  Gamma_shape1=function(m) rgamma(m,shape=1,scale=10),
  Gamma_shape0.1=function(m) rgamma(m,shape=.1,scale=sqrt(100/.1))
)
# Check population variances analytically, not by forcing each sample variance.
theoretical_variance <- c(Normal=10^2,Uniform=(sqrt(1200))^2/12,
                          Scaled_t5=(10*sqrt(3/5))^2*5/(5-2),
                          Gamma_shape1=1*10^2,
                          Gamma_shape0.1=.1*(sqrt(100/.1))^2)
stopifnot(all(abs(theoretical_variance-null_variance)<1e-10))
rows <- list()
for (model in names(generators)) {
  for (n in sample_sizes) {
    # Each column is a fresh independent study with n observations.
    y <- matrix(generators[[model]](n*B),nrow=n,ncol=B)
    sample_variances <- apply(y,2,var)
    Q <- (n-1)*sample_variances/null_variance
    cutoffs <- qchisq(c(alpha,1-alpha),df=n-1)
    for (tail in c("right","left")) {
      rejected <- if (tail=="right") Q>cutoffs[2] else Q<cutoffs[1]
      rate <- mean(rejected)
      mcse <- sqrt(rate*(1-rate)/B)
      rows[[length(rows)+1]] <- data.frame(
        model=model,n=n,tail=tail,B=B,rejections=sum(rejected),
        rejection_rate=rate,MCSE=mcse,
        MC_lower=max(0,rate-qnorm(.975)*mcse),
        MC_upper=min(1,rate+qnorm(.975)*mcse))
    }
  }
}
result <- do.call(rbind,rows)
print(theoretical_variance)
print(result,row.names=FALSE,digits=6)
# These checks validate bookkeeping, not a theory from one random run.
stopifnot(all(result$rejections>=0),all(result$rejections<=B),
          all(result$MCSE>=0),all(is.finite(result$rejection_rate)))

模拟频率不是定理。 表中每个数仍有Monte Carlo波动，近似95% MC区间也不保证每一行都覆盖真值，更不是同时覆盖全部行。比如本次Normal、n=20的右尾频率为.0438，其单行MC区间略未覆盖.05；这可以发生在有限次模拟中，不会推翻正态pivot给出的理论错误率.05。判断依据应结合模型推导与模拟误差，不能筛选一个seed让表格更好看。

本实验说明均值的CLT不能自动保证方差χ²检验正确；它并不声称每一种非正态分布都有同样的错误率，也不提供“看到某种形状就自动改方法”的规则。实际分析仍要保留研究目标、设计和可支持的分布假设。改变B只能降低数值误差，不能把错误的参考分布变正确。

课程对应： Chapter 7 PPT pp.23–25、class notes pp.18–20使用相同variance、不同形状来比较错误率；这里的seed、重复数和模拟结果是重新生成的，不要求与课件2500次运行的表格逐项相同。分布参数核对见R Gamma文档与R t分布文档。

Variance CI 不以 estimate 为对称中心

Variance CI 不围绕 s² 对称。原因不是计算方式特别，而是 χ² 分布偏态，加上最后需要把未知 σ² 从分母中解出来。

  1. 找中间覆盖区。 95% 情形下，χ²ν 的 .025 与 .975 quantiles 夹住 95% 概率。
  2. 放入 pivot。 qlow≤(n−1)s²/σ²≤qhigh。
  3. 解出 σ²。 正数取倒数会反转大小顺序，所以较大的 qhigh 变成下界的分母，较小的 qlow 变成上界的分母。
  4. 代入数字。 n=10、s²=4，df=9；qlow≈2.7004，qhigh≈19.0228。σ² CI=[36/19.0228,36/2.7004]≈[1.8925,13.331]。
  5. 若目标是 SD。 对两个端点分别开平方，得到 σ CI≈[1.376,3.651]，而不是把区间宽度开平方。
σ² CI=[(n−1)s²/χ²₁₋α/₂,ν，(n−1)s²/χ²α/₂,ν]

本站 χ²p,ν 指左侧累计概率为 p 的 quantile；课本表可能标右侧概率。使用之前先核对尾部记号。下方实验同时显示 χ² 的中间区域和倒数变换后的 interval，追踪 df 如何影响不对称性。

若检验 H₀:σ²=σ₀²，算 Q₀=(n−1)s²/σ₀²。Hₐ 指更大 variance 时看右尾，更小时看左尾，双侧则检查两端。如果基准给的是 SD=σ₀，要先平方；方差和标准差不能混在同一个 ratio 中。

完整 R 复现。 原创向量精确满足 n=10、s²=4，因此先复现上面的 CI。再单独演示一个事先指定的右侧问题：H₀:σ≤1.5，Hₐ:σ>1.5；基准 1.5 是 SD，要平方为 variance 2.25。这些构造值用于核对公式，本身不能验证正态总体假设。

# Constructed data with n = 10 and sample variance = 4.
y <- c(17, 17, 20, 20, 20, 20, 20, 20, 23, 23)
df <- length(y) - 1
variance_ci <- df*var(y)/qchisq(c(.975, .025), df)
c(n=length(y), sample_variance=var(y), df=df)
variance_ci
sqrt(variance_ci)
# Additional right-tailed test: H0 sigma <= 1.5 vs H1 sigma > 1.5.
sigma0 <- 1.5
Q <- df*var(y)/sigma0^2
c(Q=Q, df=df, p_right=pchisq(Q, df, lower.tail=FALSE))

左尾与双侧：同一个Q为什么会得到不同结论？

继续使用上面构造数据的 n=10、s²=4；现在换一个事先指定的方差基准 σ₀²=12，仍假定观测独立且来自正态总体，α=.05。以下比较两个不同研究问题的检验规则，用来解释方向；实际研究应先选定问题，不能计算后挑选能拒绝的方向。

Q=(n−1)s²/σ₀²=9×4/12=3；ν=n−1=9
Fν(q)=P(χ²ν≤q)
每个方向对应自己的尾概率与拒绝域
预先指定的alternativeP-value拒绝域
Hₐ:σ²<σ₀²Fν(Q)Q<χ²α,ν
Hₐ:σ²>σ₀²1−Fν(Q)Q>χ²₁₋α,ν
Hₐ:σ²≠σ₀²，课程等尾约定min[1,2min{Fν(Q),1−Fν(Q)}]Q<χ²α/₂,ν 或 Q>χ²₁₋α/₂,ν
  1. 若目标是波动变小。 H₀:σ²≥12 对 Hₐ:σ²<12。用null边界σ²=12计算，Pleft=P(χ²₉≤3)≈.035705；左尾临界值χ².05,9≈3.325113。Q=3低于门槛，故在α=.05下拒绝，支持总体variance小于12。
  2. 若目标是任一方向改变。 H₀:σ²=12 对 Hₐ:σ²≠12。课程把α/2分给两端，临界值为[2.700389,19.022768]；Q=3仍在中间，故不拒绝。相应等尾双侧P=2×.035705≈.071410。
  3. 解释差异。 左侧检验把全部α放在减小这一端；双侧还要为增大方向保留α。χ²分布不对称，双侧拒绝域不是在某个中心左右各加减同一个距离。

用匹配的置信集合回验，而不是混用单侧与双侧

等尾双侧95% variance CI仍为 [36/χ².975,9,36/χ².025,9]≈[1.892469,13.331410]，包含12，与双侧不拒绝一致。左侧检验对应的是95%单侧上置信界：

U₁₋α=(n−1)s²/χ²α,ν
U.95=36/3.325113≈10.826700

单侧置信集合是 σ²≤10.826700（在非负参数范围内）；12高于上界，所以与左侧拒绝一致。不能因为双侧95% CI包含12，就否定预先指定左侧检验的结论：两者使用了不同的尾部配置。若目标改成SD，对相应端点开平方，同时把假设中的基准也换成√12。

# Summary statistics from the constructed example; assume normal, independent data.
n <- 10
sample_variance <- 4
null_variance <- 12
alpha <- .05
df <- n-1
Q <- df*sample_variance/null_variance
p_left <- pchisq(Q,df=df)
p_right <- pchisq(Q,df=df,lower.tail=FALSE)
# The course uses an equal-tail two-sided test, not probability-density ordering.
p_two <- min(1,2*min(p_left,p_right))
critical_left <- qchisq(alpha,df=df)
critical_two <- qchisq(c(alpha/2,1-alpha/2),df=df)
# Match each test with its own confidence set.
upper_one_sided <- df*sample_variance/qchisq(alpha,df=df)
ci_two_sided <- df*sample_variance/qchisq(c(1-alpha/2,alpha/2),df=df)
print(c(Q=Q,df=df,p_left=p_left,p_equal_tail_two_sided=p_two,
        critical_left=critical_left,
        critical_two_low=critical_two[1],critical_two_high=critical_two[2]))
print(c(upper_95_one_sided=upper_one_sided,
        lower_95_two_sided=ci_two_sided[1],
        upper_95_two_sided=ci_two_sided[2]))
print(data.frame(test=c("left","equal-tail two-sided"),
                 p=c(p_left,p_two),reject=c(p_left,p_two)<alpha))
stopifnot(p_left<alpha,p_two>alpha,
          (p_left<alpha)==(upper_one_sided<null_variance),
          (p_two<alpha)==(null_variance<ci_two_sided[1] ||
                         null_variance>ci_two_sided[2]))

F 是两个独立 variance estimates 的比

两组稳定性可以用方差的比来比较。若 σ₁²/σ₂²=1，两组总体波动相同；比值大于 1，第一组更分散。样本比值 R=s₁²/s₂² 也会随机变化，需要参考分布判断。

独立正态样本：(s₁²/σ₁²)/(s₂²/σ₂²)~F(n₁−1,n₂−1)
H₀:σ₁²=σ₂² 时，Fcalc=s₁²/s₂²

F distribution 来自两个独立 χ² 量各除以 df 后的比。它有两项自由度：numerator df 属于分子组，denominator df 属于分母组，顺序要随比值一起记录。

  1. 固定第一组除以第二组，算 R。
  2. 记 ν₁=n₁−1、ν₂=n₂−1，使用对应 F(ν₁,ν₂)。
  3. 双侧检验比较 R 与左、右 α/2 quantiles；均值差是否显著不影响这一步，因为目标是 variance ratio。
  4. 构造 ratio CI 时，像上一节一样把 ratio 参数从分母解出：下界 R/F₁₋α/₂， 上界 R/Fα/₂。
σ₁²/σ₂² 的 CI=[R/F₁₋α/₂,ν₁,ν₂，R/Fα/₂,ν₁,ν₂]
Fₚ(a,b)=1/F₁₋ₚ(b,a)

若为了查表把较大样本方差放在分子，必须同时交换 df，并正确处理双侧概率。对 SD ratio 的区间则分别开平方。课程两个电压下寿命波动的例子关注 variation；平均寿命的差异不能代替方差比较。

这个 classical F test 对 nonnormality 敏感，也需要两个样本独立。配对测量不能直接按独立两个 χ² 量推导。

原创软件示例。 为展示完整输入与输出，设两组独立观测 x=8,…,15、y=5,…,15，在独立正态总体模型下进行计算。这个短向量仅用于核对操作；不是课程电压实验的原始数据，也不构成正态性证据。

# Original software example; use independent normal-population assumptions.
x <- 8:15
y <- 5:15
rbind(x=c(n=length(x), variance=var(x)),
      y=c(n=length(y), variance=var(y)))
var.test(x, y, alternative="two.sided", ratio=1, conf.level=.95)
# Reversing the quantile tail also exchanges numerator and denominator df.
c(direct=qf(.025, 7, 10), reciprocal=1/qf(.975, 10, 7))

x 的 n=8、s²=6，y 的 n=11、s²=11，所以第一组除以第二组的 F=6/11≈.54545，df=(7,10)。双侧 P≈.43392，variance ratio 的 95% CI≈[.13810,2.59697]；包含 1，表示尚无充分证据拒绝相等 variance。最后两个 quantiles 相同，核对了交换 df 与取倒数的关系。

Hartley Fmax 依靠更强的平衡与 normality

超过两组时，一个直接的问题是：最分散的一组与最稳定的一组相差多大？Hartley’s Fmax 用所有组的最大样本方差除以最小样本方差：

Fmax=max(sᵢ²)/min(sᵢ²)

例如三组方差为 4、9、16，则 Fmax=16/4=4。这个数总结了极端差距，但还没有告诉我们 null 下出现这种差距有多罕见。

它从多组中选了最大和最小，因此参考分布不同于预先指定两组的普通 F。要做检验，还需要 groups 的数量、每组 replicates、相应的 Fmax table / quantile。不能把 4 塞入普通 qf 就当成精确检验。

课程方法通常要求 equal n、相同 within-group df、独立且正态的组。它对 nonnormality 不稳健，也不适用于任意不平衡样本。若这些条件欠缺，应考虑针对设计与分布更合适的方法；下一节用 absolute deviations 来构造另一种比较。

Brown–Forsythe 把分散问题转成 absolute deviations

怎样在较少依赖正态方差分布的情况下比较分散程度？Brown–Forsythe test 先把每个观测换成“离本组中位数的绝对距离”，再比较这些距离的均值。

  1. 求每组中心。 原创 A=[2,3,4]、B=[1,3,5]，两组中位数都为 3。
  2. 改写响应。 Zᵢⱼ=|Yᵢⱼ−Mᵢ|，所以 A 变成 [1,0,1]，B 变成 [2,0,2]。
  3. 读新变量。 A 的平均距离为 2/3，B 为 4/3。B 的观测整体离自己的中心更远。
  4. 做正式比较。 对 Z 做 one-way ANOVA，检验组平均 absolute deviations 是否有差异；不是仅凭这两个小样本均值作结论。

它是 median-centered 的 Levene variation，通常比 classical variance F-test 对 nonnormality 更稳健。仍需要独立单位和合理样本量；未拒绝不是证明原方差相等。

课程 fuel-efficiency 例先看 raw response 的分散，再读绝对偏差 ANOVA。PPT 中的 car brands 与 notes 中的 additives 是不同实验场景，不能把某一组的 response definition 换到另一组；相同的是比较 spread 的统计结构。

完整 R 复现。 下面直接录入本节 A 与 B，并把 group median 和 absolute deviation 保存为列，便于逐行核对变换。

# Reproduce the two groups in the worked example.
d <- data.frame(group=factor(rep(c("A", "B"), each=3)),
                y=c(2, 3, 4, 1, 3, 5))
d$group_median <- ave(d$y, d$group, FUN=median)
d$z <- abs(d$y - d$group_median)
d
aggregate(z ~ group, data=d, FUN=mean)
summary(aov(z ~ group, data=d))

Z 的组均值为 2/3 与 4/3；ANOVA 得 F=.8、df=(1,4)、P≈.42165。虽然 B 的样本平均偏差更大，这个极小样本不足以排除抽样波动；未拒绝也不能证明两组总体 spread 相等。

Variance inference 的证据边界

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

数据很偏、n=50，variance test 能直接靠CLT保证吗？

先问CLT在这里保证哪个统计量。常用CLT针对样本均值；χ² variance pivot来自正态总体的更具体性质。方差受尾部影响很大，n=50并不自动使它有效。应检查分布与设计，并选符合目标和条件的稳健或其他方法。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

咖啡容器：先区分 variance 与 SD

Coffee 例给出 n=30、s≈3.433，先平方得到 s²≈11.789，再以 df=29 的 χ² quantiles 构造 99% variance CI，约为 [6.53,26.06]。对两个端点分别开平方，才得到 SD CI≈[2.556,5.104]。

若目标 variance 是 16，区间包含 16 只表示对应检验没有足够证据拒绝，并不证明生产线已达标。尤其要核对目标写的是 σ 还是 σ²，以及单位是否平方；把 16 代入不同参数会回答不同问题。

农药效力损失：range 不能精确代替 variance

Pesticide potency loss 例给出 n=20、s²=5.45，要检验 σ²>4。统计量为 χ²calc=19×5.45/4=25.8875，df=19 的右尾 P≈.133。因此在 α=.05 下不拒绝 null。

Class notes 以“损失约从 0% 到 8%”解释研究动机。但 range 只描述极端范围，不能唯一决定总体 SD，更不能据此声称 χ² 模型条件已经满足。正式推断仍要检查独立性与总体 normality。

缝纫电压与多组稳定性

110V 组给出 s=.474、n=10，220V 组给出 s=.233、n=16。若估计 σ110²/σ220²，先算 ratio≈(.474/.233)²≈4.139，再使用分子 df=9、分母 df=15 的两个 F quantiles 构造 90% CI。交换 ratio 的方向时，df 与端点也必须一起调整。

Hartley 例的 Fmax=80.22/6.89≈11.64，依赖三组各 n=9 的平衡与 normality。Fuel 例则把各值到本组 median 的绝对距离交给 Brown–Forsythe 方法。PPT 的 car brands 与 notes 的 additives 是不同因素；虽然都研究 spread，也不能把它们说成同一个实验。

方差比小于 1 也可以检验：把组别、自由度和尾部一起读

F 分布只取正值，但它允许统计量小于1。把“大方差放分子”是某些手查表流程的便利安排，不是运行 F 检验的必要条件。固定组别定义通常更容易保持问题和结果的一致性。

原创比较：组A有 n_A=10，sample variance s_A²=4；组B有 n_B=15，s_B²=9。两组独立、各自总体正态。目标参数 R=σ_A²/σ_B²，检验 H₀:R=1 对 Hₐ:R≠1。

  1. 固定方向。 F=s_A²/s_B²=4/9≈.444444。
  2. 跟随分子分母写 df。 numerator df=10−1=9；denominator df=15−1=14。
  3. 计算两侧。 P(F₉,₁₄≤.444444)≈.111834；右尾约 .888166。
  4. 使用等尾双侧规则。 p=2 min(.111834,.888166)≈.223668。不能因为方差比“不到一半”就认定差异显著。
  5. 构造参数比的区间。 95% CI=[F/q_.975,F/q_.025]≈[.138486,1.687979]，分位数都取 F(9,14)。区间含1，与该双侧检验未拒绝一致。

这一区间很宽：数据仍容许 A 的方差明显较小，也容许它大于 B。结论应是“尚无足够证据证明两总体方差不同”，不能说“两个方差已经相等”。

ratio <- 4/9
df_a <- 10-1
df_b <- 15-1
# Keep group order fixed throughout the calculation.
p_left <- pf(ratio,df_a,df_b)
p_right <- pf(ratio,df_a,df_b,lower.tail=FALSE)
p_two <- min(1,2*min(p_left,p_right))
ci <- ratio/qf(c(.975,.025),df_a,df_b)
c(F=ratio,p_two=p_two,lower=ci[1],upper=ci[2])

分析边界： 经典 F 方差检验对非正态敏感；这里的 p 和 CI 依赖前述模型。也不要把“F 检验未显著”当成必须使用 pooled t 的证书。比较两个均值时，Welch 是否合适应根据目标与设计判断，不应机械地由一次方差预检决定。

Hartley Fmax 从统计量走到临界值：构造它自己的参考分布

Hartley检验不能使用普通两样本F参考，因为分子和分母是从多个样本方差中挑出来的最大值与最小值。下面在独立、正态、每组相同样本量的条件下，直接构造这个极值比的null分布，完成一次可复现的检验。

原创例：k=3组，每组n=10，sample variances为4、9、16。检验H₀:σ₁²=σ₂²=σ₃²，对至少一个总体方差不同的alternative。统计量Fmax=16/4=4；每个样本方差的df为ν=n−1=9。观察到的最大组与最小组必须由全部三组一起决定。

H₀下：Xᵢ=νsᵢ²/σ² 独立服从 χ²ν
Fmax=max(Xᵢ)/min(Xᵢ)

共同的σ²与ν在比值中抵消，所以参考分布不需要知道共同总体方差的数值。它依赖的是组数k和共同df；组数增加后，出现较极端最大/最小组合的机会也会改变。

令fν与Fν分别为χ²ν的density与CDF。对r≥1，Fmax的CDF可以写成：

G(r)=P(Fmax≤r)
=k ∫₀∞ fν(x)[Fν(rx)−Fν(x)]ᵏ⁻¹ dx
  1. 设最小值在x附近。 连续分布中最小值几乎必然唯一，k个组中的任何一个都可能提供它，因此有系数k。
  2. 限制其他k−1个值。 要让最大/最小≤r，每一个其余值都必须落在[x,rx]中。单个概率为Fν(rx)−Fν(x)。
  3. 使用独立性并累加。 将这个概率取k−1次方，再乘最小值位置对应的density并对x积分，就得到全部允许情况的概率。
  4. 取右尾与分位数。 p=1−G(4)；95%临界值c满足G(c)=.95。

数值积分得到 p≈.120301，95%临界值约为5.338458。因为4<5.338458，且p>.05，本例在5%水平不拒绝方差相等的null。这个结论表示证据不足，不表示三个方差已经被证明相等。

# CDF of the ratio of the largest to smallest independent chi-square.
# Equal group sizes are required for this common-df construction.
fmax_cdf <- function(r,k,df) {
  stopifnot(length(r)==1L,k >= 2,df > 0)
  if (r <= 1) return(0)
  value <- integrate(function(x) {
    interval_prob <- pmax(pchisq(r*x,df)-pchisq(x,df),0)
    k*dchisq(x,df)*interval_prob^(k-1)
  },lower=0,upper=Inf,rel.tol=1e-10,subdivisions=1000L)$value
  min(1,max(0,value))
}
sample_variances <- c(4,9,16)
k <- length(sample_variances)
n <- 10
nu <- n-1
observed_fmax <- max(sample_variances)/min(sample_variances)
p_value <- 1-fmax_cdf(observed_fmax,k,nu)
# The upper bracket is chosen for this k=3, df=9 example.
critical <- uniroot(function(r) fmax_cdf(r,k,nu)-.95,
                    interval=c(1,100),tol=1e-9)$root
c(Fmax=observed_fmax,p_value=p_value,critical_95=critical)
stopifnot(abs(p_value-.1203008) < 1e-6,
          abs(critical-5.3384579) < 1e-6)

这里使用确定性的数值积分，不是Monte Carlo；最后几位精度受到积分与求根容差影响。代码返回的是该正态、独立、平衡设计下Fmax统计量的参考概率，而非普通pf(4,9,9)。

使用边界： 不等n时，各χ²的df和缩放不同，以上共同df公式不能直接复用。非正态时，样本方差也不再具有这里使用的χ²参考。课程的Brown–Forsythe方法提供了另一条检查组间分散差异的途径，但它也需要独立单位和合理条件。不要先看哪一种检验显著，再倒推使用哪一种。
