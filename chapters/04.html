先列 sample space，再计算 event

统计方法要处理随机变化，先需要一种方式描述“可能出现哪些结果，以及各有多大可能”。Probability（概率） 的取值在 0 与 1 之间：不可能事件的概率为0，整个sample space的概率为1。但反过来不能把任何零概率事件都叫作不可能：从[0,1]连续均匀抽取一个数时，每个指定单点的概率都是0，仍然会抽到某一个数。概率1表示补事件的概率为0，称为almost surely（几乎必然）；它不必等于逻辑上绝无例外。

一次实验所有可能结果的集合叫 sample space；你关心的一部分结果叫 event（事件）。关键是把基本结果列对。例如两颗公平骰子，用有序数对 (第一颗,第二颗) 表示结果，一共有 6×6=36 个等可能结果。和为 7 对应 (1,6)、(2,5)、(3,4)、(4,3)、(5,2)、(6,1)，因此概率为 6/36=1/6。

如果直接把“和为 2、3、…、12”列成 11 个结果再除以 11，就错了，因为这些和并不等可能。同样，两次公平掷币的基本结果是 HH、HT、TH、TT，恰好一次正面对应 HT 与 TH，概率为 2/4。

P(Aᶜ)=1−P(A)
P(A∪B)=P(A)+P(B)−P(A∩B)

Union（并集） A∪B 表示 A 或 B 至少一个发生；intersection（交集） A∩B 表示同时发生。直接把 P(A) 和 P(B) 相加，会把交集算两次，所以要减去一次。Complement（补集） Aᶜ 则表示 A 没发生。

“至少一次成功”常用补集更容易算。n 次独立试验、每次成功概率为 p 时，全部失败的概率是 (1−p)ⁿ，所以至少成功一次的概率是 1−(1−p)ⁿ。先检查独立性，再使用这个乘法。

当基本结果确实等可能时，可以用 classical probability 的“有利结果数/总结果数”。不满足等可能时，要使用每个结果各自的概率，或用合理的重复实验估计 relative frequency。重复模拟的比例会波动，不必每次精确等于理论概率。

Conditional probability 改变了分母

已知一条信息后，计算概率的范围可能改变。Conditional probability（条件概率） P(A|B) 问的是：在 B 已经发生的情形中，有多少也满足 A？竖线读作“给定 B”，并不是除号。

P(A|B)=P(A∩B)/P(B)，要求 P(B)>0
P(A∩B)=P(A|B)P(B)
  1. 先缩小范围。 在骰子例中，令 B 为第一颗骰子是 6。36 个结果中只有 (6,1) 到 (6,6) 这 6 个满足 B。
  2. 再找其中的目标结果。 令 A 为两颗之和是 7。满足 B 的 6 个结果中，只有 (6,1) 也满足 A。
  3. 在新的分母上求比例。 P(A|B)=1/6，也等于 (1/36)/(6/36)。不要仍用全部 36 个结果作为条件概率的分母。

课堂案例：同一个交集可以对应不同分母

课程保险例的100 条理赔记录中有 10 条 fraud，其中 fire 类有 20 条、fraud 与 fire 同时满足的有 6 条。因此全表 fraud 比例为 10/100=.10，fire 类中的 fraud 比例为 6/20=.30。若问题反过来问“fraud 记录中，多少属于 fire”，分母就应换成 10，得到 6/10=.60。这三个比例回答三个不同问题。这里描述的是课堂表中的频率；推广到未来所有理赔还需要抽样与总体模型支持。

Independence（独立） 表示知道 B 不改变 A 的概率，也就是 P(A|B)=P(A)。等价地，P(A∩B)=P(A)P(B)。它与 mutually exclusive（互斥） 不一样：两个正概率事件若互斥，一个发生就排除了另一个，反而不独立。

原创完整例：先读整张表，再决定分母

以下是另行设计的 200 条理赔记录，不是上面的课堂原始数据。每条记录只属于 fire、auto、theft 中一种保单类型，并且 fraud / nonfraud 两行完整、互斥。令 F 表示 fraud，H 表示 fire。先考虑“从这份完整清单中等概率随机抽一条”的有限抽取实验。

原创理赔计数；最右列和最下行是边际总数
状态fireautotheft行合计
fraud18121040
nonfraud428830160
列合计6010040200
  1. 检查表的总量。 fraud 行为 18+12+10=40，nonfraud 行为 42+88+30=160；fire 列为 18+42=60。两种汇总方向都得到 N=200，不能把边际合计再次计入观测数。
  2. 求 marginal probabilities（边际概率）。 从全部 200 条中随机抽一条，P(F)=40/200=.20，P(H)=60/200=.30。边际概率只限制一个事件。
  3. 求 joint probability（联合概率）。 同时满足 F 和 H 的是左上角 18 条，所以 P(F∩H)=18/200=.09。这里没有给定条件，分母仍为全表 200。
  4. 给定 fire，再问 fraud。 只保留 fire 列 60 条，其中 18 条 fraud，因此 P(F|H)=18/60=.30。也可用 .09/.30=.30 核对。这个 .30 不是“所有 fraud 中有 30% 来自 fire”。
  5. 给定 fraud，再问 fire。 只保留 fraud 行 40 条，其中 18 条 fire，因此 P(H|F)=18/40=.45，也等于 .09/.20=.45。分子未变，条件决定的分母变了，所以两个方向通常不同。
  6. 检查 independence。 P(F)P(H)=.20×.30=.06，而 P(F∩H)=.09，两者不同。在这份有限清单的随机抽取实验中，F 与 H 不独立。等价检查为 P(F|H)=.30≠.20=P(F)，或 P(H|F)=.45≠.30=P(H)。
同一个交集 18：
joint → 18/200=.09
fraud given fire → 18/60=.30
fire given fraud → 18/40=.45
独立要求 joint=.20×.30=.06；本表为 .09

为什么 .30 恰好出现两次？ 本例的 P(H)=.30 和 P(F|H)=.30 是数值巧合，代表不同事件；判断独立要比较 P(F|H) 与 P(F)，不能把任何两个相等的比例都当成独立证据。交集 .09>0 也说明 F 与 H 不互斥，但“能够同时发生”本身不保证独立。

观测频率与总体模型要分开说

如果研究对象就是这份固定清单，且每条记录被抽中的机会相同，上面各比例是该有限抽取实验的精确概率。如果这 200 条只是更大总体的一份样本，上面各比例是经验频率或总体概率的估计；样本表不满足乘积关系，不能仅凭这一点断言总体依赖已通过显著性检验。反过来，样本表恰好满足乘积关系也不证明总体独立。样本是否具有代表性、记录是否独立、分类是否完整，都会影响推广；本节不进行总体独立性的假设检验。

条件分母为零时，概率未定义。 若表中没有 fire 记录，P(F|H) 需要计算 0/0，不能填成 0。若 fire 记录存在但全部 nonfraud，则 0/正数=0，是合法的经验条件概率。条件组很小但非空时，比例仍可计算，但推广到总体时可能很不稳定；不要把“可计算”当成“已精确知道总体概率”。

# Original teaching data: rows are fraud status, columns are policy types.
claims <- matrix(c(18,12,10,42,88,30),nrow=2,byrow=TRUE,
                 dimnames=list(status=c("fraud","nonfraud"),
                               policy=c("fire","auto","theft")))
stopifnot(all(claims>=0),all(claims==floor(claims)))
n <- sum(claims)
fraud_n <- sum(claims["fraud",])
fire_n <- sum(claims[,"fire"])
intersection_n <- claims["fraud","fire"]
print(addmargins(claims))
# Return NA, not zero, when the conditioning event has no records.
safe_ratio <- function(numerator,denominator) {
  if (denominator==0) return(NA_real_)
  numerator/denominator
}
p_fraud <- safe_ratio(fraud_n,n)
p_fire <- safe_ratio(fire_n,n)
p_joint <- safe_ratio(intersection_n,n)
p_fraud_given_fire <- safe_ratio(intersection_n,fire_n)
p_fire_given_fraud <- safe_ratio(intersection_n,fraud_n)
product <- p_fraud*p_fire
print(c(n=n,fraud_n=fraud_n,fire_n=fire_n,joint=p_joint,
        fraud=p_fraud,fire=p_fire,
        fraud_given_fire=p_fraud_given_fire,
        fire_given_fraud=p_fire_given_fraud,
        product_of_marginals=product))
# This equality describes the table, not a population significance test.
empirical_independence <- isTRUE(all.equal(p_joint,product))
print(list(empirical_independence=empirical_independence,
           zero_condition=safe_ratio(0,0)))
stopifnot(n==200,fraud_n==40,fire_n==60,
          abs(p_joint-.09)<1e-12,
          abs(p_fraud_given_fire-.30)<1e-12,
          abs(p_fire_given_fraud-.45)<1e-12,
          abs(product-.06)<1e-12,
          !empirical_independence,is.na(safe_ratio(0,0)))

不放回抽样：前面的结果会改变后面的条件

不放回抽样能直接看出条件为什么会改变。10 颗种子中 6 颗健全，第一颗健全的概率是 6/10；已知第一颗健全且不放回，第二颗的分母变成 9，健全数变成 5。因此两颗都健全的概率为 (6/10)×(5/9)=1/3。若每次放回并重新随机抽取，才是 (6/10)²=.36。

Notes 的区域经理抽选同理：M 人中有 m 人满足条件，不放回连续抽到三名的概率是 (m/M)×((m−1)/(M−1))×((m−2)/(M−2))。此时结果相互依赖，不能直接套 binomial。资料中一处“both”的 union 记号，应按同时发生的 intersection 理解。

Binomial 把重复的 0/1 结果变成计数

掷币、发芽和就业例子都能把每次结果写成 0 或 1。把一次随机结果对应到数值，得到 random variable（随机变量）。如果 Y 记录 n 次试验中成功的总数，并满足下面的条件，就可以使用 Binomial(n,p)：

  • 试验次数 n 事先固定。
  • 每次只按“成功/失败”两类记录。
  • 每次成功概率都是同一个 p。
  • 各次试验相互独立。
P(Y=k)=C(n,k)pᵏ(1−p)ⁿ⁻ᵏ
E(Y)=np；Var(Y)=np(1−p)；SD(Y)=√[np(1−p)]

这个公式可以拆开读。pᵏ 是 k 次成功的概率因子，(1−p)ⁿ⁻ᵏ 是其余失败的因子；但成功可以出现在不同位置，所以要乘组合数 C(n,k)。例如 n=3、p=.5，恰好两次成功有 SSF、SFS、FSS 三种顺序，每一种概率都是 .5³，所以 P(Y=2)=3×.125=.375。

课程 germination 例 n=20、p=.85。要算至少 18 颗发芽，就把三个互斥结果相加：P(Y≥18)=P(Y=18)+P(Y=19)+P(Y=20)≈.4049。也可以取补集 1−P(Y≤17)。这里的 17 不能误写成 18，否则会把恰好 18 颗也减掉。

平均成功数是 np=17，不表示每批一定有 17 颗发芽；标准差 √[20×.85×.15]≈1.597 描述不同批次成功数的波动。下方实验改变 n 和 p 时，柱子改变的是各个成功数的概率，而不是单次试验的结果。

“Success” 只是事件名称，不含好坏判断。若把“未就业”定义成成功，p=.1；改为“就业”，p=.9，同时随机变量也改为 n−Y。共享环境使种子相关，或不同种子成功率不同，都会使简单 binomial 模型不再合适。

dbinom(18, size=20, prob=.85) # Exactly 18 successes
pbinom(17,20,.85,lower.tail=FALSE) # Strictly greater than 17, i.e. at least 18
# SAS: PDF('BINOMIAL',k,p,n); CDF('BINOMIAL',k,p,n)

精确二项检验：单点概率为什么不是P-value

已会计算 Binomial probabilities，还要区分三种问题：某个计数恰好发生的概率、一个方向的尾概率、以及为预先指定检验定义的 P-value。它们可能都很小，但含义不同，不能交换标签。

这一节把概率计算连接到检验。若第一次见到 H₀、Hₐ 和 P-value，可先阅读Chapter 5 的检验定义，再回来比较下面三种概率。

课程选举教学例记录1218人中516人支持某候选人。为核对课件，本节保留这两个计数，以独立、相同成功概率的二分类抽样为教学模型。令 X 为支持人数，p 为目标总体支持比例；在观察结果之前指定 H₀:p=.5 对 Hₐ:p≠.5，α=.05。因此 null 下 X~Binomial(1218,.5)。实际调查若存在抽样偏差、非应答或相关受访者，需要重新评估设计，不能单靠二项公式消除这些问题。

同一个516，对应三个不同的概率

课程计数的精确二项概率；保留事件与尾部标签
计算对象事件或定义数值R调用
单点概率 PMFP₀(X=516)1.486318887×10⁻⁸dbinom(516,1218,.5)
左尾概率P₀(X≤516)5.457477156×10⁻⁸pbinom(516,1218,.5)
预先双侧的精确 P-value在 null 下，汇总不比实际计数更可能的结果1.091495431×10⁻⁷binom.test(516,1218,p=.5,alternative="two.sided")

与源材料的标注核对： Chapter 4 PPT 63–64页、class notes 44页将约5.45748×10⁻⁸写在 P(X=516) 旁；按精确分布复算，这个数字实际上对应 P(X≤516)，不是单点 PMF。本节分别保留事件和正确数值，避免沿用这个错位。若研究原先指定 Hₐ:p<.5，左尾概率才是对应的单侧 P-value；不能看见516低于609后，再把原先的双侧问题改成单侧。

  1. 确定“更极端”的规则。 本节使用 R binom.test() 默认的 probability ordering：把 null 下单点概率不大于观测点单点概率的所有计数相加。这是一个明确的双侧检验定义。
  2. 利用本例的对称性。 p₀=.5时分布关于1218/2=609对称。516的镜像是1218−516=702，所以被累加的结果为 X≤516 或 X≥702。
  3. 累加两端。 两边概率相等，因此 Ptwo=2P₀(X≤516)=1.091495431×10⁻⁷。这一步依赖本例的对称结构。
  4. 按原定α判断。 双侧 P远小于.05，因此在指定模型下拒绝 p=.5。样本比例516/1218≈.423645，提示偏离方向向下；P-value不是“p=.5为真的概率”，也不是对未来选举结果的概率预测。

为什么不能用“单点概率小于.05”当检验规则？

同一个 null 模型下，最靠近中心的计数是609。它的单点概率 P₀(X=609)≈.022857，已经小于.05；但609恰好等于 null 的期望人数，对应双侧 P-value是1。若机械地把“小于.05的单点概率”当成拒绝标准，就会把这个最符合模型中心的位置也判为异常。计数可能值很多时，每个单点都可以很小；P-value需要按预先规定的极端性规则累加结果。

不对称二项分布：双侧不一定是2倍较小尾部

双侧检验的定义并不唯一。R默认的概率排序法与 min(1,2×较小单侧尾概率) 是不同规则；后者常称为 central / equal-tailed 方法，不能在任意p₀下把它当成R默认输出。

原创对照：X~Binomial(20,.2)，观测x=0。该点概率为.8²⁰≈.011529215；按默认概率排序，另一个尾部从9开始，因为k=9,…,20的单点概率都不大于k=0的单点概率。于是默认双侧 P=P₀(X=0)+P₀(X≥9)≈.021511001；机械把左尾乘2则得.023058430，两个数字不同。使用哪种规则应事先写清楚，不能挑较小的结果。

# Course teaching counts; the null model is fixed before examining the result.
x <- 516
n <- 1218
p0 <- .5
alpha <- .05
point_mass <- dbinom(x,n,p0)
left_tail <- pbinom(x,n,p0)
two_sided <- binom.test(x,n,p=p0,alternative="two.sided")$p.value
# Probability ordering adds all outcomes no more likely than the observed one.
k <- 0:n
null_mass <- dbinom(k,n,p0)
selected <- null_mass<=point_mass*(1+1e-7)
manual_two_sided <- sum(null_mass[selected])
# Symmetry at p0 = .5 gives the matching opposite-tail boundary n - x.
reflected_tail <- pbinom(n-x-1,n,p0,lower.tail=FALSE)
print(c(sample_proportion=x/n,point_mass=point_mass,left_tail=left_tail,
        right_reflected_tail=reflected_tail,two_sided=two_sided,
        manual_two_sided=manual_two_sided,reject_at_alpha=two_sided<alpha))
# A small point mass at the null center is not evidence against the null.
center_x <- n/2
print(c(center_count=center_x,center_mass=dbinom(center_x,n,p0),
        center_p=binom.test(center_x,n,p=p0)$p.value))
stopifnot(abs(two_sided-manual_two_sided)<1e-15,
          abs(two_sided-2*left_tail)<1e-15,
          dbinom(center_x,n,p0)<alpha,
          binom.test(center_x,n,p=p0)$p.value==1)
# An asymmetric example: probability ordering and doubled smaller tails differ.
n2 <- 20
x2 <- 0
p02 <- .2
k2 <- 0:n2
mass2 <- dbinom(k2,n2,p02)
observed_mass2 <- dbinom(x2,n2,p02)
selected2 <- mass2<=observed_mass2*(1+1e-7)
manual2 <- sum(mass2[selected2])
left2 <- pbinom(x2,n2,p02)
right2 <- pbinom(x2-1,n2,p02,lower.tail=FALSE)
doubled_tail2 <- min(1,2*min(left2,right2))
helper2 <- binom.test(x2,n2,p=p02,alternative="two.sided")$p.value
print(k2[selected2])
print(c(default_two_sided=helper2,manual_two_sided=manual2,
        doubled_smaller_tail=doubled_tail2))
stopifnot(abs(manual2-helper2)<1e-12,
          abs(helper2-doubled_tail2)>1e-3)

Continuous probability 是面积，不是曲线高度

对连续测量，“恰好 20.000…cm”这一精确点的概率为 0，但一个范围仍然可以有正概率。这里使用 probability density function（PDF，概率密度），用曲线下的面积表示概率，而不是直接读曲线的高度。

P(a≤Y≤b)=∫ₐᵇ f(y)dy；CDF F(y)=P(Y≤y)

密度甚至可以大于 1。例如均匀分布在 [0,.5] 上，密度高度是 2，整个矩形的面积仍是 .5×2=1。在 [.1,.3] 内的概率为 (.3−.1)×2=.4。因此 PDF 的高度与 probability 是不同量。Cumulative distribution function（CDF） 则把某个位置左边的面积累加起来，取值始终在 0 与 1 之间。

Normal distribution（正态分布） 的中心由 μ 决定，宽度由 σ 决定。为了把不同单位的正态变量放到同一套表上，先标准化：

Y~Normal(μ,σ²)；Z=(Y−μ)/σ~Normal(0,1)
  1. 确定区域。 要算 μ=20、σ=2 时 P(Y<23)，目标是 23 左侧的面积。
  2. 换成标准尺度。 z=(23−20)/2=1.5，意思是阈值比均值高 1.5 个标准差。
  3. 查左侧面积。 Φ(1.5)≈.9332，所以原概率也是 .9332。
  4. 按问题处理尾部。 若问大于 23，取 1−.9332；若问一个区间，把两个 CDF 相减。μ=20、σ=2 时 P(Y<16)=Φ(−2)≈.0228。

找 percentile 是反向过程。先找标准正态中累计概率为 p 的 z，再还原单位：yₚ=μ+σΦ⁻¹(p)。例如 μ=55、σ=3 的第 80 百分位为 55+3×.8416≈57.525。课程产奶量例也应按“区域→标准化→面积或分位数”顺序计算。

Student’s t、χ² 和 F 也有密度和CDF，后面会说明各自为何出现在推断中。先用下面的R代码核对正态面积与分位数，再看离散计数怎样连接到连续面积。

pnorm(23,mean=20,sd=2)
qnorm(.80,mean=55,sd=3)

离散计数怎样接到连续正态面积

Continuity correction（连续性校正） 把整数k对应的概率柱看作从k−.5到k+.5的一格。用连续曲线近似时，要覆盖完整的格子。先把严格不等式改写成整数事件，再确定半格边界。

令X为整数计数，Xₐ为近似的连续正态变量
整数事件连续面积边界理由
X≤kXₐ≤k+.5包含k这一整格
X≥kXₐ≥k−.5从k这一格的左缘开始
a≤X≤ba−.5≤Xₐ≤b+.5两端整数都包含
X=kk−.5≤Xₐ≤k+.5单个整数对应宽度1的格子

例如X<15先改写为X≤14，因此边界是14.5；X>25先改写为X≥26，因此边界是25.5。不能见到“小于”就机械地给原数字加.5。

完整例题： 40次独立试验，每次成功概率为.5。令X为成功次数，求P(15≤X≤25)。先确认固定次数、相同p与独立性，再使用X~Binomial(40,.5)。

  1. 检查近似条件。 np=20，n(1−p)=20。课程采用两项都大于5作为粗略筛选；这不是保证所有尾部概率都准确的定理。
  2. 匹配中心与分散。 正态近似变量的mean为np=20，SD为√[np(1−p)]=√10≈3.162278。
  3. 扩大到完整整数格。 目标改写为14.5到25.5之间的连续面积，对应标准化端点−1.739253与1.739253。
  4. 求面积。 Φ(1.739253)−Φ(−1.739253)≈.918010。
  5. 用精确值核对。 exact binomial为F(25)−F(14)≈.919310；不校正直接取15到25的正态面积约.886154，遗漏了两个半格。

Continuity correction处理的是离散格子与连续面积之间的边界差异，不能修复不合适的分布形状。课程发芽例n=20、p=.85有n(1−p)=3：P(X≤12)的exact值约.005921146，带12.5校正边界的normal值约.002416120，两者仍明显不同。原notes中该校正式旁的数值与公式不一致；以下代码直接按公式复算。遇到这种偏斜且靠近尾部的情形，优先使用exact binomial。

n <- 40
p <- .5
lower <- 15
upper <- 25
mu_count <- n*p
sd_count <- sqrt(n*p*(1-p))
# Keep both integer endpoints in the exact binomial calculation.
exact <- pbinom(upper,n,p)-pbinom(lower-1,n,p)
# Extend the continuous area to the outer edges of the integer bins.
normal_cc <- pnorm(upper+.5,mu_count,sd_count)-
  pnorm(lower-.5,mu_count,sd_count)
normal_uncorrected <- pnorm(upper,mu_count,sd_count)-
  pnorm(lower,mu_count,sd_count)
print(c(exact=exact,normal_cc=normal_cc,
        normal_uncorrected=normal_uncorrected))
stopifnot(abs(exact-.91930953224801) < 1e-12,
          abs(normal_cc-.91800967899962) < 1e-12)
# A skewed tail example: correction does not guarantee accuracy.
n_seed <- 20
p_seed <- .85
cutoff <- 12
print(c(expected_successes=n_seed*p_seed,
        expected_failures=n_seed*(1-p_seed),
        exact=pbinom(cutoff,n_seed,p_seed),
        normal_cc=pnorm(cutoff+.5,n_seed*p_seed,
                        sqrt(n_seed*p_seed*(1-p_seed)))))

Sampling distribution 描述的是统计量的反复变化

一株植物的高度会波动，一批植物的平均高度也会波动，但两者的波动程度不同。Sampling distribution（抽样分布） 不是这一批植物的高度分布，而是“重复抽取同样大小的样本，每次算一个平均值”后，这些平均值形成的分布。

  1. 固定目标总体和样本量 n，例如每次抽 25 株。
  2. 抽一批，算一个 ȳ；再独立抽另一批，算另一个 ȳ。
  3. 不断重复，把所有 ȳ 放到图中。图上的每个值代表一批样本的平均，而不是一株植物。
E(ȳ)=μ；Var(ȳ)=σ²/n；SE(ȳ)=σ/√n

均值的方差为什么要除以 n？因为 ȳ=(Y₁+…+Yₙ)/n。独立观测的方差相加得到 nσ²，再除以 n²，留下 σ²/n。开平方得到 standard error（SE，标准误）。SD 描述个体的差异，SE 描述估计量在重复抽样中的差异。

课程例 μ=115、σ=10、n=25，个体 SD 是 10，样本均值 SE 是 10/√25=2。若总体正态，P(ȳ>119)=P(Z>2)≈.0228；这与单个 Y 超过 119 的概率不同，因为两次标准化使用的分母不同。

Central Limit Theorem（CLT，中心极限定理） 说明：在独立同分布、均值和方差有限等条件下，n 增大时，标准化后的样本均值趋向正态。总体本身正态时，任意 n 的样本均值都精确正态；总体偏态时只是近似，不能因此说原始数据也变正态了。

“n>30”是常用经验，不是保证。严重偏态、极端尾部或相关观测仍要检查。n 从 25 增到 100，SE 从 2 减到 1；要把 SE 减半，通常需要四倍独立样本。样本量增加可以降低随机误差，却不能自动修复 selection bias。下一章正是利用估计量的抽样分布来构造区间和检验。

“均值接近总体”与“均值分布接近正态”是两个问题

Law of large numbers（LLN，大数定律）与CLT不能互换。在独立同分布、有限mean且0<σ²<∞的模型下，LLN说随着每个样本的n增大，样本均值偏离μ超过某个固定距离的概率趋于0；它不要求在一条实际抽样路径上，每加一个观测都比上一步更接近μ。

例如公平硬币把正面记1、反面记0，μ=.5。一次可能的观测顺序为[0,1,1,1,0]；累计均值为[0,.5,.6667,.75,.6]。第2次恰好到.5，第3次和第4次却走远了。这不违反LLN，不能在均值暂时回退时说“大数定律失效”。一个有限序列也不能证明或否定渐近结论。

LLN：对固定ε>0，P(|Ȳₙ−μ|>ε)→0
经典CLT：√n(Ȳₙ−μ)/σ 的分布→Normal(0,1)

CLT进一步描述经过中心化与标准化的抽样分布形状，并给出SE按1/√n缩小的尺度。它没有把原始观测变正态，也不保证一个小样本均值必然接近μ。上面的Exp模拟中，“Sample size n”是每次均值用多少观测；“抽100个samples”是在固定n下重复100次来观察均值的分布，不能把这两个数量混作n。

# A possible sequence from independent Bernoulli(.5) observations.
y <- c(0,1,1,1,0)
n <- seq_along(y)
running_mean <- cumsum(y)/n
error <- abs(running_mean-.5)
print(data.frame(n=n,observation=y,running_mean=running_mean,
                 absolute_error=error))
# The second mean equals .5, but the third is farther away.
stopifnot(error[3] > error[2])

P(A)=.4、P(B)=.5、P(A∩B)=.3，A与B独立吗？

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

硬币与骰子：先数基本结果

两枚公平硬币有四个等可能的有序结果：HH、HT、TH、TT。恰有一个 head 对应 HT 和 TH，因此概率为 2/4。两个公平骰子有 36 个等可能的有序结果；和为 7 的结果有 6 个，和为 11 的只有 2 个，所以概率分别是 6/36 与 2/36。

关键是先给基本结果计数，再汇总成“几个 head”或“sum 是多少”。不同 sum 对应的基本结果数不同，不能把所有可能的 sum 当作等可能。千万次模拟会接近理论概率，但有限次数的比例仍有随机波动。

保险类型与理赔程度：条件决定分母

在 policy type 与 claim severity 的联合频数表中，某个单元格的频数除以全部记录数，得到 joint probability P(severity∩policy)。如果问题改成“这种保单下，严重理赔有多常见”，分母就应改成该 policy 类别的列总数。

这样得到 P(severity|policy)。再把它与不区分保单类型的 marginal probability P(severity) 比较，可以检查两者是否符合 independence。保单类别是标签，类别的排列顺序没有数值大小的含义。

草坪萌发与失业：明确 success 是什么

Turfgrass germination 例设 n=20、π=.85。Y 表示萌发种子数，则 P(Y=17)≈.24283，而 P(Y≤17)≈.59510；后者在 R 中用 pbinom(17,20,.85) 计算。两者分别是一个计数的概率与多个计数概率的和。

Employment 例若把 success 从 employed 改成 unemployed，π 就从 .9 改成 .1，Y 也必须改为失业人数。先定义计数，再检查独立性、固定 n、相同成功概率及每次二分类这四个 binomial 条件；最后才根据 exactly、at most、at least 决定求和范围。

选举与牛奶产量：先确定参考模型

抽了就不放回：为什么“成功次数”未必是 Binomial

看到“n 次里面有几次成功”，不要立刻套 binomial。课程的候选人抽选例说明，抽样机制决定每一步概率是否保持不变。这里用一组新数字完整推导。

十名候选人中，六人有温室经验，四人没有。随机选三名，不放回。令 Y 为三人中有经验的人数。

  1. 第一次。 选到有经验者的概率为 6/10。
  2. 已知第一次成功。 剩下九人中只有五名有经验者，因此第二次成功概率变成 5/9。
  3. 如果前两次都成功。 第三次成功概率为 4/8。
  4. 三人全有经验。 P(Y=3)=(6/10)(5/9)(4/8)=1/6≈0.1667。

若错误地当作独立且每次 p=.6，会得到 .6³=.216。差异来自不放回使后续构成发生变化。一次成功会使下一次成功稍不容易，这些试验相互依赖。

还有一种更直接的计数方法：所有三人组合都等可能，共 C(10,3)=120 种。恰好两人有经验，要从六人中选二人、再从四人中选一人，共 C(6,2)C(4,1)=60 种。

P(Y=k)=C(6,k)C(4,3−k)/C(10,3)
P(Y=2)=60/120=.5
P(Y≥1)=1−C(4,3)/C(10,3)=29/30≈.9667

这就是 hypergeometric distribution（超几何分布） 的计数结构，是对课程不放回例子的延伸。这里的支持集为 k=0,1,2,3；一般还受到总体两类人数的限制。两次成功发生在哪个抽取位置，不需要再额外乘三：组合计数已经覆盖所有选人方式。

# Three draws without replacement from six successes and four failures.
dhyper(2, m=6, n=4, k=3)
phyper(0, m=6, n=4, k=3, lower.tail=FALSE)
# Compare the all-success event under two different mechanisms.
c(without_replacement=dhyper(3,6,4,3),
  independent_trials=dbinom(3,3,.6))

何时可以近似 binomial？ 如果总体很大、抽取比例很小，不放回对剩余成功比例的影响可能很小。但这是需要说明的近似条件，不能仅因为 n 大就成立。学习时先写四个词：放回吗、独立吗、概率恒定吗、次数固定吗，再选择分布。

练习： 若改成每次抽选后放回并重新随机抽，三次全有经验的概率变为 .216。注意此时允许同一个人被抽到多次，已经改变了实验。
