Two-sample & paired inference

两种肥料的差异，应该比较两组 mean，还是每块地内的差？

相同的两个平均值，在 independent 与 paired designs 中有不同的 SE。

独立 random variables 的 variance 会相加

E(ȳ₁−ȳ₂)=μ₁−μ₂
Var(ȳ₁−ȳ₂)=σ₁²/n₁+σ₂²/n₂（independent samples）

减法改变 mean 的方向，但 independent fluctuations 不会相互抵消，所以 variance 仍相加。若样本有相关性，应额外减去 2Cov(ȳ₁,ȳ₂)，不能继续使用 independent formula。

先决定 estimand 是 μ₁−μ₂、median difference 还是 paired mean difference，再选模型。Drug potency 课程例比较 fresh 与 stored samples，两个独立样本的设计决定后面的 denominator。

Pooled t-test 假定共同的 population variance

sₚ²=[(n₁−1)s₁²+(n₂−1)s₂²]/(n₁+n₂−2)
SE=sₚ√(1/n₁+1/n₂)
t=[(ȳ₁−ȳ₂)−D₀]/SE，df=n₁+n₂−2

每个 sample variance 都估计相同 σ²，因此按 degrees of freedom 合并。不是对 SD 直接取平均。假设 independent observations、正常或足够 robust 的 sampling distributions、equal population variances。

原创例：n₁=n₂=5，means=12 与 10，s₁²=s₂²=4。Pooled variance=4，SE=√1.6≈1.265；H₀ difference=0 时 t≈1.581、df=8，95% CI=2±2.306×1.265≈[−.917,4.917]。估计为正，证据仍可能不足。

Welch t-test 不必强行共享 variance

SE=√(s₁²/n₁+s₂²/n₂)
ν≈(s₁²/n₁+s₂²/n₂)² / [(s₁²/n₁)²/(n₁−1)+(s₂²/n₂)²/(n₂−1)]

Welch / Satterthwaite approximation 用两组各自 variance 估计 uncertainty，df 可为非整数。Statistic 仍是 effect-minus-null 除以 SE，CI 使用对应 t critical value。尤其在 unequal n 与 unequal variances 同时出现时，pooled t 的 Type I error 可能偏离 α。

课程模拟改变 sample size 与 variance ratio，强调检验误差率取决于假设。不要先用小样本 F-test 未显著就宣称 equal variances 得到证明。R 的 t.test 默认 Welch；要 pooled 必须明确 var.equal=TRUE。

t.test(x,y,alternative='two.sided') # Welch
 t.test(x,y,var.equal=TRUE)           # pooled，仅在有依据时
# SAS PROC TTEST 的 Pooled 与 Satterthwaite 行要选对

读 one-sided 和 two-sided output 要与 Hₐ 对齐

软件往往同时给 Pr>t、Pr<t 与 Pr>|t|。Right-tail alternative 使用右尾；left-tail 使用左尾；two-sided 使用两尾。在 symmetric t distribution 下，two-sided P = 2 × 较小的单尾 P，而不是随意把任意单尾 P 乘 2。

课程 tapeworm treatment 例以 parasite count 为 response；定义 difference 是 treatment−control 后，改善可能对应负差，Hₐ 的方向要随这个定义写。报告到研究问题，而不是仅粘贴软件表格。

Wilcoxon rank-sum 使用整体排序比较两组

  1. 合并 independent samples 并排序。
  2. 相同值用 average ranks。
  3. 取第一组 rank sum W，或 U=W−n₁(n₁+1)/2。
  4. 用 null 下的 exact distribution 或带 tie correction 的 asymptotic approximation 求 P。
E(W)=n₁(N+1)/2
无 ties：Var(W)=n₁n₂(N+1)/12，N=n₁+n₂

Wilcoxon rank-sum / Mann–Whitney 的 basic null 是两组 distributions 相同。若共同形状且只发生 location shift，可以解释为中心位移；不能对任意不同形状宣称这是“检验 median 相等”。它依然需要 independent observations，并非完全没有假设。

原创例 A=[1,4]、B=[2,3]：ranks A 为 1 和 4，W=5，正好等于 null mean 2×5/2=5。课程 alcohol reaction-time 例示范非正常分布及错误使用 t-test 的风险。

wilcox.test(x,y,exact=FALSE) # 有 ties 时说明近似与 continuity correction
# SAS: PROC NPAR1WAY WILCOXON
有 tied rank blocks tⱼ：Var(W)=n₁n₂/12 × [N+1−Σ(tⱼ³−tⱼ)/(N(N−1))]

Large-sample Z=(W−E(W))/√Var(W)。若采用 continuity correction，按 rejection tail 调整 0.5；ties 多或样本小要核对 exact/permutation 条件和软件版本。“每组超过 10”是课程的近似经验，不能保证任何数据的 approximation 都准确。

Paired t-test 先把每对变成一个 difference

同一辆车在两个维修店得到报价、同一块地对比两个处理，pair 内共享个体背景。令 Dᵢ=Yᵢ₁−Yᵢ₂，将 n 对 differences 当成一个样本。

t=(D̄−D₀)/(sᴅ/√n)，df=n−1
CI=D̄±t₁₋α/₂,ₙ₋₁ sᴅ/√n
Var(D)=σ₁²+σ₂²−2Cov(Y₁,Y₂)

正相关会让 sᴅ 小于独立组的 uncertainty。课程 wrecked-car quotes 在忽略 pairing 时不能发现差异，而 paired analysis 利用车本身的差异抵消背景。Normality 要检查 differences，不要求每个 marginal distribution 独自 normal；pairs 之间仍须 independent。

原创 differences=[1,2,3,2,2]：D̄=2、sᴅ²=.5、SE≈.3162、t≈6.325、df=4。把 pair 顺序打乱会改变 sᴅ，说明 pairing 是数据结构。

t.test(before,after,paired=TRUE)
t.test(before-after,mu=0) # 等价，保持相同 difference 方向

启用 JavaScript 后可调整参数。完整推导与 worked examples 可直接阅读正文。

Signed-rank 同时使用 direction 和 magnitude ranks

Wilcoxon signed-rank 先删 zero differences，再按 |Dᵢ| 排 rank，ties 用 average rank；将正差 ranks 相加为 W⁺，负差 ranks 为 W⁻。无 ties 时 E(W⁺)=m(m+1)/4，Var(W⁺)=m(m+1)(2m+1)/24。

它要求 difference distribution 对称，使 null 下 sign 与 absolute magnitude 的关系适合推导。若 differences 极度不对称，sign test 的 median 问题可能更合适。软件可能报告 W⁺、W⁻ 或 min(W⁺,W⁻)，必须核对 definition 及 tail。课程 split-field grass-clipping 例通过 paired fields 排除地块背景。

原创 differences=[−3,1,2]：|D| ranks 为 3,1,2，W⁺=1+2=3，W⁻=3。总 rank=6；不能先排序 signed differences 再取绝对值。

有 |D| ties（各块大小 tⱼ）：Var(W⁺)=m(m+1)(2m+1)/24 − Σ(tⱼ³−tⱼ)/48

删零之后重新确定 m、ranks 与 tie blocks。无 ties 时 W⁺+W⁻=m(m+1)/2；average ranks 也保持这个总和。可用 wilcox.test(before,after,paired=TRUE)，先确认 differences 的方向；交换 before / after 会反转 one-sided alternative。

预算要分配给真正独立的单位

equal n per independent group：n≈2σ²(z₁₋α/₂+z₁₋β)²/Δ²
paired：n pairs≈σᴅ²(z₁₋α/₂+z₁₋β)²/Δ²

Independent formula 的 n 是 每组数量，总数 2n。Paired formula 用 difference variance。若 n₂=r n₁、两组共同 σ²，则 n₁≈σ²(1+1/r)(z sum)²/Δ²，n₂向上取整；unequal variances 时需要对应 variance terms。Course cattle-diet example 区分 equal 与 unequal allocation。Precision-based CI planning 将 z sum 换成 z critical 并以 E 代替 Δ。

练习：同一植物处理前后测量，能用 independent t-test 吗？

设计为 paired，应该分析各植物 differences 或相应 repeated-measures model。Independent formula 忽略 covariance。只有确实不同独立单位才按 independent samples。

Precision planning 的 paired 版本是 n≈(z₁₋α/₂σᴅ/E)²；如果课程用 full width W，应将 E=W/2。已知的两组 σ₁、σ₂ 时 difference variance 为 σ₁²/n₁+σ₂²/n₂，equal n planning 为 n≈(σ₁²+σ₂²)(z sum)²/Δ²。Real t planning 需 iteration，因为 t critical 与 df 随 n 改变。

把课程案例连回方法与结论

下面将课程中的不同场景连回明确的 statistical question。数字来自教学例子；不是个人提交作业或考试答案。重复的逐行软件输出归并为机制与读取方法。

Fresh / stored drug potency

这是两个 independent groups：估计 μFresh−μStored，先看 difference SE 与 variances 的条件。相同数据同时显示 pooled / Satterthwaite output 时，按模型假设选择行；显著性不能用“哪行 P 更小”决定。

Sheep tapeworm treatment（notes）

独有的 tapeworm case 比较 drug-treated 与 control sheep。先按定义设置 subtraction 和 Hₐ：虫数降低对应 treated−control<0。Same t statistic 的 left、right、two-tail P 分别是 CDF、1−CDF、2×smaller-tail。

Alcohol reaction time、repair estimates、grass clippings

Alcohol 的独立参与者用整体 ranks；repair estimates 在同一辆车上 paired，先求 garage1−garage2；fertilizer 在每个 field 分半处理，signed-rank 分析 field differences。它们分别对应 independent skewed observations、paired mean、paired symmetric location。

Cattle diets 与 unequal allocation

固定最小有意义 weight-gain difference，再估计共同 planning variance；equal n 是每组数量。n₂=m n₁ 时 SE²=σ²(1+1/m)/n₁。不能把 more observations 自动当 more independent animals。
