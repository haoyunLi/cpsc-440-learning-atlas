Confidence intervals & hypothesis testing

观察到的平均差异，是信号还是抽样波动？

只报估计值忽略其不稳定性；本章把 sampling distribution 变成可解释的区间和决策。

Confidence interval 是一个有覆盖率的程序

已知 σ：CI = ȳ ± z₁₋α/₂ σ/√n
未知 σ、normal population：CI = ȳ ± t₁₋α/₂,ₙ₋₁ s/√n

Confidence level 1−α 描述重复抽样时构造出的区间包含固定参数 μ 的长期比例。得到某个区间后，μ 是否落入已确定；frequentist 95% CI 不能解释成“μ 有 95% 概率在这个区间”。也不是 95% 个体落在其中。

课程例 n=168、ȳ=36.92、s=6.737，以 large-sample z approximation 得 SE=.5198，95% CI≈[35.90,37.94]。小样本且未知 σ 用 t；大样本用 t 仍然合理。相同数据下，99% CI 比 95% 更宽；n 增加、SD 降低会使区间变窄。

若已知 σ，希望 half-width 不超过 E，n≥(z₁₋α/₂σ/E)²，向上取整。课程 cereal 精度例 E=.25、σ=.75、99% confidence，用 z≈2.576 得 n≈59.72，所以 60。未知 σ 用 pilot estimate 并考虑预算及实际设计。

七步 test 把问题、模型与结论连起来

  1. 写 H₀ 与 Hₐ：例如 H₀:μ≤μ₀，Hₐ:μ>μ₀。方向由研究问题预先确定。
  2. 在观察结果前确定 α 与 sample size。
  3. 选 statistic 及它在 null 下的 reference distribution，检查设计假设。
  4. 确定 rejection region 或计算 P-value 的规则。
  5. 收集数据、算 effect estimate、SE 与 statistic。
  6. 按 P≤α 或 critical value 决定 reject / fail to reject。
  7. 用研究语言报告 effect、uncertainty、证据与适用范围。
Z=(ȳ−μ₀)/(σ/√n)　或　t=(ȳ−μ₀)/(s/√n)，df=n−1

P-value 是 H₀ 及模型成立时，获得当前或更极端 statistic 的概率。它不是 H₀ 为真的概率，也不是差异由偶然造成的概率。Fail to reject 表示证据不足，不能改写为“接受 H₀”或“证明相同”。

原创例：已知 σ=10，n=25，ȳ=54，H₀:μ=50。SE=2，Z=2；双尾 P≈.0455，α=.05 时 reject。若右尾 P≈.0228；不能看完结果再把双尾改成单尾。

Type I 与 Type II errors 对应不同世界

决策H₀ true指定 alternative true
Reject H₀Type I error，概率 αPower = 1−β
Fail to reject正确不拒绝Type II error，概率 β

α 在 null 世界量化 false rejection。β 必须针对指定 μₐ、variance、n 与检验定义；不指定 effect size，就没有唯一 power。固定 n 下减小 α 通常增加 β；更大的真实差异、更小 variability 或更大 n 通常提高 power。

右尾临界样本均值 c=μ₀+z₁₋α σ/√n
β(μₐ)=Φ[(c−μₐ)/(σ/√n)]
双尾 β=Φ[(cᵤ−μₐ)/SE]−Φ[(cₗ−μₐ)/SE]

课程 encyclopedia training 示例 μ₀=33、μₐ=38、s≈8.4、n=35、α=.05，以已知/规划 σ 的 z 近似得到 c≈35.34、β≈.0305、power≈.9695。未知 variance 的精确 t power 用 noncentral t，不能把 t critical value 代入 standard normal 就声称精确。

Sample size 先服务研究中有意义的差异

one-sided z plan: n ≈ σ²(z₁₋α + z₁₋β)²/Δ²
two-sided approximate plan: n ≈ σ²(z₁₋α/₂ + z₁₋β)²/Δ²

Δ=|μₐ−μ₀| 是最小值得发现的差异。公式在 independent sampling 与已知/规划 variance 下使用，双尾公式通常是近似；向上取整并考虑 dropout、clustering 和 repeated measurements。精度 E 与 power 的 Δ 回答不同问题，不要混用。

例如 σ=10，Δ=5，one-sided α=.05、目标 power=.8，n≈100(1.645+.842)²/25≈24.74，取 25。统计显著不代表 agronomically meaningful；应同时比较 estimate 和事先定义的实质阈值。

Student’s t 承认我们也在估计 variance

σ 未知时用 s，分母变成随机量，使标准化均值有更重的尾。Normal independent observations 下 t statistic 精确服从 Student's t(df=n−1)；df 增大逐渐接近 standard normal。

课程冰淇淋微生物例：n=9、ȳ=.4564、s=.2128，检验 μ>.3：t≈2.205、df=8、one-sided P≈.029。α=.01 时不能拒绝，即使 estimate>.3。仓库处理时间例同时报告 mean CI、t 与 P；normality 诊断看数据或残差的 QQ plot，而不是只看检验结果。

t procedures 对温和偏离可能 robust，但 small n、heavy tails、强偏态和 outliers 会影响 error rates。Shapiro–Wilk 未拒绝不证明 normal，小样本下可能缺乏能力。独立性通常由实验设计判断，QQ plot 无法检验它。

t.test(y,mu=.3,alternative='greater',conf.level=.99)
qt(.975,df=8); pt(2.205,df=8,lower.tail=FALSE)
# SAS: PROC TTEST H0=.3 SIDES=U ALPHA=.01

Noncentral t 用于未知 σ 的 t-test power：假定 planning σ，δ=(μₐ−μ₀)√n/σ；alternative 下 T~t(df=n−1,ncp=δ)。Right-tail power=1−Fnct(t₁₋α;df,δ)，two-sided 将两个 rejection tails 相加。这里不能把 s 当已知 σ，再声称得到精确 t power；数值上可用 pt(critical,df,ncp=delta) 或 power.t.test()。

当中心问题是 median：Sign test 与 order statistics

Sign test 只记录 Yᵢ−M₀ 的正负，丢弃恰好等于 M₀ 的 ties，并用剩余 m 个值。在 continuous distribution、H₀ median=M₀ 下，positive count B~Binomial(m,.5)。方向由 Hₐ 决定，two-sided 可用两边尾概率；离散/tied 数据需要说明假设和规则。

原创例：9 个非零差中 8 个为正，right-tail P=P(B≥8)=(9+1)/512≈.01953。它回答 median 或正负平衡问题，不能当成 mean 的检验。

Median CI 用 sorted observations Y₍₁₎…Y₍ₙ₎。选 k 使 2P(Binomial(n,.5)≤k−1)≤α，再用 [Y₍ₖ₎,Y₍ₙ₋ₖ₊₁₎]；实际 coverage 由于离散性常高于名义值。课程 recyclable material 例正是将 order statistics 与 binomial 连接。

Course notes 也给 large-sample order-statistic approximation：下标约 n/2 ± z₁₋α/₂√n/2（整数与端点规则要写清）。它来自 B~Binomial(n,.5) 的 normal approximation；small n 优先用上面的 exact binomial coverage。改变 median 问题不能只因为 mean test 不显著，必须依据科学目标。

把显著性转换成准确的话

练习：P=.08，α=.05，可以说处理“没有作用”吗？

不能。可以说数据没有提供足够证据拒绝指定 null。报告 estimate 和 CI；若想证明差异足够小，应定义 equivalence margins 并使用合适的 equivalence test。

练习：95% CI 不含 μ₀ 与双尾 test 的关系是什么？

在使用相同模型、SE 和 α=.05 的对应 test 时，CI 不含 μ₀ 等价于 reject；若用不同 approximation 或单尾 test，必须先确认对应关系。
