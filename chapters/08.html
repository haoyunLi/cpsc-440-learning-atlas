ANOVA：分解变异来比较多个 mean

学习单元 06 / 10 · Chapter 08

One-way ANOVA & diagnostics

三种肥料是否有相同的总体平均产量？

逐对比较会引入多重检验；ANOVA 先回答整体 mean 是否一致。

把每个观测写成背景、处理与误差

Yᵢⱼ=μ+τᵢ+εᵢⱼ　　Στᵢ=0（等权参数约束）
εᵢⱼ independent Normal(0,σ²)

Completely Randomized Design (CRD) 在适合的 experimental units 中随机分配 treatments。μ 是 model 的 baseline / grand mean（平衡时等于总体组均值平均）；τᵢ 是 treatment effect；εᵢⱼ 是同 treatment 内仍无法解释的 variation。

H₀:μ₁=…=μₜ，Hₐ:至少一个 mean 不同。Alternative 不是“所有组都不同”。One-way ANOVA 假定 independent errors、constant variance 及用于 exact F-test 的 normality。随机化减少系统性 assignment bias，但不会把十片同盆叶子变成 independent EUs。

一项偏差拆成 treatment signal 与 residual

Yᵢⱼ−ȳ.. = (ȳᵢ.−ȳ..) + (Yᵢⱼ−ȳᵢ.)
SST = ΣᵢΣⱼ(Yᵢⱼ−ȳ..)²
SStrt = Σᵢ nᵢ(ȳᵢ.−ȳ..)²
SSE = ΣᵢΣⱼ(Yᵢⱼ−ȳᵢ.)²
SST = SStrt + SSE

Within each group residuals 总和 0，所以平方展开中的 cross-term 加总消失。这不是任意拆分平方都可相加，而是 least-squares projection 的性质。Grand mean ȳ.. = Σnᵢȳᵢ./N，unequal n 时按样本数加权。

Degrees of freedom：total N−1；treatment t−1；error N−t。Mean square = SS/df；F=MStrt/MSE。在 H₀ 下二者估计相同 σ²；处理 mean 有差异会将 numerator 拉大。

一个完整的小型 ANOVA 计算

原创数据 A=[4,5,6]、B=[7,8,9]、C=[10,11,12]。Group means 5、8、11；grand mean=8；N=9、t=3。

  1. SStrt=3[(5−8)²+0+(11−8)²]=54。
  2. 每组 SSE=1+0+1=2，总 SSE=6；SST=60。
  3. df treatment=2、error=6、total=8。
  4. MStrt=27、MSE=1，F=27，reference F(2,6)，P=.001。
  5. α=.05 时 reject equal means；再设计 follow-up comparisons，不能凭整体 F 说所有 pair 显著。

如果保持 group means 而增加 within-group variation，MSE 增加、F 减小。同样的 mean separation 在嘈杂实验中提供更弱证据，interactive 图会同时显示 signal、noise 和 SS。

用 residuals 检查模型的条件，而非混合 raw data

Residual eᵢⱼ=Yᵢⱼ−ŷᵢⱼ；one-way fitted value 是 group mean。各组 raw values 混合后可能多峰，即使各组 errors normal；所以 pooled raw QQ plot 不是 model-error normality 的合适检查。

QQ plot 比较 residual quantiles 与 normal theoretical quantiles；弯曲和 tails 偏离提示不匹配。Residual vs fitted 图若呈 funnel 提示 variance 随 mean 改变；group-specific plots 和 Brown–Forsythe 补充检查。Shapiro–Wilk 对小样本 power 低、大样本可能发现微小偏离，结合图与设计判断。

课程 leaf phosphorus、psychology students 例将 model output、QQ、Shapiro–Wilk 与 variance diagnostics 连起来。统计检验不替代科学问题；报告 treatment effect、样本结构和 uncertainty。

fit <- aov(y ~ treatment,data=d)
summary(fit)
plot(fitted(fit),residuals(fit)); abline(h=0)
qqnorm(residuals(fit)); qqline(residuals(fit))
# SAS: PROC GLM; MODEL y=treatment; OUTPUT OUT=r R=resid;

Kruskal–Wallis 通过 ranks 比较多个 distributions

H = [12/(N(N+1))]Σ(Rᵢ²/nᵢ) − 3(N+1)

Rᵢ 为合并排序后第 i 组 rank sum。Large-sample H 近似 χ²(t−1)。有 ties 时除以 correction C=1−Σ(tⱼ³−tⱼ)/(N³−N)。小样本使用合适 exact/permutation methods。

Kruskal–Wallis 是 rank-sum 的多组扩展，basic null 为相同 distributions；共同形状、location-shift assumptions 才允许仅解释为中心差异。它不自动解决 unequal variances。若目标仍是 means 且 variance 不等，可考虑 Welch ANOVA；不要只因 normality 不好就改变 estimand 而不说明。

kruskal.test(y ~ treatment,data=d)
oneway.test(y ~ treatment,data=d,var.equal=FALSE)

Transformation 改变分析尺度，也改变问题

若 spread 随 mean 系统变化，可以尝试有科学依据的 transformation，随后重新检查 residuals。课程 Gulf oxygen consumption 和 laughing-gas examples 比较不同 scales；不能只挑产生最小 P 的 transformation。

mean–variance pattern候选 scale条件与解释
Var(Y)≈kμ√Y非负 counts，低值与 zeros 需谨慎
Var(Y)≈kμ²log YY>0；差异对应 multiplicative ratios
Var(Y)≈kμ⁴1/Y不能有 0；变换会反转数值顺序

Approximate delta method：Var[g(Y)]≈[g′(μ)]²Var(Y)，说明为什么这些 transforms 可以 stabilize variance。Box–Cox gλ(y)=(yλ−1)/λ，λ=0 时 log y，要求正数；选择 λ 后要保留解释和模型检查。现代 count 或 proportional data 有适合的 generalized models，transformation 并非唯一选择。

Notes 的表还包括 proportion p 的 arcsine-square-root transform g(p)=arcsin√p：若 fixed denominator m 下 Var(p)=p(1−p)/m，g′(p)=1/[2√p(1−p)]，delta method 给近似 variance 1/(4m)。Near 0/1 或不同 denominators 时该近似不能随意推广；binomial model 能直接表达 denominator。

整体问题与 follow-up 问题需要分开

练习：F 很大，就说明 effect 在实际生产中很大吗？

不一定。F 比较 signal 与 noise 并受 sample size 影响。报告原单位 mean differences、CI 和科学意义；非常稳定的小差异也可能显著。

练习：为何 SSE 的 df 是 N−t？

每组估计一个 mean，使该组 residuals 有一个和为零的约束。t 个 groups 共消耗 t 项独立信息，剩 N−t。

原始 greenhouses / CRD

四组 greenhouse 数据的总偏差分成 fitted treatment deviations 与 within-treatment residuals；notes 实算表提醒每一项 SS 对应 df。本站的小型原创例子重做完整步骤，避免只记一个软件 F 值。

Apple leaf phosphorus 与 psychology students

Leaf P 比较多个 treatment means，omnibus F 拒绝后仍需指定 comparisons；psychology groups 的 nonnormal residuals 引出 Kruskal–Wallis，并有 tie correction。Group labels 不是连续 predictor。

Gulf pollution / oxygen consumption

不同距 shore 的 sampling groups 出现 mean–variance relationship；√Y scale 可能降低 heteroscedasticity，必须重看 residuals。变换后的 ANOVA 结论针对 E(√Y) 的差异，不能直接写成 original mean 的同一检验。

Laughing-gas 与 IBS scores（notes）

Laughing-gas剂量 / IBS 的三个气体组案例比较 raw、sqrt 与 log scales；notes 明确症状 score 的科学含义。Raw residual normality 与 variance 检查不同，改变 scale 后要同时复查。不能依据 P 值择优而忽略测量与零值。
