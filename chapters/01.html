从测量到数据描述

学习单元 01 / 10 · Chapter 1–3

Descriptive statistics

一组植物长得怎样，能用一个平均数说清吗？

先描述你实际观测到了什么，再讨论能否推到未观测的总体。

推断之前，先确定你在谈论谁

假设你想比较两种肥料，看看哪一种能让植物长得更高。把测到的高度求平均并不难，真正需要先想清楚的是：你想说明这批植物，还是想说明今后采用同样种植条件的植物？这两个问题需要的证据并不一样。

Population（总体） 是你想了解的全部单位，Sample（样本） 是实际选来测量的一部分。例如，研究目标是某地区、某个生长季的这一品种，你只测了其中 20 株。这 20 株是样本；目标地区中符合研究条件的所有植株才构成总体。结论适用的范围叫 inference space，需要把品种、环境和时间说清楚。

接着区分两个层次的数字。总体平均高度 μ 是 parameter（参数）；20 株的平均高度 ȳ 是 statistic（统计量）。同一个目标总体的 μ 是固定的，只是我们通常不知道。换一批植物重新抽样，ȳ 则可能改变。统计推断要处理的，正是“一个会随样本改变的数字，能把固定但未知的参数估计到什么程度”。

  1. 先定义目标。 想知道哪个总体、哪个参数？平均高度与高度的波动是不同问题。
  2. 再说明样本怎么来。 只挑高大植株，会让样本系统性偏离总体；样本再多也不能自动消除这种 selection bias。
  3. 计算样本结果。 假设这 20 株平均高 30 cm，这准确描述了已测的样本。
  4. 最后才向总体推断。 要说目标总体的平均高度接近 30 cm，还需要合理的抽样过程和不确定性说明。后面的 confidence interval 就服务于这一步。

Random sampling（随机抽样） 与 random assignment（随机分配） 也要分清：前者决定谁进入样本，帮助总体推断；后者决定入选单位接受什么处理，帮助识别处理效应。把肥料随机分给同一温室的盆栽，并不会使这些盆栽自动代表所有气候条件。

在 observational study / survey 中，研究者记录已经发生的暴露和结果，可能受到 confounding、selection bias 和 nonresponse 的影响；在 designed experiment 中，可以事先安排处理和随机分配。无论是哪一种研究，都应先检查 sampling frame，也就是实际有机会被抽中的单位名单。

变量类型决定图与计算是否有意义

在选择统计方法之前，先看一行数据代表什么、每一列记录什么。Variable（变量） 是一个单位上记录的属性，例如品种、植株高度或结籽数量。并不是所有写成数字的列都适合求平均。

先认变量，再选描述方式
类型例子数字应怎样理解
Nominal品种 A、B、C只有类别，没有自然大小顺序
Ordinal轻、中、重病害有顺序，但相邻等级不一定等距
Discrete quantitative一株的种子数可计数的数量，通常取整数
Continuous quantitative高度、质量连续测量，必须保留单位

例如，把品种 A、B、C 编成 1、2、3，方便软件识别，却不会使“平均品种 2.1”产生生物学意义。相反，高度 30 cm 与 40 cm 的差 10 cm 有明确含义；它们可以用于均值和方差的计算。

再看 experimental unit（EU，实验单位）。它是独立接受处理的单位。若肥料分给整盆植物，一盆里测了十片叶子，这十片叶子共享处理和盆内环境，不能直接算成十个独立的肥料重复。叶片是测量单位，盆才是这里的实验单位。

实际整理数据时，把每个单位的编号、处理、测量单位、缺失原因以及重复结构记下来。一次生物学重复中的多次测量可以帮助提高测量精度，但不能凭空增加独立重复数。这一点会在 sample size、paired analysis 和 blocking 中反复出现。

Histogram 把数值范围变成可比较的频率

拿到一长列高度，直接盯着数字很难看出分布。Histogram（直方图） 先把数值范围分成区间，再数每个区间里有多少观测。它回答的是：数据主要集中在哪里，尾部伸向哪里，是否有多个聚集区域？

  1. 确定分箱边界。 例如数据为 [2,3,3,4,18]，可用 [0,5)、[5,10)、[10,15)、[15,20]。每个值只能进入一个区间；最末端的边界要保证包含最大值。
  2. 逐项计数。 四个区间的 frequency 分别为 4、0、0、1。总数 4+0+0+1=5，应等于样本量 n。
  3. 决定纵轴。 若画 relative frequency，就把计数除以 5，得到 .8、0、0、.2。这些比例总和为 1。
  4. 回到原始数据解释。 大部分观测落在较低的区间，右侧有一个远离主体的值。换一种分箱方式会改变图的细节，却不会改变这五个观测。

Histogram 的横轴是连续数值区间；bar chart（条形图） 的横轴是类别。条形图中类别顺序可以按问题调整，直方图中数值顺序不能随意交换。若区间宽度不同，不能只用柱高代表频率，需要用柱子的面积：

density height = frequency / (n × bin width)

这样每根柱的面积才等于该区间的样本比例。课程的鸡体重例子把频数表、累计频数和直方图连在一起：先数观测，再读分布。若要估计 P(Y>3.9)，就数超过 3.9 的值并除以 n；P(Y≥3.9) 是否不同，要看恰好等于 3.9 的观测。

小样本也可以用 stem-and-leaf plot（茎叶图）。例如 key 写成 12|6=12.6，stem 12 和 leaf 6 合起来恢复原数值。把叶子排序后，既能看分布，也能找到中位数；key 不写清楚，图中的数值单位就不确定。

Mean、median 与 mode 回答不同的“典型”

“这组数据通常多大？”可以有不同答案。Mean、median 和 mode 使用的信息不同，因此应根据研究问题选择，而不是把三个词当作同一数字的不同叫法。

sample mean：ȳ = (Y₁+Y₂+…+Yₙ)/n

符号 Yᵢ 表示第 i 个观测，n 是观测总数，Σ 表示把所有观测相加。Mean（均值） 使用每一个数值；median（中位数） 只看排序后的中间位置；mode（众数） 找出现次数最多的值，也能用于类别数据。

  1. 算均值。 对 [2,3,3,4,18]，先加得到 30，再除以 5，得到 ȳ=6。
  2. 找中位数。 数据已经排好序，第三个值是 3，所以 median=3。偶数个值时，取中间两个值的平均。
  3. 找众数。 3 出现两次，其他值各出现一次，所以 mode=3。可能有多个众数，也可能没有唯一的众数。
  4. 解释差异。 18 参与了总和，把均值拉到 6；中间位置仍是 3。若关心总量或每个单位的平均贡献，均值有意义；若关心一个典型单位位于哪里，中位数可能更直接。

为什么均值也叫“平衡点”？把每个观测减去 6，得到 −4、−3、−3、−2、12，偏差加起来正好为 0。右侧的大偏差抵消了左侧几个小偏差。这个性质会直接进入 variance 和 regression 的推导。

Skewness（偏度） 描述左右不对称，长尾向右叫正偏，向左叫负偏。右偏数据的均值常高于中位数，但不能把这个经验关系当作所有分布的定理。Kurtosis（峰度） 与标准化四阶矩和尾部极端值有关；使用时要说明是否减去 3，不能仅看“峰尖不尖”。

Variance 将偏差平方，SD 把单位还给你

均值相同的两组数据，表现仍可能很不一样。[4,4,4] 和 [2,4,6] 的均值都是 4，后一组却更分散。要描述这种差别，就需要衡量每个值离均值有多远。

直接把偏差相加没有用：−2+0+2=0，正负偏差抵消了。Variance（方差） 把偏差平方后相加，使两边的偏离都贡献正数；standard deviation（SD，标准差） 再开平方，把单位还原。

s² = Σ(Yᵢ−ȳ)²/(n−1)；s=√s²
  1. 先算中心。 [2,4,6] 的 ȳ=(2+4+6)/3=4。
  2. 求每个偏差。 2−4=−2，4−4=0，6−4=2。
  3. 平方并相加。 (−2)²+0²+2²=4+0+4=8。这一步得到的是 sum of squared deviations。
  4. 除以自由度。 n=3，所以 s²=8/(3−1)=4。
  5. 还原单位。 s=√4=2。若原数据是 cm，方差是 cm²，标准差是 cm。

分母为什么是 n−1？样本均值已经由这组数据估计出来，偏差必须满足总和为 0。知道其中 n−1 个偏差，最后一个就被确定了。在独立同分布且总体方差有限的条件下，除以 n−1 使 s² 成为 σ² 的 unbiased estimator；s 本身并不因此严格无偏。

还可以使用课程 notes 的等价计算式。对 [2,4,6]，ΣYᵢ²=56，(ΣYᵢ)²/n=144/3=48，两者相减仍得到 8：

s² = [ΣYᵢ²−(ΣYᵢ)²/n]/(n−1)

这个 machine formula 便于手算。但很大的数减去非常接近的数，可能损失浮点精度；程序通常优先使用中心化或稳定的更新算法。

Range（极差） 只看最大值减最小值，忽略中间观测。Coefficient of variation（CV） 为 100s/ȳ%，用相对尺度描述分散，但需要真实零点且均值远离 0，不适合任意套到 Celsius 温度。Normal distribution 的约 68%、95%、99.7% 规则指 μ±1σ、2σ、3σ；偏态或多峰数据不能直接照搬。

Box plot 把中心、分散和异常候选分开

如果要在一张图里同时比较中心、分散和远离主体的观测，box plot（箱线图） 很方便。读图时先看中位数，再看箱体宽度，最后看 whiskers 和单独显示的点；它并不完整显示分布形状。

第一、第二、第三四分位数 Q1、Q2、Q3 分别对应 25%、50%、75% 的位置。Q2 就是中位数，IQR（四分位距） 为 Q3−Q1。计算规则并不只有一种，软件报告的 quartiles 可能略有差异。

  1. 找箱体。 对 [2,3,3,4,18]，采用 R type 7 的线性插值规则，Q1=3、Q2=3、Q3=4。箱体从 3 到 4，内部线位于中位数 3。
  2. 计算内围栏。 IQR=1；下围栏 3−1.5×1=1.5，上围栏 4+1.5×1=5.5。
  3. 找须端点。 在围栏以内，最小实际观测是 2，最大是 4。因此须伸到 2 和 4，不是伸到 1.5 和 5.5。
  4. 单独画远离主体的值。 18 超过上围栏，是 outlier candidate。这是在提示你检查来源和研究含义，不是在自动判它为错误。

Notes 还给出 outer fences：Q1−3IQR 与 Q3+3IQR。越过内围栏但未越过外围栏的点可标为 moderate，越过外围栏的点可标为 extreme。这里 18 也超过上外围栏 7。所有这些标签都是描述规则，不能替代数据质量核查或 normality test。

课程鸡体重的另一个例子 Q1=4.1、Q3=4.5，IQR=.4，内围栏为 3.5 与 5.1。步骤完全相同，只是换了单位和数据。Pollen 和 flight delays 的例子则提醒我们：少数较大的值会明显影响均值和方差，比较多个组时可以并排画箱线图，再回看各组样本量与原始分布。

# R：这里明确使用 type 7，与本站交互保持一致
mean(y); median(y); var(y); sd(y)
quantile(y, c(.25,.5,.75), type=7)
hist(y, breaks=10); boxplot(y)
# SAS：PROC UNIVARIATE、PROC FREQ、PROC SGPLOT

注意：R 的 boxplot hinges 与 quantile(type=7) 在某些样本量下可能不同。比较课件和软件结果时，先核对 quartile convention，再判断是否算错。

把描述转成可以检验的问题

先写自己的计算或理由，再展开答案。重点是把数字对应回参数、设计与研究问题。

把 [2,4,6] 每项加 10，中心与分散各怎样变？

先算新均值：(12+14+16)/3=14。再减去新均值，偏差仍为 [−2,0,2]，所以方差仍为 4、SD仍为 2。平移改变位置，不改变相对分散。若改为每项乘 10，偏差也乘 10，方差乘 100，SD乘 10。

两个处理均值相同，能说表现一样吗？

先明确“表现”包含什么。均值相同只说明中心这一方面相同；波动、尾部风险与分布形状仍可不同。画图，再把问题写成要比较 mean、median 还是 variance。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

鸡体重、花粉与航班延误

鸡体重案例先保持数据不变，再改变 histogram 的 bin width。每根柱子的含义随分箱边界改变，但总观测数不变。如果改用 relative frequency，还要把每箱计数除以总数，才能比较不同样本量的图。

花粉（pollen）案例有较长的右尾。少数很大的值会把 mean 向右拉，而 median 主要由排序后的中间位置决定。Class notes 中的 flight delays 则用 side-by-side box plots 比较日期和航班：先统一坐标尺度，再分别看中心、IQR 和尾部，不把某一个极端值当作整组的典型表现。

饮水量：从 stem-and-leaf 还原观测

鼠在一小时内的饮水量用 stem-and-leaf plot 展示。先读 key，确定 stem 与 leaf 组合后的数值及小数位置；例如同一串数字，单位或 key 不同，就会代表不同的饮水量。

这种图保留每个原始值。还原数值后，按顺序找到中间位置得到 median，再检查两端的极值。图中的 stem 只是编码的一部分，不能直接把它当作原测量值。
