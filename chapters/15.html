RCBD, random effects & Latin squares

温室光照梯度，怎样避免被误认为品种差异？

分析无法修复完全 confounded 的设计；blocking 在收集数据前创造可比较的条件。

每个 block 内都有所有 treatments

Randomized Complete Block Design (RCBD) 把类似 EUs 组成 block，每个 block 包含每种 treatment，block 内 random assignment。Course greenhouse example：3 varieties、5 light-gradient blocks，N=15。Blocks 沿 nuisance 梯度的相近区域划分，而 treatment 在各 block 都出现，避免处理只落在某一光照区域。

Randomization 是分配规则，不是把结果排序。Blocking 减少已知 nuisance variation 对 error 的贡献，提高 treatment comparisons 的 precision。它只控制一种 block source，block 内仍需近似 homogeneity；若 block 差异很小，估计 block effects 消耗 df 而未减少足够 MSE，power 可能下降。

Yᵢⱼ=μ+τᵢ+βⱼ+εᵢⱼ

τ 为 treatment，β 为 block。每 treatment×block 一个 EU 时，additive model 无法独立估计 treatment×block interaction；这是假设，需要科学依据。

分解 treatment、block 与 error

SStrt=bΣᵢ(ȳᵢ.−ȳ..)²
SSblock=tΣⱼ(ȳ.ⱼ−ȳ..)²
SSE=ΣᵢΣⱼ(Yᵢⱼ−ȳᵢ.−ȳ.ⱼ+ȳ..)²

Complete balanced additive RCBD 下 SST=SStrt+SSblock+SSE。df treatment=t−1，block=b−1，error=(t−1)(b−1)，total=tb−1。Fixed-effects treatment test F=MStrt/MSE。

Course greenhouse t=3、b=5，所以 error df=8。Ignoring blocks 的 CRD error df=12，但 residual error 会混入 block variation；不能只因为 df 更大就选 CRD。Course insecticide example 同时比较 treatment F 和 relative efficiency，阐明 blocking 的价值取决于 nuisance 是否真的造成 variation。

Relative efficiency 要同时考虑 residual reduction 与 df

把同一 complete block data 当 CRD 时，residual SS=SSblock+SSE，df=b(t−1)。课程使用

RE(RCBD,CRD) = MSE_CRD / MSE_RCBD
= [(b−1)MSblock + (b−1)(t−1)MSE_RCBD] / [b(t−1)MSE_RCBD]

这是比较 precision 的 residual-variance ratio（在指定比较和教材定义下），不是 actual power 的精确倍数；不同版本可加 small-sample df adjustments。RE>1 表示 RCBD 更有效率，RE<1 表示 blocking 在这一评价上未获益。仍须尊重实际 randomization structure，不能单凭观察到 RE 决定抹掉设计。

在 complete RCBD，treatment means 每个含相同 blocks，任意 treatment difference 中 block effects 抵消。若某 cell missing，各 treatment 平均的 block 权重不同，confounding 重新进入；需要 model-based adjusted comparisons，而非简单 raw means。

Fixed 与 random 的区别是推断目标

Fixed effect 关注指定 levels 的 mean differences；Random effect 将 levels 看作从更大 population 抽出的样本，关注 variance component 并向该 population 推断。不是“处理随机分配就叫 random effect”；fixed treatments 也应 randomize。

random blocks：βⱼ ~ Normal(0,σᵦ²)，εᵢⱼ ~ Normal(0,σₑ²)
same-block Cov(Yᵢⱼ,Yᵢ′ⱼ)=σᵦ²

指定 greenhouse positions 可以 fixed；若 blocks 代表目标 environmental population 的 random sample，可以 random。Balanced additive fixed-treatments/random-block RCBD 中 E(MSE)=σₑ²，E(MSblock)=σₑ²+tσᵦ²；method-of-moments estimate σᵦ²=(MSblock−MSE)/t，可能为负，约束估计需说明。

Complete balanced设计中 treatment comparison 抵消 shared block contribution，fixed treatment test 仍以 MSE 为 denominator；不能将这个结果任意扩展到所有 mixed/factorial models。Expected mean squares 与 design 决定其他 tests 的 denominator，mixed-model software 估计 covariance 及 df。

proc mixed data=d;
 class treatment block;
 model y=treatment;
 random block;
 lsmeans treatment / diff adjust=tukey;
run;

Factorial treatments 可以放进 RCBD

Yᵢⱼₖ=μ+Aᵢ+Bⱼ+ABᵢⱼ+Blockₖ+εᵢⱼₖ

每个 block 包含 ab combinations。每 cell 在 b₀ blocks 各一个 EU 时 N=ab b₀；df block=b₀−1、A=a−1、B=b−1、AB=(a−1)(b−1)、error=(ab−1)(b₀−1)。Course flour×oven-temperature×day example 将 day 用作 block，flour 与 temperature 是 treatment factors。

3×3 combinations、3 days：N=27，block df=2，treatment components 2+2+4=8，error=16。Residual diagnostics 及 follow-up comparisons 依然必要；blocking 不保证 normality 或 equal variance。

Latin square 控制两个 nuisance factors

一个 t×t Latin square 中 t treatments 每 row、每 column 各出现一次，两个 blocking factors 的 levels 数都为 t。随机化应在允许的 square structure 下执行，例如合法 row、column 和 treatment permutations；不是每个 cell 独立随机填字母。

Yᵢⱼₖ=μ+Treatmentₖ+Rowᵢ+Columnⱼ+εᵢⱼₖ
df：treatment=t−1，row=t−1，column=t−1
error=(t−1)(t−2)，total=t²−1

每 cell 一个观测，assumption 是 additive effects，没有需要单独估计的 treatment×row、treatment×column 或 row×column interaction。t 小时 error df 很少。Missing observations 破坏 orthogonality，需合适 model analysis。

Course spreadsheet example：4 software treatments、4 secretaries、4 problem types，N=16。每人每类问题只用一个 software，software 每 row/column 一次。df 三个 factors 各 3，error 6；SST=SStrt+SSrow+SScol+SSE。软件 mean 的 adjusted comparisons 解释为控制两种 nuisance 后的表现，不等于适用于任意人员或任务。

在测量前检查设计是否能回答问题

练习：所有 V1 放强光区，所有 V2 放弱光区，测量 1000 株能分离品种与光照吗？

不能。两因素完全 confounded，更多重复提高了混合差异的 precision，却没有识别单独 variety effect。需要在相同光照区域中都包含 varieties 或其他可识别设计。

练习：3×3 Latin square 有多少 error df？

(3−1)(3−2)=2。9 个 observations 中，baseline 与三个 factors 共消耗 1+2+2+2=7 个 model parameters，只剩 2。

Greenhouse 与 insecticides

Greenhouse 15EUs被分成5blocks，每block3varieties；RCBD error df8，忽略block的CRD error df12。利用 reduction in SSE 与df来比较MSE和efficiency；missing EU 会使 treatment 的 block-weight composition 不同。Insecticide × bean variety 案例同样检验 treatment，并单独解释 block variation。

Fixed / random block source

固定block推断只针对这些levels；random block model εij与Bj独立，Var(B)=σb²，E(MSblock)=σe²+tσb²，E(MSE)=σe²。Moment estimate (MSblock−MSE)/t 可能为负；variance不能为负，现代 mixed-model估计需对应 constraints。Treatment test 的 denominator 依据 expected MS 推导。

Bread factorial within days

Flour3levels×temperature3levels，3days作为blocks，N27；flourdf2、temperaturedf2、interactiondf4、daydf2、error df16。Blocked design 与factorial treatment structure同时存在；不要把 day 当一个感兴趣 treatment factor。

Secretaries × task × spreadsheet

四 spreadsheet treatments 在4secretaries×4task rows/columns各出现一次；N16，treatment/row/column各df3，error df6。设计假设不包含重要 treatment×row / treatment×column interactions；它们无法由每格一个obs独立估计。
