第一次学：先分清四件事

统计推断的起点是一项可以重复的研究。Population（总体）是你想谈论的对象集合；sample（样本）是实际看到的一部分；parameter（参数）描述总体，例如未知的 μ；statistic（统计量）由样本算出，例如 ȳ。把 ȳ 算得很精确，并不意味着 μ 已经被观察到了。

一块田分配一种肥料，在田中测量十株植物：若肥料分配给整块田，田才是 experimental unit。十株是 subsamples，不能直接算十个独立 treatment replicates。独立性来自研究设计，不能靠一个正态性检验补救。

  1. 画图与描述。变量是什么、单位是什么、一个数据点对应谁？
  2. 明确参数。要比较 mean、median、variance，还是解释连续关系？
  3. 写模型与条件。独立？配对？几个因素？有没有 blocks？
  4. 计算与解释。估计值 + uncertainty + evidence + 适用范围。

把科学记数法读回概率

1e-6 表示 10−6=0.00000110^{-6}=0.00000110−6=0.000001，2.5e-4 表示 0.00025。小数位数有限时，很小的正概率可能显示为 0.000；这只是显示精度，不能据此写“概率为 0”。接近 1 的概率也可能显示为 1，读出 1 − 1e-6 则能保留小的补事件概率。

例如独立的 60 次 Bernoulli trials，每次成功概率为 0.01，全部成功的概率是 0.0160=10−1200.01^{60}=10^{-120}0.0160=10−120，非常小但仍大于 0。在二项分布实验中核对。P-value 的科学记数法同样如此；它不是 H₀ 为真的概率，也不衡量 effect size。

总体、样本与模型：相似字母不等于同一个量

μ（mu） / σ（sigma） / ρ（rho）通常表示未知 population mean / SD / correlation；ȳ / s / r是样本算出的对应统计量。单样本中的 n 是观测数；paired analysis 中 n 是完整 pair 数；多个组时 N 常表示所有组总数。先认清独立单位，再数 n。

α（alpha）在检验中是显著性水平；ANOVA 的 αᵢ 却可能表示第 i 个 treatment effect。β（beta）可表示 Type II error，回归中的 β₀、β₁ 则是总体截距和斜率。ν（nu）常表示 degrees of freedom。符号要连同上下文一起读，不能仅凭字母替换含义。

例如 qt(0.975, df=10)≈2.228；pt(2.228, df=10)≈0.975。R 的 q 函数从 probability 找 cutoff，p 函数从 cutoff 找 cumulative probability。双侧 α=0.05 把尾概率分成左右各 0.025；单侧则不能自动除以 2。在分布工作台中移动 cutoff，看阴影面积。

自检：为什么 Σ(Yᵢ−ȳ)=0，却仍有 variance？

[2,4,6] 的均值是 4，偏差是 [−2,0,2]。原偏差求和为 0；平方偏差求和为 4+0+4=8。s²=8/(3−1)=4。这是先对每个偏差平方，再求和；若误算成 [Σ(Yᵢ−ȳ)]²，就会永远得到 0。回到方差的完整计算。

先写参数，再决定保留哪些信息

“非正态”只描述一个模型条件，不能替你选择科学问题。预计总工时需要 arithmetic mean；典型个体位置可能关心 median；预先匹配对象的改变可以问 median(D)；秩位置比较则使用相对排序。即使面对同一份资料，这些目标也不等价。先判断总工时的目标，再用偏态配对差题核对为什么不能直接套 signed-rank。

配对问题先固定 D=A−B，所问 median(D) 一般不等于 median(A)−median(B)。Sign 不使用变化幅度；signed-rank 使用绝对差的排名，并增加对称性条件。对于两个或多个独立组，只知道各组 median 相等，并不保证原始标签可交换；不同形状下的 median 比较需要专门匹配目标的方法，不能无条件以 rank-sum 或 Kruskal–Wallis 代替。

若数据含 blocks、同一对象有三个及以上测量，或问题涉及多个因素，须保留其相关性与因素结构。普通独立组 rank-sum / Kruskal–Wallis 不会自动处理这些设计；给每个 cell 排名，也不能自动获得正确的交互作用检验。在方法向导中改变目标与设计，查看相应入口或需要补充的条件。

读输出顺序：先看每组样本量与描述，再看 model 的 Df、Sum Sq、Mean Sq、F value、Pr(>F)。本例 group 的 df=2，residual df=12，F≈24.667；Tukey 的 diff / lwr / upr / p adj 回答具体成对差异，并控制该比较 family 的错误率；Tukey 不要求先通过 omnibus ANOVA。诊断图支持判断，不能证明模型正确。

读取自己的 CSV 可以用 d <- read.csv(file.choose())，然后 names(d)、str(d) 核查列名、类型、缺失值。不要照抄示例列名，也不要未经检查就删除缺失值或异常点。 如果处理组用1、2、3编码而含义是类别，导入后要明确转为 d$group <- factor(d$group)，再用 levels(d$group) 与 table(d$group) 核对。否则 aov(y ~ group, data=d) 会把数字当连续变量拟合线性趋势，检验的就不是三组均值相等；不要把剂量等真正连续变量一律转成 factor。

结论怎么写

完整结论至少说明目标 population、parameter、方向、估计与区间、检验与证据。以一个假设例子：独立随机样本比较肥料 A 与 B 的平均产量，Welch 估计 A−B=2.4 kg，95% CI [0.8,4.0] kg，P=0.006。可写“在设计与模型条件合理的前提下，有证据支持该目标总体中 A 的平均产量高于 B；估计差异为 2.4 kg，95% CI 为 [0.8,4.0] kg。”

若 P=0.23，应写“未获得充分证据支持差异”，不能写“证明相同”。要声称足够接近，需要预设具有实际意义的等效界值与专门的 equivalence analysis；这超出本站基本检验。

容易写错改成什么
P 是 H₀ 为真的概率P 是在 H₀ 与模型条件下，统计量达到所观测的或更极端程度的概率。
P>0.05 证明没有效应证据不足；区间宽度也许仍允许有实际意义的效应。
95% CI 包含 95% 个体CI 估计 parameter；individual coverage 需要另一种区间。
Shapiro 不显著，数据就是 normal未发现充分反对证据；结合 Q–Q、样本量、异常值与设计判断。
ANOVA 显著，每一组都不同至少一个 mean 不同；具体差异需 follow-up comparisons。
异常点妨碍显著性，可以删除先查录入与测量依据。真实极端值应保留，并考虑预先合理的稳健性分析。
相关系数大，X 导致 Y相关描述 association；causal claim 还依赖研究设计与混杂处理。

中英术语与符号

Population / sample · 总体 / 样本
总体是推断目标，样本是已收集的观测。由方便样本推广到整个总体需要额外理由。
Parameter / statistic · 参数 / 统计量
μ、σ² 是总体特征；ȳ、s² 从数据计算，会随样本变化。
Experimental unit · 实验单位
独立接受 treatment 分配的单位。Subsample 数不等于独立重复数。
Random sampling / random assignment · 随机抽样 / 随机分配
前者帮助总体代表性，后者帮助处理组的可比性。它们解决不同问题。
SD / SE · 标准差 / 标准误
SD 描述观测的分散；SE 描述估计量的抽样不确定性。样本均值的估计 SE=s/√n。
Sampling distribution · 抽样分布
在同一抽样方案下重复抽样，统计量会得到的分布；不是这一份 raw data 的 histogram。
Null / alternative · H₀ / Hₐ
H₀ 给出计算参考分布的假设；Hₐ 决定哪些结果更极端以及检验方向。
Significance level · α
预先选择的 Type I error 控制水平；不是观察到数据后才决定的 P-value。
Type I / Type II / power · α / β / 1−β
真 H₀ 被拒绝 / 特定 alternative 下未拒绝 / 特定 alternative 下拒绝。β 与 power 必须指定真实效应。
Degrees of freedom · df / ν
估计约束后剩下的独立信息量。单样本 variance 用 n−1；Welch 的近似 df 可以不是整数。
Confidence interval · CI
由重复抽样覆盖率校准的参数区间。置信水平提高通常会让区间变宽。
Residual · eᵢ
观测值减 fitted value。Error εᵢ 是模型中的未知误差；residual 是估计后可计算的量。
Sum of squares / mean square · SS / MS
偏差平方和 / 除以相应 df。经典 ANOVA 用两个 MS 的比进行检验。
Contrast · 对比
系数之和为零的 means 线性组合。必须先说明它对应哪一个科学比较。
Family-wise error rate · FWER
一个事先定义的比较 family 中至少一次 Type I error 的概率。
Interaction / simple effect · 交互作用 / 简单效应
一个因素的效应随另一个因素水平改变 / 固定另一因素时的效应。Interaction 不要求线条交叉。
Block · 区组
按 nuisance variation 组织的相似实验单位集合；在 block 内随机分配 treatments。
LSMeans / estimated marginal means · 调整均值
依赖 fitted model 和指定 weighting 的均值；unbalanced data 中不一定等于 raw mean。
Fixed / random effect · 固定 / 随机效应
针对特定水平的差异 / 用随机水平描述更大总体的变异。选择取决于推断目标，不能只由因素名称决定。
Prediction interval · PI
新个体 response 的区间，包含 mean estimation uncertainty 与新个体自身 variability。
