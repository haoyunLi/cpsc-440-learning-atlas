每个 block 内都有所有 treatments

本节导读 · 1 个主题
  1. 先确认抽签范围：相同的15盆，可能来自不同设计

温室中靠窗与远离窗的位置可能光照不同。如果一种品种全放靠窗，另一种全放里面，测到的差就混合了品种与光照。Blocking（区组化） 先把相近环境的实验单位组成 block，再在每个 block 内比较 treatments。

Randomized Complete Block Design（RCBD，随机完全区组设计） 中，“complete”表示每个 block 都含所有 treatments，“randomized”表示在 block 内随机分配。课程温室例有 3 varieties 和 5 light-gradient blocks，每个 block 各放一个品种，共 15 个实验单位。

  1. 先识别已知 nuisance，例如光照、实验日期或地块背景。
  2. 把内部较相似的单位组成 blocks，让光照差异主要出现在 blocks 之间。
  3. 在每个 block 内随机分配所有 treatments，使每种处理都经历同一组环境。
  4. 分析时把 block term 留在模型中，避免将可解释的环境差异全部算成 error。
Yij=μ+τi+βj+ϵijY_{ij}=\mu+\tau_i+\beta_j+\epsilon_{ij}Yij​=μ+τi​+βj​+ϵij​

一次测量同时受肥料、田块共同环境和剩余波动影响。

τᵢ 是 treatment 部分，βⱼ 是 block 部分。每 treatment×block 只有一个观测时，无法再独立估计 treatment×block interaction；additivity 是需要科学依据的假设。

Blocking 的价值来自减少与研究目标无关的 variation。如果 blocks 实际几乎没差，估计它们仍消耗 df，可能未提高精度。下方实验会保留 treatment balance，同时改变环境梯度，显示这个权衡。

先确认抽签范围：相同的15盆，可能来自不同设计

原创设计：比较A、B、C三种处理对植株高度（cm）的影响。有15盆分别接受处理的植物；每盆只记录一次响应，并假定不存在盆间干扰。先把位置按光照分成5个带，每带3盆。以下两种方案都预先规定每处理共5盆，但随机化规则不同：

实验单位相同，允许的处理分配不同
方案实验前怎样分配每个光照带保证什么
RCBD每个block内把A、B、C三个标签随机排到三盆；各block分别抽签。A、B、C各出现一次。
CRD，固定每组5盆把5个A、5个B、5个C标签在全部15盆之间随机排列，不按光照带限制。不保证三处理各一次；同一处理可占一个带的多盆。

Experimental unit 是单盆。 处理分别施加给每盆；物理上的block是用来限制随机化、控制背景的分组，并没有整体只接受一种处理。不能把“有5个blocks”读成“只有5个实验单位”。固定各处理数量也意味着标签分配之间有约束，不能把每盆的抽签当作互相独立的三选一。

在上述允许的分配中等概率抽签，RCBD有(3!)⁵=7776种标签排列；CRD有15!/(5!5!5!)=756756种。后者也包含那些每个光照带碰巧各出现A、B、C一次的排列，因此它可能偶然平衡，却仍然是CRD。设计由实验前实际执行的分配机制决定，不能只看实验结束后的字母表反推。

先判断：RCBD数据只拟合 y ~ treatment，会变成CRD吗？

不会。它是在已按RCBD收集的数据上省略block term重新拟合。SSE、error df、MSE可能改变，但历史上的抽签规则没有改变。反过来，给CRD数据的模型加上预先记录的block变量，也不能把原随机化过程改写成RCBD。模型是否适合还要按实际设计、研究目标和误差条件判断。

因此，本章对同一份数据“保留block”与“忽略block”的MSE比较，回答的是模型怎样分解variation；要演示两种实验设计，应真的比较block内抽签和全场抽签。一次抽签得到平衡布局也不能证明误差独立、正态、共同variance或treatment与block加性。

下面的R只核对上述分配方案数。在指定的等概率CRD下，碰巧所有blocks完整平衡的概率约为1.02754%；这是随机化布局的概率，不是处理效应检验的P-value，也不替代真实实验的分配记录。

# Count assignments for 15 distinct pots and fixed treatment totals of 5 each.
# This code counts the stated randomization spaces; it does not randomize an experiment.
treatments <- c("A","B","C")
blocks <- 5
pots_per_block <- 3
N <- blocks*pots_per_block
# Enumerate the legal label orders for one complete block.
orders <- expand.grid(position1=treatments,position2=treatments,
                      position3=treatments,stringsAsFactors=FALSE)
legal <- apply(orders,1,function(z) length(unique(z))==pots_per_block)
orders <- orders[legal,,drop=FALSE]
print(orders,row.names=FALSE)
rcbd_count <- nrow(orders)^blocks
# Choose the five A pots, then the five B pots; the remaining pots receive C.
crd_count <- choose(N,5)*choose(N-5,5)
crd_factorial_check <- factorial(N)/factorial(5)^3
# Under the specified uniform CRD, every complete-block layout is also possible.
chance_complete_blocks <- rcbd_count/crd_count
print(c(RCBD_assignments=rcbd_count,CRD_assignments=crd_count,
        CRD_probability_of_one_each_per_block=chance_complete_blocks))
stopifnot(nrow(orders)==6,rcbd_count==7776,crd_count==756756,
          abs(crd_count-crd_factorial_check)<1e-8,
          chance_complete_blocks>0,chance_complete_blocks<1)

分解 treatment、block 与 error

RCBD 的总变化分成三份：treatment 中心差、block 中心差，以及两者都解释不了的 residual。完整平衡设计让每种 treatment 包含同样的 blocks，因此这些部分可以分开。

Relative efficiency 要同时考虑 residual reduction 与 df

本节导读 · 3 个主题

  2. 再使用课程的重复数规划公式
  3. 核对课件温室例：6.05从哪里来？

把光照不同的田块分开记录，常能让剩下的波动变小；但要估每片田的环境差异，也要花自由度。所以要问两个具体问题：同一份数据里，计入田块之后，误差尺度小了多少？如果下一次不分田块，得多做多少重复才能达到类似精度？两问用的是不同的计算。

RE_plan 不是 actual power 的精确倍数，也不自动保证未来实验具有相同方差。它是沿用指定方差估计、比较 SE 的课程规划指标；正式 power 规划还需效应大小、α、误差分布、自由度与设计条件。这一精度比较也不是 random-block 模型下单个环境总体 mean 的完整方差：后者包含 block 抽样变异，见单个mean与同blocks差值的SE。

核对课件温室例：6.05从哪里来？

课程给 t=3、b=5、MSblock=57.375、MSE_RCBD=3.075。重拟合的CRD输出在notes第11页，MSE_refit=21.175，所以R_refit=21.175/3.075≈6.886179。第12页的规划公式则给RE_plan≈6.045296，保留两位小数即课件的6.05；PPT第18页用5个blocks得到约30.25个重复/处理，取整数应至少31个。两页计算使用不同的CRD误差估计，不能从21.175/3.075直接得到6.05。

Notes第12页末句的“4×6.05=24.4”另有算术笔误，实际为24.2；本温室例应以PPT明确的5个blocks为准。复算应保留中间精度，再在最后对重复数向上取整。

# Original complete RCBD: three fixed treatments in four complete blocks.
d <- data.frame(treatment=factor(rep(c("A","B","C"),each=4)),
                block=factor(rep(1:4,3)),
                y=c(18,18,20,24,19,23,25,25,23,25,27,29))
with(d,table(treatment,block))
fit_block <- aov(y ~ treatment + block,data=d)
fit_ignore <- aov(y ~ treatment,data=d)
tab <- summary(fit_block)[[1]]
print(tab)
print(summary(fit_ignore))
t <- nlevels(d$treatment)
b <- nlevels(d$block)
error_df <- (t-1)*(b-1)
ignore_df <- t*(b-1)
mse <- deviance(fit_block)/error_df
ms_block <- tab["block","Mean Sq"]
ss_block <- tab["block","Sum Sq"]
ss_error <- deviance(fit_block)
# This ratio describes re-fitting the same observed data without a block term.
mse_refit <- (ss_block+ss_error)/ignore_df
ratio_refit <- mse_refit/mse
# The course planning formula estimates the CRD variance for replication planning.
mse_plan <- ((b-1)*ms_block+b*(t-1)*mse)/(b*t-1)
re_plan <- mse_plan/mse
continuous_reps <- b*re_plan
required_reps <- ceiling(continuous_reps)
print(c(RCBD_df=error_df,refit_CRD_df=ignore_df,MSE_RCBD=mse,
        MSE_refit=mse_refit,refit_ratio=ratio_refit,
        MSE_planning=mse_plan,planning_RE=re_plan,
        continuous_reps=continuous_reps,reps_per_treatment=required_reps))
# Compare SE proxies for the same treatment difference, with equal replication.

Fixed 与 random 的区别是推断目标

Fixed effect 与 random effect 的区别在推断目标。若只关心这几个指定 levels 的均值差，可视为 fixed；若把这些 levels 看作从更大环境总体中抽出的样本，关注它们的 variance component，则使用 random-effect 结构。

“随机分配 treatments”与“random effects”不是同一概念。Fixed treatments 也应随机分配；random block 描述的是 block levels 如何代表目标总体以及它们的 covariance。

同一田块的单位共享一份环境波动，所以它们可能相关。

共享 βⱼ 的观测会一起偏高或偏低，所以同 block 相关。Balanced fixed-treatments/random-block additive RCBD 中：

E(MSE)=σe2,E(MSblock)=σe2+tσb2,σb2^=MSblock−MSEtE(\mathrm{MSE})=\sigma_e^2,\quad E(\mathrm{MS}_{\mathrm{block}})=\sigma_e^2+t\sigma_b^2,\qquad\widehat{\sigma_b^2}=\frac{\mathrm{MS}_{\mathrm{block}}-\mathrm{MSE}}tE(MSE)=σe2​,E(MSblock​)=σe2​+tσb2​,σb2​​=tMSblock​−MSE​

推导顺序是先写 expected mean squares，再相减以分离 block variance。抽样中 MSblock 可能比 MSE 小，moment estimate 于是为负；这不是负的真实 variance，而是该估计方法与样本波动的结果，约束估计需明确处理。

完整平衡设计的 treatment comparison 会抵消共享 block 部分，所以这里 fixed treatment test 仍用 MSE。不要把这个 denominator 规则扩展到所有 mixed/factorial designs；不同随机项可能改变 expected MS、covariance 与 df。

温室与杀虫剂：从 block 内形成比较

Greenhouse 的 15 个 experimental units 分成 5 个 blocks，每 block 包含 3 个 varieties。RCBD 的 error df=(3−1)(5−1)=8；对同一份 RCBD 数据省略 block 重拟合，error df=15−3=12；实验实施时的随机化方案并没有改变。Blocking 同时减少部分 SSE 并消耗 df，因此效率要通过 MSE 比较。

如果一个单位缺失，各 treatment 所经历的 block 构成可能不再一样，共同背景不能像完整平衡时那样直接抵消。Insecticide×bean variety 案例同样把 treatment 问题与 block variation 分开解释；研究因素可以是 factorial，block 仍承担控制背景差异的作用。

Fixed 与 random blocks：推断到哪里

Fixed block 模型的推断针对选定的这些 levels；random block 模型把它们看作环境总体的抽样。若 Bj 与 εij 独立，Var(Bj)=σb²，则 E(MSblock)=σe²+tσb²，而 E(MSE)=σe²。

两式相减得到 moment estimate σ̂b²=(MSblock−MSE)/t。这个估计可能为负，尽管真正的 variance 不能为负；采用现代 mixed model 时要说明估计方法与约束。Treatment test 的 denominator 也应由对应模型的 expected mean squares 推导。

面包实验：factorial treatments 放进 days

Flour 3 个 levels 与 temperature 3 个 levels 形成 9 个 treatment combinations，在 3 个 days 中各完成一次，N=27。Flour、temperature、interaction、day 的 df 为 2、2、4、2；error df=(9−1)(3−1)=16。

先检查每个 day 都包含全部 9 个组合，再按模型分解。Flour 与 temperature 是研究 factors，day 是 nuisance block；factorial structure 与 blocking 可以同时存在，分别回答处理关系与背景控制问题。

Random block：单个 treatment mean 的 SE 与均值差的 SE 为什么不同？

将 block 视为环境总体的随机抽样后，单个 treatment mean 包含“这次恰好抽到哪些环境”的不确定性。但是，如果两个 treatments 在同一组完整 blocks 中各出现一次，共享的环境项会在差中抵消。把两个均值的 SE 当作互相独立再平方相加，就会漏掉这种 covariance。

原创完整 RCBD：A、B、C 是固定 treatments，从环境总体抽取五个独立 blocks，每个 block 内随机分配三个实验单位。以下是完整观测；假定 additive random-block model，且 blocks 与实验误差相互独立。

  2. 用完整平衡 ANOVA 估计方差分量。 本例 SSblock=120、dfblock=4，MSblock=30；SSE=10、error df=(3−1)(5−1)=8，MSE=1.25。由 E(MSblock)=σe²+3σB²，得到 ANOVA moment estimate σ̂B²=(30−1.25)/3=9.58333，σ̂e²=1.25。
  3. 计算单个环境总体 treatment mean 的 SE。 SE(Ȳi.)≈√[(9.58333+1.25)/5]=1.47196。若只针对这五个 fixed blocks 的平均，去掉环境抽样项后对应 SE 为 √(1.25/5)=.5；这两种 SE 回答的推断范围不同。
  4. 再算同 blocks 内的 treatment difference。 Cov(ȲA.,ȲB.)≈9.58333/5=1.91667。差的估计方差为 2×1.47196²−2×1.91667=.5，所以 SE(B−A)=√.5≈.707107。它不是 √(1.47196²+1.47196²)≈2.08167。

为什么本节不用两个独立均值的公式？ 相同 blocks 中的环境变动同时影响 A 与 B；我们比较的是它们在相同环境构成下的差。若两个 treatments 在完全不同的独立 blocks 中观察，环境项不再这样抵消，需要重新推导差的方差。缺失 treatment×block cell 也会使简单的同权抵消与这些公式失效。

SE 不等于已经获得精确 CI。 上面单个 treatment mean 的 SE 是代入两个 ANOVA variance-component estimates 得到的；它不能自动配上 residual df=8 构造普通精确 t 区间。因为单个 mean 的 uncertainty 同时含 block 与 error 两个来源，interval 还需要与方差估计方法匹配的自由度或其他推断方法。本节只给共享 blocks 的 treatment contrast 使用其对应的精确误差 t 参考；不把 aov 的固定因子输出冒充 REML 拟合。

Moment estimate 可能在别的数据中为负，尽管真实 variance 非负；这里恰好为正，不能据此把这个限制忘掉。采用 constrained mixed-model estimation 时应说明方法，不能默默改成 0 后还沿用未经核对的推断。若同时研究多个 treatment contrasts，还需像上一章一样定义 family 与校正；本例仅检验事先选定的 B−A。完整随机区组只有每格一个单位，也仍依赖 treatment×block additivity。

若忽略blocks，会改变什么？

因为设计完整平衡，忽略block不改变本例的cell means和A/B/AB平方和，但会把block SS并入error：SSEignored=192+12=204，error df=18−6=12，MSEignored=17。Interaction变为F=(27/2)/17≈.794118，P≈.47436。更多error df并没有补偿丢进残差的环境差异。

保留block的理由来自实验设计和模型，不是因为它让P更小。若blocks几乎没有解释力，估计它们仍消耗df；也不能依据这份构造例的显著结果证明blocking对任意实验都有效。

缺失一个区组单元：raw difference与可估计的调整比较

本节导读 · 4 个主题
  1. 设计仍然连通，但误差自由度少了一个
  2. Raw difference和同一reference grid上的adjusted contrast
  3. 用同一个模型的covariance完成SE、t和CI
  4. 不用矩阵黑箱，也能核对5/8从何而来

完整区组的raw treatment means具有相同的block构成，所以可以直接相减。丢失一个观测后，这个自动抵消可能失效；但“raw means混入block差异”与“模型中的处理比较不可估计”不是同一句话。本节把本站已有原创区组例删去一个观测，完整计算二者的区别。

原实验为三个treatments、四个blocks，每个treatment×block一个观测。现在treatment2在block4的观测缺失，分析只使用下面11个已观察值。这里明确采用fixed-block additive model，目标是调整这四个指定blocks后的处理差；假定独立、正态、共同variance误差。

缺一格后，先看实际设计矩阵还能估计哪些参数，再计算自由度。

这里的design matrix X每行代表一个已观察单位，六列依次为[1, I(treatment=2), I(treatment=3), I(block=2), I(block=3), I(block=4)]；I条件成立时为1，否则为0。例如treatment2/block3对应[1,1,0,0,1,0]。矩阵rank是线性独立列的数量，与Wilcoxon给观测排序的rank含义不同。参考组留在intercept里，所以不另外添加treatment1和block1的指示列。

虽然少了treatment2/block4，所有treatments仍通过共同blocks连接；在这一个加性模型下，六个参考编码系数仍可唯一估计。拟合得到b̂=[8,6,0,2,4,6]ᵀ，SSE=6，MSE=6/5=1.2。原完整设计的(t−1)(b−1)=6不能原封不动用于缺失后的数据。

“可估计”取决于设计和所指定的模型。这里利用没有treatment×block interaction的假设，把已观察的处理差跨blocks共用；若允许每个cell有任意独立均值，缺失cell就没有观测直接识别。换coding或把缺失值填0都不会增加信息；更多缺失还可能使设计不连通，需要重新检查rank与具体contrast。

Raw difference和同一reference grid上的adjusted contrast

  1. 先算raw difference。 Treatment2只经历前三个blocks，raw mean=16；treatment1经历四个blocks，raw mean=11，差为5。两者的背景构成不相同。
  2. 统一平均目标。 对每个treatment都在相同四个blocks上预测并各赋1/4权重。加性拟合给出的adjusted means为11、17、11，因此treatment2−1=6。
  3. 解释那一个单位的差别。 拟合block shifts相对block1为[0,2,4,6]。前三个block的平均shift是2，四个block是3，所以raw difference中额外混入2−3=−1；得到6−1=5。
  4. 注意预测与观测的区别。 缺失cell的fitted mean为20；它是加性模型作出的预测，不是找回了原观测。把20补回去当一个真实样本会虚增信息，并错误恢复自由度。

缺失机制仍然重要。 Rank足够只说明参数在指定模型中可以识别，不保证缺失后的估计没有选择偏差。若较低或较高的未观测响应更容易丢失，剩余数据可能不再满足所假设的误差结构；需要记录缺失原因并考虑相应模型与敏感性分析。不能因为软件成功返回一个数，就宣称缺失问题已解决。

本节固定四个blocks进行OLS调整；若推断目标改为随机环境总体，应声明random-block covariance模型并使用匹配的估计与SE。在失衡设计中，不能将这里的OLS输出自动冒充mixed-model推断。只有每格一个观测，也仍无法独立检验完整的treatment×block interaction。
