Regression & correlation

温度每变一度，response 怎样变？能预测下一次观测吗？

ANOVA 比较分类组；regression 把连续 explanatory variable 写进同一套 linear-model 思路。

Simple linear regression 描述 conditional mean

Yᵢ=β₀+β₁xᵢ+εᵢ
E(Y|x)=β₀+β₁x，Var(Y|x)=σₑ²

Response variable Y 随 explanatory variable x 改变。β₀ 是 x=0 时的 model mean；β₁ 是 x 增 1 unit 时 mean Y 的变化量。Intercept 若 x=0 不在数据或科学范围中，可能只承担数学定位作用。

假设 mean relationship linear、errors independent、mean zero、constant variance；normal errors 用于 exact t/F/interval inference，least-squares fitting 本身无需 normality。每个 x 上有 Y 的 conditional distribution，不是所有观测必须落在线上。

Course pharmacy profit 与 absence/work-experience examples 展示正负 slopes。Observational association 不自动证明 causation；randomization、confounding 与 design 仍决定因果解释。

Least squares 最小化 vertical residual squares

Sxx=Σ(xᵢ−x̄)²，Sxy=Σ(xᵢ−x̄)(Yᵢ−ȳ)
b₁=Sxy/Sxx，b₀=ȳ−b₁x̄
ŷᵢ=b₀+b₁xᵢ，eᵢ=Yᵢ−ŷᵢ

选择 b₀、b₁ 使 SSE=Σeᵢ² 最小。Residual 是 vertical difference，不是点到直线的最短距离。要求 x 有 variation，Sxx>0。With intercept，Σe=0，fitted line 穿过 (x̄,ȳ)。

Course road resurfacing data x=[1,3,4,5,7]，Y=[6,14,10,14,26]：x̄=4、ȳ=14、Sxx=20、Sxy=60，所以 b₁=3、b₀=2。Predictions=[5,11,14,17,23]，residuals=[1,3,−4,−3,3]，SSE=44。Interactive 允许调整最后一点，直接观察 outlier / leverage 怎样影响 line。

Extreme x 可有 high leverage；large residual 是 outlier。Influence 同时依赖两者。不要机械删除异常点，先核对测量与研究场景，比较 sensitivity。

Regression 也能分解 SS 并检验 slope

SST=Syy=Σ(Yᵢ−ȳ)²
SSR=Σ(ŷᵢ−ȳ)²=b₁²Sxx　　SSE=SST−SSR
MSE=SSE/(n−2)，F=(SSR/1)/MSE ~ F(1,n−2) under H₀:β₁=0

Road example SST=224、SSR=180、SSE=44、MSE≈14.6667、F≈12.2727、df=(1,3)，P≈.0394。在同一个 SLR model 中 slope two-sided t test 的 t²=F，结论一致。

SE(b₁)=√(MSE/Sxx)
SE(b₀)=√[MSE(1/n+x̄²/Sxx)]
t=(bⱼ−βⱼ,₀)/SE(bⱼ)，df=n−2

CI=bⱼ±t critical×SE。Road slope SE≈.85635，t≈3.50325；估计两个 coefficients 消耗 2 df。β₀、β₁ 的 sampling variance depends on x distribution；更广 x range 可提高 slope precision，但应在科学可比范围中设计。

Mean confidence interval 与 prediction interval 不同

ŷ₀=b₀+b₁x₀
mean CI：ŷ₀ ± t₁₋α/₂,n₋₂ √[MSE(1/n+(x₀−x̄)²/Sxx)]
new individual PI：ŷ₀ ± t₁₋α/₂,n₋₂ √[MSE(1+1/n+(x₀−x̄)²/Sxx)]

CI 为 E(Y|x₀) 的 estimation uncertainty；PI 还包含新个体自己的 error，所以多一个 1，通常更宽。两个区间都在 x̄ 最窄，离 x̄ 越远越宽。Course absence example 对不同 work-experience values 比较两种区间。

Road example x₀=4：ŷ=14，t₀.₉₇₅,₃≈3.18245。Mean CI half-width≈5.4506；PI half-width≈13.3511。这两个范围不能互换。Extrapolation 到未观测范围可能因 mean model 错误失效，数学上计算得出区间不代表科学上可信。

显著 slope 不保证 linear model 适合

Residual vs fitted / x 出现弯曲可能表示 nonlinear mean；funnel 提示 variance pattern；QQ 检查 error normality；独立性依赖 sampling、randomization 与时间/空间结构。

若有 g 个 distinct x levels 且各有 independent replicate measurements，可以将 SSE 拆为 Pure error 与 Lack of fit。

SSPE=ΣⱼΣₖ(Yⱼₖ−ȳⱼ)²，dfPE=n−g
SSLOF=SSE−SSPE，dfLOF=g−p
FLOF=[SSLOF/(g−p)]/[SSPE/(n−g)]

p 是 fitted mean parameters 的数目，SLR p=2，quadratic p=3。Null 是 mean model 在所测 x levels 适合。重复同一数据记录不等于 independent replicates；without replication，不能凭此公式独立估计 pure error。

Course heat-loss vs temperature example：SLR SSLOF≈858.91、dfLOF=2，MSPE≈20.833，F≈20.61，发现不适合；加入 x² 后继续检验与诊断，而不是仅因 R² 升高就宣称 quadratic 正确。

fit <- lm(y ~ x,data=d)
summary(fit); plot(fit)
predict(fit,data.frame(x=4),interval='confidence')
predict(fit,data.frame(x=4),interval='prediction')
anova(fit,lm(y~factor(x),data=d)) # 有重复 x 且条件成立时 LOF
lm(y ~ x + I(x^2),data=d)

Correlation 衡量 linear association，不替代机制

r=Sxy/√(Sxx Syy)，−1≤r≤1
R²=SSR/SST；SLR with intercept 下 R²=r²
H₀:ρ=0，t=r√[(n−2)/(1−r²)]，df=n−2

Pearson correlation unitless，交换 x 与 Y 不变；slope 有单位且交换变量通常改变值。r=0 表示没有 linear association，不表示 independent，也不排除 U-shaped relationship。R² 是此 model 解释 sample variation 的比例，不是预测成功概率。

Road data r≈.89642、R²≈.80357。ρ test 的常用 exact reference 依赖 independent bivariate normal observations；它和 SLR slope test 在这一设置下相同。Perfect |r|=1 时 denominator 为零，对退化情况不能普通代入有限 t。

Estimator 的 sampling distribution 可以有偏

Bias(r)=E(r)−ρ

r 是 population correlation ρ 的 estimator，但 finite samples 下通常有 bias，sampling distribution 也可能 highly nonnormal。Course simulations 比较 ρ=.8、n=3 与 n=50，以及 ρ=0：small n 下 r 分布可贴近边界，estimate 不稳定；n 增大通常减少 bias 和 variation。

ρ=0 的 symmetric setting 可给 E(r)=0，但不能把它推广到所有 ρ。Simulation 验证模型设定的 repeated-sampling behavior，不等于实测科学结果。合理 simulation 要记录 true ρ、n、replicate count 与 seed，并区分 Monte Carlo variability 与 estimator bias。

练习：r=.9，能说 x 造成 Y 增加吗？

不能。可能存在 confounder、reverse causality、selection 或测量结构。Correlation 描述数据关系，因果推断需要可识别的设计和假设。

练习：why is PI wider than mean CI？

Mean CI 只包含估计 conditional mean 的 uncertainty；new observation 还带独立 residual noise，其 variance 多 σₑ²，因此公式里多 1。

Road resurfacing与 influential points

x=[1,3,4,5,7]，Y=[6,14,10,14,26]：ŷ=2+3x，SSE44，MSE44/3，F≈12.273，P≈.03939。改最后点的交互显示 slope、r²、interval为何一起变化。Residual大的点与 high-leverage极端x不是同一概念；Cook distance结合二者影响。

Pharmacy wording需要分开

PPT 将x定义为非brand-name药物比例、Y为profits；notes 将问题写成处方销售volume与从manufacturer直接购买ingredients的比例。二者作为不同业务例子：解释 slope 必须沿用各自x/Y单位，不能把一份数据的结论直接改写成另一个指标的效果。

Absence、parameter tests 与 earnings per share（notes）

Absence随experience下降：b₁的单位是每单位experience对应的absence变化，b₀是x=0的预测值，可能在观察范围外。Notes 另外用executive mean age与前一年 earnings-per-share percentage change进行slope inference，不能用correlation直接声称年龄造成earnings变化。Code中 predict(newdata=data.frame(x=...)) 的column name须与 fitted predictor一致。

Heat loss、pure error 与 bias simulation

Heat loss在4个temperature各3obs，N12、unique x t4：SLR residualdf10、pure-error df8、lack-of-fit df2。比较 linear fit SSE 与同温度 within-group SSE；显著LOF后考虑quadratic并重新diagnose。Correlation simulationρ=.8,n3 的500r平均约.70；n50约.796，有限模拟的mean只是E(r)的estimate，不是解析定理。
