Simple linear regression 描述 conditional mean

前面用 groups 解释差异；现在 x 是连续变量，例如工作经验或道路长度。Simple linear regression（简单线性回归） 描述在指定 x 条件下，Y 的平均值如何变化。

Yᵢ=β₀+β₁xᵢ+εᵢ
E(Y|x)=β₀+β₁x；Var(Y|x)=σₑ²

Response variable Y 是要解释或预测的响应；explanatory variable x 是用于描述关系的变量。β₁ 表示 x 每增加一单位，conditional mean Y 改变多少；β₀ 表示 x=0 时的模型均值。

若 x 是工作年数、Y 是缺勤天数，slope 的单位就是“每增加一年经验，平均缺勤天数改变多少”。若 0 年不在数据范围或科学范围里，intercept 可能只负责给直线定位，不宜作额外实质解释。

直线描述的是 conditional mean，并不要求每个观测都落在线上。模型假设 mean relationship linear，errors 独立、均值为 0、variance 固定；normal errors 用于常见精确 t/F/interval inference，least-squares fitting 本身不需要正态。

课程 pharmacy 与 absence 例分别有不同 x、Y 定义。Observational association 不能直接说成 causation；confounding、selection 和设计条件仍需要另行说明。

Least squares 最小化 vertical residual squares

Least squares（最小二乘） 选择 intercept 与 slope，使所有 vertical residuals 的平方和最小。Residual 是同一个 x 上观察值减预测值，不是点到线的最短斜距离。

Sxx=Σ(xᵢ−x̄)²；Sxy=Σ(xᵢ−x̄)(Yᵢ−ȳ)
b₁=Sxy/Sxx；b₀=ȳ−b₁x̄
ŷᵢ=b₀+b₁xᵢ；eᵢ=Yᵢ−ŷᵢ
  1. 求中心。 课程 road data x=[1,3,4,5,7]、Y=[6,14,10,14,26]，x̄=4、ȳ=14。
  2. 中心化。 x 偏差为 [−3,−1,0,1,3]，Y 偏差为 [−8,0,−4,0,12]。
  3. 求两个和。 Sxx=9+1+0+1+9=20；Sxy=24+0+0+0+36=60。
  4. 求线。 b₁=60/20=3，b₀=14−3×4=2，所以 ŷ=2+3x。
  5. 求 residuals。 Predictions=[5,11,14,17,23]；e=[1,3,−4,−3,3]；SSE=1+9+16+9+9=44。

含 intercept 时，residuals 总和为 0，拟合线经过 (x̄,ȳ)，可用这两个性质核查结果。Sxx 必须大于 0，所有 x 相同就无法识别 slope。

下方实验只改最后一个 Y，观察 fitted line 和 residuals 一起改变。极端 x 带来 high leverage，大 residual 指离线远，influence 则关心一个点对拟合改变多大；三者不能混为一谈。先核对测量与场景，再作 sensitivity comparison，不要机械删点。

Regression 也能分解 SS 并检验 slope

Regression 也可按“解释部分与残余部分”分解平方和。含 intercept 的 SLR 将总 variation 分成 fitted line 解释的 SSR，以及观测到 line 的 SSE。

SST=Syy=Σ(Yᵢ−ȳ)²
SSR=Σ(ŷᵢ−ȳ)²=b₁²Sxx；SSE=SST−SSR
MSE=SSE/(n−2)；F=(SSR/1)/MSE
  1. Road data 的 SST=224，上一节得到 SSE=44，因此 SSR=180；也可用 3²×20=180。
  2. 估计了 intercept 与 slope 两个参数，error df=5−2=3，MSE=44/3≈14.6667。
  3. 检验 H₀:β₁=0 时，regression df=1，F=180/14.6667≈12.2727。
  4. 在模型条件下用 F(1,3) 的右尾求 P≈.0394。这是线性 slope 是否为 0 的证据，不是模型已完全正确的证明。
SE(b₁)=√(MSE/Sxx)
SE(b₀)=√[MSE(1/n+x̄²/Sxx)]
t=(bⱼ−βⱼ,₀)/SE(bⱼ)，df=n−2

Road slope SE=√(14.6667/20)≈.85635，t=3/.85635≈3.50325；t²≈12.2727，与对应双侧 slope F test 一致。Coefficient CI 是 bⱼ±t critical×SE。

更多 x variation 可以增大 Sxx，降低 slope SE，但取值必须在科学可比较的范围中。只为了扩大范围而混入不同总体，可能改变研究问题。下一节将区分“这条平均线的 uncertainty”和“一个新观测的 uncertainty”。

从 coefficient CI 到预测：保留 covariance

继续用课程 road 五个观测 x=[1,3,4,5,7]、Y=[6,14,10,14,26]。已得到 b₀=2、b₁=3、MSE=44/3、x̄=4、Sxx=20。下面把两个 coefficient intervals 真正算出来，再解释它们怎样共同决定 fitted mean 的不确定性。

  1. Slope CI。 SE(b₁)=√[(44/3)/20]≈.856349。df=3、t.975,3≈3.182446，区间为 3±3.182446×.856349≈[.274716,5.725284]，单位仍是 Y单位/x单位。
  2. Intercept CI。 SE(b₀)=√[(44/3)(1/5+4²/20)]≈3.829708，区间为 2±3.182446×3.829708≈[−10.187841,14.187841]。这里 x=0 不在观测范围1–7内；区间描述该模型系数，并不自动赋予零里程额外科学含义。
  3. 记录两个估计量的 covariance。 Cov̂(b₀,b₁)=−x̄×MSE/Sxx=−4×(44/3)/20=−2.933333。它们是同一条线共同估出的参数，不能当作两个互相独立的估计值。
Var̂(b₀)=14.666667；Var̂(b₁)=.733333；Cov̂(b₀,b₁)=−2.933333
Var̂(ŷ₀)=Var̂(b₀)+x₀²Var̂(b₁)+2x₀Cov̂(b₀,b₁)

在 x₀=4，方差为 14.666667+16×.733333+8×(−2.933333)=2.933333，SE≈1.712698。因此 mean CI 为14±3.182446×1.712698≈[8.549432,19.450568]，与下一节的 h₀ 公式一致。若漏掉 covariance，会误得 variance=26.4；也不能把 intercept 与 slope 各自 CI 的上下端点直接相加，声称它们组成同一置信度的预测区间。

# Reproduce the course road example from complete inline data.
d <- data.frame(x=c(1,3,4,5,7), y=c(6,14,10,14,26))
fit <- lm(y ~ x, data=d)
b <- coef(fit)
V <- vcov(fit)
error_df <- df.residual(fit)
mse <- deviance(fit)/error_df
critical <- qt(.975, df=error_df)
se <- sqrt(diag(V))
data.frame(estimate=b, SE=se,
           lower=b-critical*se, upper=b+critical*se)
confint(fit)
V
# Prediction is a linear combination of the same correlated coefficients.
x0 <- 4
a <- c(1, x0)
variance_mean <- as.numeric(t(a) %*% V %*% a)
estimate_mean <- as.numeric(a %*% b)
c(fitted_mean=estimate_mean, variance_mean=variance_mean,
  SE_mean=sqrt(variance_mean),
  wrong_variance_without_covariance=V[1,1]+x0^2*V[2,2],
  SE_new_observation=sqrt(mse+variance_mean))
predict(fit, newdata=data.frame(x=x0), se.fit=TRUE, interval="confidence")
predict(fit, newdata=data.frame(x=x0), interval="prediction")
# Centering changes the intercept's meaning, not the fitted line.
d$xc <- d$x-mean(d$x)
centered_fit <- lm(y ~ xc, data=d)
summary(centered_fit)$coefficients
vcov(centered_fit)

中心化可以让解释更直观。 改用 xc=x−4，直线写为 ŷ=14+3xc。Slope 及其 SE 不变；新的 intercept 是 x=4 的 conditional mean，SE≈1.712698，而不再是 x=0 的 coefficient。此时 Cov̂(new intercept,slope)=0（数值计算可能显示接近0的舍入误差），fitted values、residuals、SSE 与对应 x 处的预测均保持不变。改变坐标原点不能让数据支持原本没有支持的新结论。

Mean confidence interval 与 prediction interval 不同

给定 x₀ 后，有两个不同问题：“这个 x 上的总体平均 Y 是多少？”和“一个新单位的 Y 会是多少？”前者用 mean confidence interval，后者用 prediction interval（PI）。

ŷ₀=b₀+b₁x₀
h₀=1/n+(x₀−x̄)²/Sxx
Mean CI：ŷ₀±t₁₋α/₂,n₋₂√(MSE h₀)
New-observation PI：ŷ₀±t₁₋α/₂,n₋₂√[MSE(1+h₀)]

h₀ 描述 fitted mean 的估计不确定性。PI 中多出来的 1 对应新单位自身的 residual variance；即使平均线估得很准，个体仍会在它周围波动。因此 PI 通常明显更宽。

  1. Road data 在 x₀=4 时，ŷ₀=2+3×4=14。
  2. x₀ 正好等于 x̄，所以 h₀=1/5=.2；MSE=44/3。
  3. df=3、95% t critical≈3.18245。Mean CI 半宽=3.18245√[(44/3)×.2]≈5.4506，CI≈[8.5494,19.4506]。
  4. PI 半宽=3.18245√[(44/3)×1.2]≈13.3511，PI≈[.6489,27.3511]。

两种 interval 都在 x̄ 附近最窄，离中心越远，h₀ 越大。下方先在同一 x₀ 切换 CI/PI，再移动 x₀，看宽度如何变化。区间类型改变的是问题，不是数据。

Extrapolation（外推） 指到未观测范围预测。公式能算出一个区间，不表示 linear mean、variance 或科学机制在该范围仍成立。课程 absence 例也需要分别解释不同 work-experience 下的 mean 与 individual prediction。

上面的 h₀ 公式也可以由 coefficient covariance 的完整例子推出：ŷ₀=b₀+b₁x₀，因此必须把2x₀Cov(b₀,b₁)保留在其方差中。vcov(fit) 与 predict(fit, newdata=..., se.fit=TRUE) 应得到一致的 fitted-mean SE；单个新观测再加入自己的 error variance。

显著 slope 不保证 linear model 适合

Slope 显著，不代表直线适合。Residual vs x 若有弯曲，可能遗漏了 mean relationship；funnel 提示 variance pattern；QQ plot检查 error shape。独立性仍根据设计判断。

若某些 x levels 有独立重复观测，可以把拟合误差分成 pure error（纯误差） 与 lack of fit（拟合不足）。前者是在同一个 x 上，Y 本身的波动；后者是该 x 的平均 Y 与模型线之间的系统差距。

SSPE=ΣⱼΣₖ(Yⱼₖ−ȳⱼ)²，dfPE=n−g
SSLOF=SSE−SSPE，dfLOF=g−p
FLOF=[SSLOF/(g−p)]/[SSPE/(n−g)]
  1. 数 distinct x levels 为 g，总观测为 n，mean model 参数数为 p；SLR p=2，quadratic p=3。
  2. 在每个 x 内用其 own sample mean 求平方和，得到 SSPE。
  3. 从 line SSE 扣掉 SSPE，剩下 SSLOF；它衡量 cell means 未被 line 解释的部分。
  4. 分别除以 df 后取 ratio，问系统不适合是否大于同 x 重复单位的自然误差。

课程 heat-loss 在 4 个 temperatures 各 3 repeats，n=12、g=4。SLR 的 LOF df=2、pure-error df=8；SSLOF≈858.91，MSPE≈20.833，F≈20.61，提示线性 mean 不适合。加入 x² 后还要继续诊断；R² 增加本身不证明 quadratic 正确。

复制一行数据不是 independent replication。没有合适的重复 x，就不能用上述公式独立估 pure error。Null 也只关于所测 x levels 上的 model form，不是整条无限范围内的科学定律。

完整原创 R 示例。 上面的 heat-loss 是课程汇总结果；以下另用一组明确列出的教学数据复现整个计算过程，数值不冒充 heat-loss 原始记录。设 x=1,2,3,4，每个 x 测量三个独立单位；cell means 为 3、6、11、19。一次性比较直线与事先列出的 quadratic 形式，避免把任意增加模型复杂度当作验证。

# Original data: four x levels, three independent units per level.
d <- data.frame(x=rep(1:4, each=3),
                y=c(2, 3, 4, 5, 6, 7, 10, 11, 12, 18, 19, 20))
with(d, table(x))
aggregate(y ~ x, data=d, FUN=mean)
line <- lm(y ~ x, data=d)
cell <- lm(y ~ factor(x), data=d)
# The cell model leaves pure error from genuine within-x replication.
ss_pe <- deviance(cell)
df_pe <- df.residual(cell)
ss_lof <- deviance(line) - ss_pe
df_lof <- df.residual(line) - df_pe
F_lof <- (ss_lof/df_lof)/(ss_pe/df_pe)
c(SSE_line=deviance(line), SS_pure_error=ss_pe, SS_lack_of_fit=ss_lof,
  df_pure_error=df_pe, df_lack_of_fit=df_lof, F=F_lof,
  p_value=pf(F_lof, df_lof, df_pe, lower.tail=FALSE))
anova(line, cell)
# A prespecified quadratic offers a second mean-form illustration.
quadratic <- lm(y ~ x + I(x^2), data=d)
coef(quadratic)
anova(quadratic, cell)
par(mfrow=c(1, 2))
plot(d$x, residuals(quadratic), xlab="x", ylab="Quadratic residual",
     main="Residuals vs x")
abline(h=0, lty=2)
qqnorm(residuals(quadratic))
qqline(residuals(quadratic))
par(mfrow=c(1, 1))
# Both intervals below are conditional on the quadratic model assumptions.
predict(quadratic, data.frame(x=2.5), interval="confidence")
predict(quadratic, data.frame(x=2.5), interval="prediction")

逐行核对 LOF。 同一 x 内的三个值都离本组 mean 为 −1、0、1，因此 SSPE=4×2=8，dfPE=12−4=8，MSPE=1。直线 SSE=26.9，所以 SSLOF=26.9−8=18.9、dfLOF=4−2=2；F=9.45、P≈.007823，在 α=.05 下拒绝线性 mean 形式。anova(line, cell) 的第二行给出同一个检验。

Quadratic 的拟合式为 ŷ=2.75−.95x+1.25x²，SSE=8.15；它与 cell model 的差为 SSLOF=.15、dfLOF=1，F=.15、P≈.70864。未发现拟合不足并不证明 quadratic 为真，仍需读残差、核对独立性与方差条件。在这些模型条件成立时，x₀=2.5 的 mean estimate=8.1875，95% mean CI≈[7.1927,9.1823]，new-observation PI≈[5.8161,10.5589]。PI 更宽，因为它还包括新个体误差；该示例不支持向观测范围之外外推。

Correlation 衡量 linear association，不替代机制

Pearson correlation（相关系数） 总结两个变量的 linear association，范围在 −1 与 1。它没有单位；slope 有单位。把 x 与 Y 交换，r 不变，但 slope 一般改变。

r=Sxy/√(Sxx Syy)
R²=SSR/SST；含 intercept 的 SLR 中 R²=r²

Road data Sxy=60、Sxx=20、Syy=224，因此 r=60/√4480≈.89642。R²=180/224≈.80357，表示这个 fitted model 解释了约 80.4% 的样本 Y variation；不是“预测有 80.4% 概率正确”。

平方会丢失符号，所以只能说 R²=r²，不能总写 r=√R²。负 slope 对应负 r，而 R² 仍非负。r=0 也只表示没有线性关系：U-shaped pattern 可能有很强非线性结构，却得到接近 0 的 r。

检验 H₀:ρ=0：t=r√[(n−2)/(1−r²)]，df=n−2

常见精确 reference 依赖独立 bivariate normal observations；在相应模型下，它与 SLR slope test 对应。|r|=1 是退化情形，不能把分母为 0 硬算成普通有限 t。

Correlation 仍不能确定因果方向或排除 confounding。先看 scatterplot、取值范围、异常点与样本选择，再决定 r 对研究问题说明了什么。

Estimator 的 sampling distribution 可以有偏

真实总体 correlation 为 ρ，样本算出的 r 会改变。除了随机波动，r 在有限样本下还可能有 bias（偏差）：重复抽样的平均结果不完全等于 ρ。

Bias(r)=E(r)−ρ
  1. 模拟时先指定真实 ρ，例如 .8，以及样本量 n。
  2. 每次从同一个模型生成独立样本，算一次 r。
  3. 重复多次，查看 r 的 distribution；其样本平均估计 E(r)，与 .8 的差估计 bias。
  4. 改变 n，再比较平均位置和分散程度。不要把一轮模拟的 mean 当作无误差的解析结论。

课程 ρ=.8、n=3 的 500 次模拟，r 平均约 .70；n=50 时约 .796。小样本的 r 分布可能靠近边界，形状不正态，单次 estimate 很不稳定。n 增大通常降低偏差与变异，但必须保留生成模型的条件。

在 ρ=0 的对称情形下可有 E(r)=0，不能把这一结果推广到任意 ρ。模拟要记录 true ρ、n、重复次数与 seed；Monte Carlo variability 是有限次模拟带来的误差，estimator bias 是估计量本身的重复抽样性质，两者不同。

练习：r=.9，可以说 x 造成 Y 增加吗？

先说数据中线性关联较强，再检查设计能否识别因果。Confounder、reverse causality 或 selection 都可能造成关联，r 本身无法区分。

练习：为什么 PI 比 mean CI 宽？

第一步，mean CI 只估计 E(Y|x₀) 的 uncertainty。第二步，新单位还有自己的 residual error。第三步，两份方差相加，所以 PI 的括号中多一个 1。

自己生成一个已知ρ的总体模型，再量化 Monte Carlo 误差

知道 bias 的定义之后，还需要知道“真实ρ怎样放进模拟”和“有限模拟的均值有多不稳定”。令 X 与 Z 是相互独立的标准正态变量，构造 Y=ρX+√(1−ρ²)Z。此时 Var(X)=Var(Y)=1，Cov(X,Y)=ρ，所以总体 correlation 确实为ρ；每个样本的 r 仍然会随机变化，不是被强制设成ρ。

  1. 区分两种数量。 n 是每次估计 r 所用的观测对数；B 是独立重复整次研究的次数。增大 n 改变估计量的 sampling distribution，增大 B 则让我们更精确地观察该分布。
  2. 每次重新抽独立数据。 固定同一个总体ρ，为每次研究分别生成 n 对 (X,Y)，计算一个 r。不要从一次样本复制出 B 份，也不要在循环内反复设同一个 seed。
  3. 估计 bias。 B 个 r 的均值 r̄MC 估计 E(r)，因此 bias estimate=r̄MC−ρ。模拟中ρ已知；真实研究中的未知ρ不能这样直接代入。
  4. 给模拟结果自己的误差尺度。 MCSE=s(r₁,…,rB)/√B。B 较大时，可用 bias estimate±1.96MCSE 表达近似 Monte Carlo 不确定性；这是我们对模拟期望的数值精度，不是某个真实研究中ρ的 CI。

下面的原创模拟固定seed=44011、每种情形B=5000。它沿用课程的总体模型思路，重新生成数据，因此无需与课件SAS的500次模拟均值完全相同。

# Original Monte Carlo study; the seed fixes this software illustration.
set.seed(44011)
repetitions <- 5000
simulate_r <- function(n, rho, repetitions) {
  stopifnot(n >= 3, abs(rho) < 1)
  replicate(repetitions, {
    x <- rnorm(n)
    independent_z <- rnorm(n)
    y <- rho*x+sqrt(1-rho^2)*independent_z
    cor(x, y)
  })
}
settings <- data.frame(n=c(3,50,3), rho=c(.8,.8,0))
r_samples <- lapply(seq_len(nrow(settings)), function(i) {
  simulate_r(settings$n[i], settings$rho[i], repetitions)
})
mean_r <- vapply(r_samples, mean, numeric(1))
sampling_sd <- vapply(r_samples, sd, numeric(1))
bias_estimate <- mean_r-settings$rho
mcse <- sampling_sd/sqrt(repetitions)
simulation_summary <- data.frame(settings, repetitions=repetitions,
  mean_r=mean_r, sampling_SD=sampling_sd, bias_estimate=bias_estimate,
  MCSE=mcse, MC_lower=bias_estimate-qnorm(.975)*mcse,
  MC_upper=bias_estimate+qnorm(.975)*mcse)
simulation_summary
# These histograms describe repeated estimates, not the raw X or Y data.
par(mfrow=c(1,3))
for (i in seq_len(nrow(settings))) {
  hist(r_samples[[i]], breaks=30, xlim=c(-1,1), xlab="Sample r",
       main=paste("n =",settings$n[i],"rho =",settings$rho[i]))
  abline(v=settings$rho[i], col="firebrick", lwd=2)
}
par(mfrow=c(1,1))

不要把bias、精度与检验混成一件事。 r的sampling SD描述一次研究中r的波动；MCSE描述5000次r平均值的数值误差。加大B能降低MCSE，却不会改变固定n下估计量本身的bias。也不能把本页已知ρ的模拟bias作为所有真实数据都适用的扣除项。

前一节的精确 t reference 针对 H₀:ρ=0；若研究要检验一个非零ρ₀，不能只把公式中的r换成r−ρ₀就继续用同一个t分布。本节提供的是已知模型下的bias研究，没有把该模拟区间冒充未知ρ的置信区间。

把课程案例连回方法与结论

下面把前面的计算方法放回课程案例。每个案例先辨认研究目标与数据结构，再说明如何计算和解释。PPT 与 class notes 中不同的场景分别保留。

铺路与 influential points：完整算一次 line

Road resurfacing 给出 x=[1,3,4,5,7]、Y=[6,14,10,14,26]。Least squares 得到 Ŷ=2+3x，residuals=[1,3,−4,−3,3]，SSE=44、MSE=44/3，F≈12.273、P≈.03939。正文与分步图展示了这些结果的来路。

交互中可改变最后一个点，观察 slope、R² 与 intervals 怎样一起变化。Residual 大表示点偏离 fitted line；high leverage 来自极端 x 位置，两者不同。Cook’s distance 结合位置与偏离对拟合的影响，不能只根据一个 residual 大小判断影响力。

药房案例：先保留各自的变量定义

PPT 将 x 定义为非 brand-name 药物的比例，Y 为利润；class notes 则描述处方销售量与从 manufacturer 直接购买原料的比例。这是两个不同的业务问题，解读时应分别沿用各份资料的 x 与 Y 定义。

Slope 的单位由“Y 的单位 / x 的单位”决定。先写清分子分母，再解释 x 增加一个单位对应的 fitted mean 变化；不能把一份利润数据的结论，直接改写成另一份销售量指标的效果。

缺勤与每股收益：coefficient 有单位和范围

Absence 随 experience 下降时，b₁ 表示每增加一个 experience 单位，预期 absence 怎样改变。b₀ 是 x=0 的 fitted mean；如果 0 在观测范围外，不能不加说明地赋予它现实意义。

Class notes 另用 executive mean age 与前一年 earnings-per-share percentage change 做 slope inference。它反映 observational association，不能据此声称年龄造成收益变化。R 的 predict(newdata=data.frame(x=...)) 还要求 newdata 列名与拟合时的 predictor 名称一致。

热损失与 correlation 模拟：两种不同的误差

Heat loss 在 4 个 temperatures 各测 3 个观测，N=12。SLR residual df=10；相同 x 内的 pure-error df=12−4=8，lack-of-fit df=4−2=2。先算组内 SSE，再从线性拟合 SSE 中减去它，才能把随机波动与线性失配分开；显著 LOF 后可考虑 quadratic，并重新检查模型。

Correlation 模拟固定真实 ρ=.8。n=3 时，500 次 r 的平均值约 .70；n=50 时约 .796。有限模拟的均值只是 E(r) 的估计，仍有 Monte Carlo 波动；观察它随 n 接近真值，可以理解 small-sample bias，但不能把一次模拟当成精确解析定理。

高 leverage、outlier 与 influence：三个问题分别检查

回归中的“异常点”至少包含三种不同情况。Leverage 问 x 是否远离大多数预测变量；residual outlier 问 Y 是否远离模型给出的条件均值；influence 问去掉这个点会让拟合结果改变多少。它们相关，但不是同义词。

原创五个观测 x=[0,1,2,3,4]，y=[1,2,5,8,9]。最小二乘线为 ŷ=.6+2.2x。现在增加一个 x=10 的观测，它远离原有 x 范围。

  1. 若新 y=22.6。 新点恰好落在原拟合线，加入后 slope 仍为2.2、intercept 仍为.6。它的 leverage 很高，但本次没有改变回归系数。
  2. 若同一个 x=10 的 y 改成5。 加入后 slope≈.347368、intercept≈3.842105，拟合方向几乎被拉平。
  3. 看新点自身 residual。 第二种情形中，新点的 fitted y≈7.315789，residual≈−2.315789。它已经把线拉向自己，因此它对原线的巨大偏离，被重新拟合后的残差部分掩盖。
hᵢ=1/n+(xᵢ−x̄)²/Sxx
加入 x=10 后，该点 h≈.868421

Leverage 由 x 决定，所以上述两个版本的 h 完全相同。这个例子说明，只按“绝对 residual 最大”寻找有影响的点，会漏掉重要情况。

x <- c(0,1,2,3,4,10)
y <- c(1,2,5,8,9,5)
fit <- lm(y ~ x)
# Compare the full fit with a documented sensitivity fit.
coef(fit)
coef(lm(y[-6] ~ x[-6]))
# Examine predictor leverage, scaled residuals, and influence together.
data.frame(x=x,y=y,
  leverage=hatvalues(fit),
  studentized_residual=rstudent(fit),
  cooks_distance=cooks.distance(fit))
plot(x,y,pch=16,xlab="x",ylab="y")
abline(fit,col="firebrick",lwd=2)
abline(lm(y[-6] ~ x[-6]),col="steelblue",lty=2,lwd=2)

如何行动： 先核查原始记录、单位和测量流程；再判断这个 x 是否属于目标总体，以及直线模型在此范围是否合理。对真实但影响很大的观测，应透明报告敏感性结果，并考虑更合适的模型或更多该范围的数据。某个诊断超过经验阈值，只是调查线索，不能自动触发删除。
